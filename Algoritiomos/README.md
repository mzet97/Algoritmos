## Biblioteca bib1

Cada linguagem tem uma biblioteca auxiliar:

| Linguagem | Arquivo | Funções |
|-----------|---------|---------|
| Python | `python/bib1.py` | `entrada()` |
| Rust | `rust/bib1/src/lib.rs` | `Leitor::entrada()`, `python_float()` |
| Go | `go/bib1/bib1.go` | `Entrada()`, `PythonFloat()` |
| C | `c/bib1.h` | `entrada()`, `print_python_float()` |
| C++ | `cpp/bib1.hpp` | `entrada()`, `python_float()` |

- **`entrada()`** — lê uma linha de stdin ignorando linhas vazias, retorna EOF
- **`python_float()`** — formata floats no estilo Python (shortest round-trip)
