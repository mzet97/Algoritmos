# Aula 9 - Function pointers, callbacks e tabelas de despacho

---

## Objetivo da Aula

Ao final, voce devera: ler uma assinatura com ponteiro de funcao e dizer o que ela recebe e devolve; parametrizar um comportamento via callback sem tocar o chamador; e explicar por que chamar por ponteiro com assinatura errada e UB silencioso.

### Como ler esta aula (tres niveis)

- **Fundamental:** declarar, atribuir e chamar por ponteiro; `typedef` para legibilidade.
- **Intermediario:** callback como parametro, tabela de despacho indexada.
- **Aprofundamento (opcional):** conversao entre ponteiros de funcao de assinaturas distintas e o custo da indirecao (aula 30 retoma).

## 2. O que e function pointer?

- **Function pointer**: ponteiro que referencia uma funcao com determinada assinatura.

Exemplo:

```c
int soma(int a, int b) {
    return a + b;
}

int (*op)(int, int) = soma;
```

### 2.1 O que essa declaracao quer dizer?

- `op` e ponteiro;
- para funcao;
- que recebe `(int, int)`;
- e retorna `int`.

Essa sintaxe assusta no inicio, mas o contrato e claro.

---

## 3. Chamando via ponteiro

Exemplo:

```c
int resultado1 = op(2, 3);
int resultado2 = (*op)(2, 3);
```

As duas formas sao validas.

### 3.1 Modelo mental

Em vez de chamar um simbolo conhecido estaticamente, voce chama atraves de uma referencia indireta.

---

## 4. Por que isso existe?

Porque permite:

- callbacks;
- selecao dinamica de comportamento;
- tabelas de operacoes;
- plugin manual simplificado;
- separacao entre "quem decide" e "quem executa".

Sem isso, C ficaria muito menos flexivel para APIs genericas.

---

## 5. Callback

- **Callback**: funcao passada para outra funcao para ser chamada depois em certo contexto.

Exemplo:

```c
void percorre(int *v, int n, void (*f)(int)) {
    for (int i = 0; i < n; i++) {
        f(v[i]);
    }
}
```

Agora podemos passar comportamentos diferentes.

---

## 6. Exemplo simples de callback

```c
#include <stdio.h>

void imprime(int x) {
    printf("%d\n", x);
}

void percorre(int *v, int n, void (*f)(int)) {
    for (int i = 0; i < n; i++) {
        f(v[i]);
    }
}

int main(void) {
    int v[3] = {10, 20, 30};
    percorre(v, 3, imprime);
    return 0;
}
```

### 6.1 O que isso ensina?

Que o algoritmo de percorrer e fixo.

O comportamento aplicado em cada elemento e parametrizavel.

---

## 7. `typedef` para melhorar legibilidade

Sem `typedef`:

```c
int (*op)(int, int);
```

Com `typedef`:

```c
typedef int (*OperacaoBinaria)(int, int);
OperacaoBinaria op;
```

### 7.1 Regra pratica

Para APIs mais ricas com callback:

- `typedef` melhora muito a leitura.

---

## 8. Tabela de despacho

- **Dispatch table**: estrutura que mapeia uma operacao para a funcao correspondente.

Exemplo:

```c
typedef int (*OperacaoBinaria)(int, int);

struct Entrada {
    const char *nome;
    OperacaoBinaria func;
};
```

Agora voce pode ter array dessas entradas.

---

## 9. Exemplo completo da aula

```c
#include <stdio.h>
#include <string.h>

typedef int (*OperacaoBinaria)(int, int);

int soma(int a, int b) {
    return a + b;
}

int subtrai(int a, int b) {
    return a - b;
}

int multiplica(int a, int b) {
    return a * b;
}

struct Entrada {
    const char *nome;
    OperacaoBinaria func;
};

int executar(const struct Entrada *tabela, int n, const char *nome, int a, int b) {
    for (int i = 0; i < n; i++) {
        if (strcmp(tabela[i].nome, nome) == 0) {
            return tabela[i].func(a, b);
        }
    }
    return 0;
}

int main(void) {
    struct Entrada tabela[] = {
        {"soma", soma},
        {"subtrai", subtrai},
        {"multiplica", multiplica}
    };

    int n = (int)(sizeof(tabela) / sizeof(tabela[0]));

    printf("soma = %d\n", executar(tabela, n, "soma", 10, 5));
    printf("subtrai = %d\n", executar(tabela, n, "subtrai", 10, 5));
    printf("multiplica = %d\n", executar(tabela, n, "multiplica", 10, 5));

    return 0;
}
```

### 9.1 Explicacao linha por linha

- `typedef int (*OperacaoBinaria)(int, int);`: nomeia uma assinatura de callback.
- `struct Entrada`: associa nome textual a funcao.
- `strcmp(...) == 0`: compara nome pedido com nome cadastrado.
- `tabela[i].func(a, b)`: chamada indireta atraves do ponteiro de funcao.
- `sizeof(tabela) / sizeof(tabela[0])`: calcula quantidade de entradas no array local.

---

## 10. O que acontece em memoria?

Conceitualmente:

- o array `tabela` vive na stack de `main`;
- cada elemento contem um ponteiro para string literal e um ponteiro para funcao;
- o codigo das funcoes vive na secao de codigo do programa;
- o ponteiro de funcao referencia essa regiao de codigo conforme ABI da plataforma.

O ponto central e:

- dados podem carregar referencias para comportamento.

---

## 11. Cuidados importantes

### 11.1 Assinatura precisa bater

Se o ponteiro de funcao espera:

```c
int (*)(int, int)
```

nao passe funcao com assinatura diferente.

### 11.2 `NULL`

Ponteiro de funcao pode ser `NULL`.

Cheque quando a API permitir ausencia de callback.

### 11.3 Complexidade de sintaxe

Ponteiro de funcao em C e um dos pontos onde vale muito a pena usar:

- `typedef`;
- nomes claros;
- exemplos pequenos.

## 13. Comparacao com C++, Rust, Go e Python

- Em C++, functors, lambdas e `std::function` oferecem muito mais expressividade.
- Em Rust, closures e traits tornam isso mais seguro e tipado.
- Em Go, funcoes sao valores de primeira classe com sintaxe muito mais amigavel.
- Em Python, funcoes como objetos tornam callback muito natural.

Em C, a ideia e a mesma, mas a sintaxe e a seguranca sao mais cruas.

---

## 14. Erros Comuns e Anti-Padroes

1. **Assustar-se com a sintaxe e parar de ler a assinatura com calma**.
2. **Usar assinatura errada no ponteiro de funcao**.
3. **Nao validar callback opcional antes de chamar**.
4. **Esconder demais a logica e perder legibilidade**.
5. **Abusar de dispatch table sem criterio quando um `switch` simples resolveria**.
