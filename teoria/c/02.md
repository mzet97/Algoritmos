# Aula 2 - Tipos basicos, variaveis, constantes, operadores e controle de fluxo

## 2. Declaracao de variaveis

Exemplos:

```c
int x = 10;
double y = 3.14;
char c = 'Z';
```

### 2.1 O que e declarar?

- **Declarar uma variavel**: informar ao compilador seu tipo e seu nome, e opcionalmente inicializa-la.

Em C, o tipo vem antes do nome.

Isso parece simples, mas define:

- quanto espaco sera reservado;
- como interpretar os bits;
- quais operacoes fazem sentido.

---

## 3. Tipos inteiros e sinal

Tipos inteiros comuns:

- `char`
- `short`
- `int`
- `long`
- `long long`

Versoes sem sinal:

- `unsigned char`
- `unsigned short`
- `unsigned int`
- `unsigned long`
- `unsigned long long`

### 3.1 O que significa "sem sinal"?

Um inteiro sem sinal representa apenas valores nao negativos.

Isso muda o intervalo de representacao.

### 3.2 Regra importante

Nao assuma tamanhos exatos para todos esses tipos.

Assuma apenas o que o padrao e a ABI permitem.

Se precisarmos de largura exata, mais tarde usaremos tipos de `stdint.h`.

---

## 4. Tipos de ponto flutuante

Principais:

- `float`
- `double`
- `long double`

### 4.1 Ponto importante

Numeros de ponto flutuante:

- nao representam todos os reais exatamente;
- acumulam erro de arredondamento;
- exigem cuidado em comparacoes.

Exemplo conceitual:

```c
double x = 0.1 + 0.2;
```

Voce nao deve assumir que isso e exatamente `0.3` em representacao binaria.

---

## 5. `char` nao e "string"

`char` representa um byte.

Frequentemente ele armazena caractere textual, mas o tipo em si nao e "texto magico".

Exemplo:

```c
char letra = 'A';
char numero_bruto = 65;
```

Nos dois casos, estamos lidando com um byte interpretado de modos diferentes.

---

## 6. Constantes em C

Forma simples:

```c
const int limite = 100;
```

### 6.1 O que `const` faz?

Ele diz que aquele objeto nao deve ser modificado atraves daquele nome.

### 6.2 Cuidado

`const` em C nao e o mesmo tipo de garantia absoluta conceitual que muita gente imagina vindo de C++ ou Rust.

Ainda assim, e muito importante para:

- documentacao da intencao;
- APIs;
- seguranca de leitura;
- compatibilidade com buffers somente leitura.

## 7. Operadores aritmeticos

Principais:

- `+`
- `-`
- `*`
- `/`
- `%`

Exemplo:

```c
int a = 7;
int b = 3;

printf("%d\n", a + b);
printf("%d\n", a - b);
printf("%d\n", a * b);
printf("%d\n", a / b);
printf("%d\n", a % b);
```

### 7.1 Divisao inteira

Em:

```c
7 / 3
```

com operandos inteiros, o resultado e inteiro.

Ou seja:

- resultado: `2`

Esse detalhe gera muito bug em iniciantes.

---

## 8. Operadores relacionais e logicos

Relacionais:

- `==`
- `!=`
- `<`
- `<=`
- `>`
- `>=`

Logicos:

- `&&`
- `||`
- `!`

### 8.1 Verdade em C

C nao tem `bool` na origem historica da linguagem como Python ou Go.

No modelo tradicional:

- `0` significa falso;
- qualquer valor diferente de `0` significa verdadeiro.

Hoje existe `_Bool` e `stdbool.h`, mas o modelo numerico ainda importa.

## 9. Incremento e decremento

Exemplos:

```c
int x = 5;
x++;
+x;
x--;
--x;
```

### 9.1 Pre-incremento vs pos-incremento

- `x++`: usa o valor atual e depois incrementa.
- `++x`: incrementa primeiro e depois usa o valor.

Regra pratica forte:

- evite expressoes confusas com muitos incrementos no mesmo lugar.

Em C, legibilidade e seguranca mental importam muito.

---

## 10. `if`, `else` e `else if`

Exemplo:

```c
if (idade < 18) {
    printf("menor\n");
} else if (idade < 60) {
    printf("adulto\n");
} else {
    printf("idoso\n");
}
```

### 10.1 Parenteses importam

Em C, a condicao de `if` vai entre parenteses.

As chaves sao fortemente recomendadas mesmo para bloco curto.

---

## 11. `switch`

Exemplo:

```c
switch (opcao) {
    case 1:
        printf("abrir\n");
        break;
    case 2:
        printf("salvar\n");
        break;
    default:
        printf("opcao invalida\n");
        break;
}
```

### 11.1 Por que `break` importa?

Sem `break`, o fluxo pode continuar no proximo `case`.

Isso se chama:

- **fallthrough**

E pode ser:

- util em casos raros;
- perigoso em casos comuns.

---

## 12. Loops

### 12.1 `while`

```c
int i = 0;
while (i < 3) {
    printf("%d\n", i);
    i++;
}
```

### 12.2 `for`

```c
for (int i = 0; i < 3; i++) {
    printf("%d\n", i);
}
```

### 12.3 `do ... while`

```c
int i = 0;
do {
    printf("%d\n", i);
    i++;
} while (i < 3);
```

O `do ... while` roda pelo menos uma vez.

---

## 13. O que acontece em memoria aqui?

Considere:

```c
int a = 10;
int b = 3;
int c = a + b;
```

Conceitualmente:

- `a`, `b` e `c` sao variaveis locais;
- tipicamente vivem na stack frame da funcao atual;
- o compilador pode usar registradores em vez de sempre gravar tudo na memoria;
- o tipo `int` define como os bits serao interpretados nas operacoes.

Isso importa porque C e linguagem onde:

- representacao e operacao andam muito proximas.

## 14. Exemplo completo da aula

```c
#include <stdio.h>

int main(void) {
    int idade = 32;
    const int limite = 18;
    double nota = 8.5;

    printf("idade = %d\n", idade);
    printf("nota = %.1f\n", nota);

    if (idade >= limite && nota >= 7.0) {
        printf("aprovado\n");
    } else {
        printf("reprovado\n");
    }

    for (int i = 0; i < 3; i++) {
        printf("i = %d\n", i);
    }

    return 0;
}
```

### 14.1 Explicacao linha por linha

- `const int limite = 18;`: constante de leitura local.
- `double nota = 8.5;`: ponto flutuante.
- `idade >= limite && nota >= 7.0`: combinacao de operadores relacionais e logicos.
- `for (int i = 0; i < 3; i++)`: loop classico com inicializacao, condicao e passo.

## 16. Comparacao com C++, Rust, Go e Python

- Em C++, o nucleo desses operadores ainda e muito parecido, mas a linguagem adiciona sobrecarga e tipos mais ricos.
- Em Rust, comparacoes e booleanos sao mais estritos, e varias ambiguidades perigosas de C desaparecem.
- Em Go, a sintaxe e mais enxuta em alguns pontos e certas armadilhas de conversao sao menos permissivas.
- Em Python, inteiros e objetos de alto nivel; em C, estamos muito mais proximos da representacao bruta.

## 17. Erros Comuns e Anti-Padroes

1. **Confundir `=` com `==`**.
2. **Esquecer que divisao entre inteiros trunca**.
3. **Assumir que `char` e sempre "texto"**.
4. **Escrever `if` sem chaves e criar bugs de manutencao**.
5. **Montar expressoes com muitos `++` e `--` desnecessariamente**.
6. **Usar `%f` ou `%d` no `printf` para o tipo errado**.
