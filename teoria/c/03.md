# Aula 3 - Funcoes, prototipos, escopo, stack frame e organizacao basica do codigo

---

## Objetivo da Aula

Entender como C organiza comportamento em funcoes, por que prototipos existem, como parametros sao passados, o que e escopo, e como chamadas se relacionam com stack frame e fluxo de execucao. Ao final, voce deve conseguir dividir um programa em funcoes menores entendendo o custo e o modelo mental de cada chamada.

## 2. O que e uma funcao em C?

- **Funcao**: bloco nomeado de codigo que pode receber parametros, produzir um retorno e ser chamado de varios lugares.

Exemplo simples:

```c
int soma(int a, int b) {
    return a + b;
}
```

### 2.1 O que essa assinatura diz?

- retorno: `int`
- nome: `soma`
- parametros: dois `int`

Em C, assinatura e contrato essencial.

---

## 3. Por que funcoes existem?

Porque elas permitem:

- reutilizacao;
- organizacao;
- isolamento de responsabilidade;
- clareza;
- testes mais localizados;
- menor repeticao.

Regra pratica:

- `main` coordena;
- funcoes especializadas executam partes do trabalho.

---

## 4. Prototipos de funcao

Exemplo:

```c
int soma(int a, int b);
```

Isso e um prototipo.

### 4.1 O que e um prototipo?

- **Prototipo**: declaracao previa de uma funcao, informando ao compilador nome, retorno e parametros antes da definicao completa.

### 4.2 Por que isso existe?

Porque C compila por unidades de traducao e precisa conhecer a assinatura antes do uso correto.

Exemplo comum:

```c
#include <stdio.h>

int soma(int a, int b);

int main(void) {
    printf("%d\n", soma(2, 3));
    return 0;
}

int soma(int a, int b) {
    return a + b;
}
```

---

## 5. Declaracao vs definicao

Esse e um ponto central em C.

- **Declaracao**: diz que algo existe e informa seu tipo.
- **Definicao**: cria de fato aquela entidade ou implementacao.

### 5.1 Exemplo com funcao

Declaracao:

```c
int soma(int a, int b);
```

Definicao:

```c
int soma(int a, int b) {
    return a + b;
}
```

### 5.2 Por que isso importa?

Porque isso se conecta com:

- headers;
- multiplos arquivos;
- linkagem;
- bibliotecas.

---

## 6. Parametros sao passados por valor

Em C, o modelo basico e:

- passagem por valor

Exemplo:

```c
void tenta_alterar(int x) {
    x = 999;
}
```

Se `main` chamar:

```c
int n = 10;
tenta_alterar(n);
```

`n` continua valendo `10`.

### 6.1 O que foi copiado?

O valor de `n` foi copiado para o parametro `x`.

---

## 7. "Passagem por referencia" em C

C nao tem passagem por referencia nativa como C++.

O que fazemos e:

- passar o endereco do objeto por ponteiro

Exemplo:

```c
void altera(int *x) {
    *x = 999;
}
```

Uso:

```c
int n = 10;
altera(&n);
```

Agora `n` muda.

### 7.1 Modelo mental

- `&n` pega o endereco de `n`;
- `x` recebe uma copia desse endereco;
- `*x` acessa o objeto apontado.

Isso ainda e passagem por valor.

O valor copiado foi o endereco.

---

## 8. Escopo

- **Escopo**: regiao do codigo em que um nome e visivel.

### 8.1 Escopo local

```c
void f(void) {
    int x = 10;
}
```

`x` so existe dentro de `f`.

### 8.2 Escopo de bloco

```c
if (1) {
    int y = 20;
}
```

`y` so existe dentro daquele bloco.

### 8.3 Escopo global

```c
int contador_global = 0;
```

Agora o nome tem visibilidade mais ampla dentro daquela unidade de traducao, ou alem dela dependendo de ligacao.

---

## 9. Stack frame e chamada de funcao

Quando uma funcao e chamada, conceitualmente acontece algo assim:

1. argumentos sao preparados;
2. o fluxo salta para a funcao;
3. uma stack frame e usada para dados locais e controle da chamada;
4. a funcao executa;
5. retorna um valor se houver;
6. o fluxo volta para quem chamou.

### 9.1 O que costuma existir numa stack frame?

- parametros ou referencias a parametros, dependendo da ABI;
- variaveis locais;
- endereco de retorno;
- dados temporarios.

### 9.2 Importante

O compilador pode otimizar muita coisa:

- usar registradores;
- inline;
- eliminar variaveis temporarias.

Mas o modelo conceitual continua util.

## 10. `return`

Exemplo:

```c
int quadrado(int x) {
    return x * x;
}
```

### 10.1 Regras basicas

- funcao com retorno nao `void` deve devolver valor coerente;
- `void` indica ausencia de valor de retorno.

Exemplo:

```c
void imprime_ola(void) {
    printf("ola\n");
}
```

---

## 11. Recursao

Uma funcao pode chamar a si mesma.

Exemplo:

```c
int fatorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fatorial(n - 1);
}
```

### 11.1 Cuidado

Recursao profunda:

- consome stack;
- pode ser menos previsivel;
- pode causar stack overflow.

Em C, isso merece respeito.

---

## 12. Exemplo completo da aula

```c
#include <stdio.h>

int soma(int a, int b);
void troca(int *a, int *b);
int fatorial(int n);

int main(void) {
    int x = 10;
    int y = 20;

    printf("soma = %d\n", soma(x, y));

    troca(&x, &y);
    printf("apos troca: x = %d, y = %d\n", x, y);

    printf("fatorial(5) = %d\n", fatorial(5));

    return 0;
}

int soma(int a, int b) {
    return a + b;
}

void troca(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int fatorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fatorial(n - 1);
}
```

### 12.1 Explicacao linha por linha

- `int soma(int a, int b);`: prototipo de funcao.
- `void troca(int *a, int *b);`: prototipo com ponteiros.
- `int fatorial(int n);`: prototipo recursivo.
- `troca(&x, &y);`: envia enderecos, nao apenas valores.
- `int temp = *a;`: le o valor apontado por `a`.
- `return n * fatorial(n - 1);`: passo recursivo.

---

## 13. O que acontece em memoria nesse exemplo?

No `main`:

- `x` e `y` sao locais do `main`;
- vivem tipicamente na stack frame de `main`.

Na chamada:

```c
troca(&x, &y);
```

acontece conceitualmente:

- `&x` e `&y` produzem enderecos;
- esses enderecos sao copiados para os parametros `a` e `b`;
- `*a` e `*b` acessam os objetos originais.

No `fatorial(5)`:

- cada chamada cria nova ativacao logica;
- varias stack frames se acumulam;
- cada nivel espera o resultado do nivel seguinte.

## 16. Comparacao com C++, Rust, Go e Python

- Em C++, existe passagem por referencia de verdade com `T&`, o que muda a superficie da linguagem.
- Em Rust, referencias tem regras muito mais estritas de aliasing e mutabilidade.
- Em Go, tudo parece mais simples sintaticamente, mas ainda ha diferenca entre copiar valor e compartilhar estado por referencia interna.
- Em Python, nomes referenciam objetos; o modelo mental e muito diferente do custo explicito de stack frame e ponteiros em C.

---

## 17. Erros Comuns e Anti-Padroes

1. **Esquecer prototipo quando necessario**.
2. **Achar que passar ponteiro deixa de ser passagem por valor**.
3. **Retornar caminho de execucao sem valor em funcao nao `void`**.
4. **Usar recursao sem pensar no custo de stack**.
5. **Criar `main` enorme em vez de quebrar o problema em funcoes**.
6. **Confundir escopo local com tempo de vida global**.
