# Aula 02: pistas graduais

Volte aos [exercicios](../02.md#18-exercicios-obrigatorios) antes de abrir as solucoes.

1. Leia dois `int` com `scanf` conferindo o retorno; compare com `if/else` e trate o caso de igualdade como ramo proprio.
2. Paridade e o resto da divisao por 2: pense em `n % 2` e no que acontece com numeros negativos.
3. No `switch`, cada `case` precisa de `break` (ou de uma queda intencional comentada); o `default` recebe o que nao casou.
4. Compare `7 / 2` com `7.0 / 2`: o tipo dos operandos decide a divisao antes da atribuicao.
5. Para a explicacao: relacione o valor de uma condicao com o que `if` aceita como verdadeiro — qualquer escalar diferente de zero.
