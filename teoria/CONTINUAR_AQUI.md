## Decisões do usuário que continuam válidas

- Produzir **cinco livros autônomos**, em português brasileiro, para leitores que conhecem o básico de Python ou JavaScript. Um livro não pode exigir outro como pré-requisito oculto.
- Usar a profundidade didática de [Rust](rust/prompt.md) como referência editorial, mas revisar também suas afirmações técnicas. O projeto busca competências demonstráveis de alto nível, não equivalência declarada a um diploma.
- Trabalhar por **Spec Driven Development**: competência → aula → exercício → avaliação → evidência. C é o primeiro livro a completar; correções graves em qualquer idioma podem ser antecipadas.
- Ensinar segurança defensiva, memória, concorrência, redes, falhas distribuídas, multicore, HPC e GPU. C, C++ e Rust terão laboratórios de kernel **RISC-V/QEMU antes de x86-64**. Go e Python estudarão SO pelo espaço de usuário e construirão ferramentas e sistemas distribuídos.
- Manter o núcleo obrigatório em toolchains estáveis e acessíveis; hardware GPU e recursos experimentais são laboratórios opcionais. Enunciados, pistas e soluções comentadas ficam separados. Markdown é a fonte; site navegável é a primeira publicação, PDF/EPUB vêm depois.

## Evidência de verificação e limites

- **Rechecado em 2026-11-17:** `teoria/c/exemplos/10a_memoria.c` compilou em WSL com GCC `-std=c11 -Wall -Wextra -Wpedantic -Werror` e executou; informou página de 4096 bytes e 2048 posições tocadas nesta máquina. Python 25/31 tiveram ensaios; Python 30/32 só tiveram sintaxe verificada por falta de FastAPI/Pandas. Consulte a auditoria para limites por área e **reexecute o que sustentar uma nova alegação de conclusão**.
