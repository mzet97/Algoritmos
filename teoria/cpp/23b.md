# Aula 23b - Dois nós, uma verdade: replicação com log, idempotência e queda real

---

## Objetivo da Aula

Transformar o servidor endurecido da aula 23a num par de nós que sobrevivem a falha parcial: réplica morta, mensagem repetida, queda no meio da escrita e par lento. Pré-requisitos: aulas 23, 23a e 27. Linux ou WSL2. Não precisa de QEMU, kernel próprio nem GPU.

Ao terminar, você deverá explicar por que reenviar sem chave de idempotência corrompe, por que responder antes do `fsync` mente, e por que uma cauda rasgada no log exige selo antes do próximo append — tudo com teste que mata processo de verdade (`SIGKILL`), não com falha fingida.

Esta aula é o módulo CPP-8 na parte executável: dois nós preservam o contrato documentado sob repetição, atraso e queda. O que falta depois dela: relógios lógicos e consistência além de primário-réplica, autenticação entre nós, e o kernel didático das aulas 33–40.

**Como ler esta aula (tres niveis):** *fundamental* -- idempotencia, fsync antes de responder, selo na cauda; *intermediario* -- SIGKILL de verdade e o replay que cura; *aprofundamento* -- o que falta (consenso, relogios, compactacao).

## 1. Onde um nó só mente

Um servidor sozinho tem três mentiras convenientes: a rede entrega exatamente uma vez (não entrega), o disco persiste quando `write` retorna (sem `fsync`, não persiste), e o processo só cai entre operações (cai no meio). Esta aula remove as três:

1. Cada escrita carrega um `id`. Repetir o mesmo `id` devolve o primeiro valor aplicado (`OK-REPETIDO`), nunca reaplica. Sem isso, um reenvio vira corrupção silenciosa.
2. Toda escrita nova entra no log com `fsync` antes de responder. Responder antes de persistir é prometer o que pode não existir depois da queda.
3. Queda é `SIGKILL` de verdade, no meio do que estiver acontecendo. O teste mata a réplica, escreve degradado, injeta lixo sem `\n` no fim do log dela e a reinicia no mesmo arquivo.
4. O replay ignora linha sem `\n` final e linha fora do formato. Cauda truncada é descarte, nunca adivinhação.
5. Antes de anexar, o escritor verifica se o arquivo termina com `\n`; se não termina, isola a cauda rasgada com uma quebra. Sem o selo, o registro novo cola no lixo e o próximo replay descarta os dois — uma cauda rasgada engoliria tudo adiante.

## 2. O contrato entre os nós

Protocolo em linhas, uma requisição por conexão, servidor fecha após responder:

- `PUT <id> <chave> <valor>` — aplica uma vez por `id`; responde `OK <id> <valor>`, ou `OK-REPETIDO <id> <valor-antigo>` se o `id` já existe.
- `GET <id> <chave>` — responde `OK <id> <valor>` (vazio se ausente).
- Qualquer outra forma responde `ERRO ...` e a conexão fecha.
- Quem aplica primeiro responde ao cliente e depois encaminha ao par com timeout curto (2 s). Par morto atrasa a resposta, não a impede: degrada, não trava.

// Dois nos chave-valor replicados com log duravel e idempotencia.
// Processos reais via fork(); morte real via SIGKILL; teste dirige tudo.
// Uso: ./srv23b  (executa o cenario completo e sai com 0 se tudo passar)
#include <arpa/inet.h>
#include <atomic>
#include <cerrno>
#include <csignal>

namespace {

constexpr int MAX_LINHA = 4096;
constexpr int MAX_ENTRADA = 8192;
constexpr long LEITURA_SEG = 10;
constexpr long ENCAMINHA_SEG = 2;

bool envia_tudo(int fd, const char *p, std::size_t n) {
    while (n > 0) {
        ssize_t w = send(fd, p, n, MSG_NOSIGNAL);
        if (w < 0) {
            if (errno == EINTR) {
                continue;
            }
            return false;
        }
        if (w == 0) {
            return false;
        }
        p += (std::size_t)w;
        n -= (std::size_t)w;
    }
    return true;
}

// Le uma linha terminada em \n (sem o \n), ate max bytes.
// Devolve false em EOF, timeout ou linha longa demais.
bool le_linha(int fd, std::string &fora, std::size_t teto) {
    fora.clear();
    char buf[1024];
    for (;;) {
        ssize_t n = recv(fd, buf, sizeof buf, 0);
        if (n == 0) {
            return false; // EOF: linha incompleta descarta
        }
        if (n < 0) {
            if (errno == EINTR) {
                continue;
            }
            return false; // timeout ou erro: descarta
        }
        if (fora.size() + (std::size_t)n > teto) {
            return false; // passou do teto: descarta
        }
        fora.append(buf, (std::size_t)n);
        std::size_t pos = fora.find('\n');
        if (pos != std::string::npos) {
            fora.resize(pos);
            return true;
        }
    }
}

struct No {
    int porta = 0;
    std::string arquivo_log;
    std::string par; // "host:porta" ou vazio
    std::atomic<long> atraso_ms{0};
    std::atomic<bool> parando{false};
    int ouvinte = -1;
    std::mutex mu;
    std::map<std::string, std::string> dados;  // chave -> valor
    std::map<std::string, std::string> vistos; // id -> valor aplicado
    std::mutex ths_mu;
    std::vector<std::thread> ths;

    bool gravar_log(const std::string &linha) {
        int fd = open(arquivo_log.c_str(), O_RDWR | O_CREAT | O_APPEND, 0600);
        if (fd < 0) {
            return false;
        }
        // Sela a cauda rasgada: se o arquivo nao termina com '\n' (queda no
        // meio de um append anterior), isola o lixo com uma quebra antes do
        // novo registro. Sem isso, o registro colaria no lixo e o replay o
        // descartaria junto — uma unica cauda rasgada engoliria tudo adiante.
        // (O_APPEND garante que cada write cai no fim; o lseek aqui e so leitura.)
        off_t fim = lseek(fd, 0, SEEK_END);
        if (fim < 0) {
            close(fd);
            return false;
        }
        if (fim > 0) {
            if (lseek(fd, -1, SEEK_END) < 0) {
                close(fd);
                return false;
            }
            char ultimo = 0;
            if (read(fd, &ultimo, 1) != 1) {
                close(fd);
                return false;
            }
            if (ultimo != '\n' && write(fd, "\n", 1) != 1) {
                close(fd);
                return false;
            }
        }
        const char *p = linha.c_str();
        std::size_t n = linha.size();
        while (n > 0) {
            ssize_t w = write(fd, p, n);
            if (w < 0) {
                if (errno == EINTR) {
                    continue;
                }
                close(fd);
                return false;
            }
            p += (std::size_t)w;
            n -= (std::size_t)w;
        }
        bool ok = fsync(fd) == 0; // duravel antes de responder
        close(fd);
        return ok;
    }

    void rejogar() {
        FILE *f = fopen(arquivo_log.c_str(), "r");
        if (!f) {
            return; // sem log: no vazio, que e valido
        }
        char *linha = nullptr;
        size_t cap = 0;
        ssize_t n;
        while ((n = getline(&linha, &cap, f)) >= 0) {
            if (n > 0 && linha[n - 1] == '\n') {
                linha[n - 1] = '\0';
            } else {
                continue; // cauda truncada (queda no meio do append): ignora
            }
            // Formato: PUT <id> <chave> <valor>
            std::string s(linha);
            if (s.rfind("PUT ", 0) != 0) {
                continue;
            }
            std::size_t a = 4, b = s.find(' ', a), c = s.find(' ', b == std::string::npos ? b : b + 1);
            if (b == std::string::npos || c == std::string::npos) {
                continue;
            }
            std::string id = s.substr(a, b - a);
            std::string chave = s.substr(b + 1, c - b - 1);
            std::string valor = s.substr(c + 1);
            if (id.empty() || chave.empty()) {
                continue;
            }
            dados[chave] = valor;
            vistos[id] = valor;
        }
        free(linha);
        fclose(f);
    }

    // Responde uma conexao: exatamente uma requisicao e fecha.
    void atender(int fd) {
        struct timeval tv {};
        tv.tv_sec = LEITURA_SEG;
        setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof tv);
        tv.tv_sec = ENCAMINHA_SEG;
        setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof tv);
        std::string linha;
        bool ok = le_linha(fd, linha, MAX_LINHA);
        std::string resp;
        if (!ok) {
            ::close(fd);
            return; // truncado ou lento: descarta sem responder
        }
        // Divide em ate 4 tokens: VERBO id resto (valor pode conter espacos? nao: rejeita).
        std::string verbo, id, resto;
        {
            std::size_t a = linha.find(' ');
            if (a == std::string::npos) {
                verbo = linha;
            } else {
                verbo = linha.substr(0, a);
                std::size_t b = linha.find(' ', a + 1);
                if (b == std::string::npos) {
                    id = linha.substr(a + 1);
                } else {
                    id = linha.substr(a + 1, b - a - 1);
                    resto = linha.substr(b + 1);
                }
            }
        }
        if (!id.empty() && (id.find(' ') != std::string::npos || id.size() > 128)) {
            id.clear(); // id invalido: trata como pedido invalido
        }
        if (id.empty() || (verbo != "PUT" && verbo != "GET")) {
            resp = "ERRO pedido-invalido\n";
            envia_tudo(fd, resp.data(), resp.size());
            ::close(fd);
            return;
        }
        if (verbo == "GET") {
            std::lock_guard<std::mutex> g(mu);
            auto it = dados.find(resto);
            std::string v = it == dados.end() ? "" : it->second;
            resp = "OK " + id + " " + v + "\n";
            envia_tudo(fd, resp.data(), resp.size());
            ::close(fd);
            return;
        }
        // PUT id chave valor... (valor e o resto; sem espacos por contrato)
        std::size_t sp = resto.find(' ');
        if (sp == std::string::npos || resto.find(' ', sp + 1) != std::string::npos) {
            resp = "ERRO form-invalido\n";
            envia_tudo(fd, resp.data(), resp.size());
            ::close(fd);
            return;
        }
        std::string chave = resto.substr(0, sp);
        std::string valor = resto.substr(sp + 1);
        bool repetido = false;
        {
            std::lock_guard<std::mutex> g(mu);
            auto it = vistos.find(id);
            if (it != vistos.end()) {
                resp = "OK-REPETIDO " + id + " " + it->second + "\n";
                repetido = true;
            } else {
                std::string reg = "PUT " + id + " " + chave + " " + valor + "\n";
                if (!gravar_log(reg)) {
                    resp = "ERRO sem-disco\n";
                    envia_tudo(fd, resp.data(), resp.size());
                    ::close(fd);
                    return;
                }
                dados[chave] = valor;
                vistos[id] = valor;
                resp = "OK " + id + " " + valor + "\n";
            }
        }
        if (!repetido) {
            encaminhar(id, chave, valor);
        }
        envia_tudo(fd, resp.data(), resp.size());
        ::close(fd);
    }

    void encaminhar(const std::string &id, const std::string &chave, const std::string &valor) {
        std::string par;
        {
            std::lock_guard<std::mutex> g(mu);
            par = this->par;
        }
        if (par.empty()) {
            return;
        }
        long atraso = atraso_ms.load();
        if (atraso > 0) {
            struct timespec ts {atraso / 1000, (atraso % 1000) * 1000000L};
            nanosleep(&ts, nullptr);
        }
        std::size_t c = par.rfind(':');
        std::string host = par.substr(0, c), porta = par.substr(c + 1);
        int fd = socket(AF_INET, SOCK_STREAM, 0);
        if (fd < 0) {
            return;
        }
        struct timeval tv {};
        tv.tv_sec = ENCAMINHA_SEG;
        setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof tv);
        setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof tv);
        sockaddr_in ad {};
        ad.sin_family = AF_INET;
        ad.sin_port = htons((std::uint16_t)std::stoi(porta));
        if (inet_pton(AF_INET, host.c_str(), &ad.sin_addr) != 1) {
            close(fd);
            return;
        }
        if (connect(fd, (sockaddr *)&ad, sizeof ad) != 0) {
            close(fd); // par fora do ar: degrada, nao trava
            return;
        }
        std::string pedido = "PUT " + id + " " + chave + " " + valor + "\n";
        envia_tudo(fd, pedido.data(), pedido.size());
        char tmp[1024];
        (void)recv(fd, tmp, sizeof tmp, 0); // melhor esforco: resposta ignorada
        close(fd);
    }

    bool servir() {
        ouvinte = socket(AF_INET, SOCK_STREAM, 0);
        if (ouvinte < 0) {
            return false;
        }
        int opt = 1;
        sockaddr_in ad {};
        ad.sin_family = AF_INET;
        ad.sin_port = htons((std::uint16_t)porta);
        ad.sin_addr.s_addr = htonl(INADDR_LOOPBACK);
        if (setsockopt(ouvinte, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof opt) != 0 || bind(ouvinte, (sockaddr *)&ad, sizeof ad) != 0 || listen(ouvinte, 32) != 0) {
            std::perror("listen");
            return false;
        }
        while (!parando.load()) {
            pollfd p {};
            p.fd = ouvinte;
            p.events = POLLIN;
            int r = poll(&p, 1, 100);
            if (r < 0) {
                if (errno == EINTR) {
                    continue;
                }
                return false;
            }
            if (r == 0 || !(p.revents & POLLIN)) {
                continue;
            }
            int fd = accept(ouvinte, nullptr, nullptr);
            if (fd < 0) {
                if (errno == EINTR) {
                    continue;
                }
                if (parando.load()) {
                    break;
                }
                continue;
            }
            std::lock_guard<std::mutex> g(ths_mu);
            ths.emplace_back([this, fd] { atender(fd); });
        }
        return true;
    }

    void parar() {
        parando.store(true);
        if (ouvinte >= 0) {
            // Desbloqueia o accept: shutdown antes do close.
            shutdown(ouvinte, SHUT_RDWR);
            ::close(ouvinte);
            ouvinte = -1;
        }
        std::lock_guard<std::mutex> g(ths_mu);
        for (auto &t : ths) {
            if (t.joinable()) {
                t.join();
            }
        }
        ths.clear();
    }
};

} // namespace

static int conecta(const char *host, int porta, int timeout_seg = 5) {
    int fd = socket(AF_INET, SOCK_STREAM, 0);
    if (fd < 0) {
        return -1;
    }
    struct timeval tv {};
    tv.tv_sec = timeout_seg;
    setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof tv);
    setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof tv);
    sockaddr_in ad {};
    ad.sin_family = AF_INET;
    ad.sin_port = htons((std::uint16_t)porta);
    if (inet_pton(AF_INET, host, &ad.sin_addr) != 1) {
        close(fd);
        return -1;
    }
    if (connect(fd, (sockaddr *)&ad, sizeof ad) != 0) {
        close(fd);
        return -1;
    }
    return fd;
}

// Troca exatamente uma linha; falha fechando o fd.
static std::string pergunta(int fd, const std::string &q) {
    if (!envia_tudo(fd, q.data(), q.size())) {
        close(fd);
        std::fprintf(stderr, "FALHOU: escrita\n");
        std::exit(1);
    }
    shutdown(fd, SHUT_WR); // meia-fechadura: servidor ve EOF apos os bytes
    std::string r;
    char buf[1024];
    for (;;) {
        ssize_t n = recv(fd, buf, sizeof buf, 0);
        if (n == 0) {
            break;
        }
        if (n < 0) {
            if (errno == EINTR) {
                continue;
            }
            std::fprintf(stderr, "FALHOU: leitura errno=%d\n", errno);
            close(fd);
            std::exit(1);
        }
        r.append(buf, (std::size_t)n);
        if (r.size() > 1 << 20) {
            break;
        }
    }
    close(fd);
    return r;
}

static void espera_porta(int porta, int limite_seg = 10) {
    for (int i = 0; i < limite_seg * 10; i++) {
        int fd = conecta("127.0.0.1", porta, 1);
        if (fd >= 0) {
            close(fd);
            return;
        }
        struct timespec ts {0, 100000000L};
        nanosleep(&ts, nullptr);
    }
    std::fprintf(stderr, "FALHOU: porta %d nao abriu\n", porta);
    std::exit(1);
}

static void checa(bool cond, const char *msg) {
    if (!cond) {
        std::fprintf(stderr, "FALHOU: %s\n", msg);
        std::exit(1);
    }
    std::printf("ok: %s\n", msg);
}

int main() {
    char dir[] = "/tmp/aula23b_XXXXXX";
    if (!mkdtemp(dir)) {
        std::perror("mkdtemp");
        return 1;
    }
    std::string loga = std::string(dir) + "/a.log";
    std::string logb = std::string(dir) + "/b.log";
    const int PA = 18093, PB = 18094;

    // Sobe A e B como processos-filhos reais.
    pid_t pa = fork();
    if (pa == 0) {
        No no;
        no.porta = PA;
        no.arquivo_log = loga;
        no.par = "127.0.0.1:18094";
        no.rejogar();
        if (!no.servir()) {
            _exit(3);
        }
        _exit(0);
    }
    pid_t pb = fork();
    if (pb == 0) {
        No no;
        no.porta = PB;
        no.arquivo_log = logb;
        no.par = "127.0.0.1:18093";
        no.rejogar();
        if (!no.servir()) {
            _exit(3);
        }
        _exit(0);
    }
    espera_porta(PA);
    espera_porta(PB);

    // 1-2. Escrita via A replica em B.
    {
        int fd = conecta("127.0.0.1", PA);
        if (fd < 0) {
            std::fprintf(stderr, "FALHOU: conectar A\n");
            return 1;
        }
        std::string r = pergunta(fd, "PUT op1 k1 10\n");
        checa(r == "OK op1 10\n", "escrita responde ok");
    }
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "GET g1 k1\n");
        checa(r == "OK g1 10\n", "leitura no primario");
    }
    {
        int fd = conecta("127.0.0.1", PB);
        std::string r = pergunta(fd, "GET g2 k1\n");
        checa(r == "OK g2 10\n", "replicacao na replica");
    }

    // 3. Duplicata com valor diferente: vale a primeira.
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "PUT op1 k1 999\n");
        checa(r == "OK-REPETIDO op1 10\n", "duplicata detectada");
    }
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "GET g3 k1\n");
        checa(r == "OK g3 10\n", "sem reaplicacao");
    }

    // 4. Truncado: parcial + fechadura; servidor descarta e segue vivo.
    {
        int fd = conecta("127.0.0.1", PA);
        envia_tudo(fd, "PARCIAL", 7);
        shutdown(fd, SHUT_WR);
        char b[64];
        ssize_t n = recv(fd, b, sizeof b, 0);
        checa(n == 0, "truncado descarta com EOF limpo");
        close(fd);
    }
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "PING\n");
        (void)r; // PING nao e comando: servidor responde erro, mas vivo
        // Qualquer resposta (mesmo erro) prova que o servidor segue vivo.
        checa(r == "ERRO pedido-invalido\n", "servidor segue vivo");
    }

    // 5-6. kill -9 na replica; escrita degradada responde.
    if (::kill(pb, SIGKILL) != 0) {
        std::perror("kill");
        return 1;
    }
    int estado = 0;
    waitpid(pb, &estado, 0);
    {
        auto t0 = std::chrono::steady_clock::now();
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "PUT op2 k3 30\n");
        double dt = std::chrono::duration<double>(std::chrono::steady_clock::now() - t0).count();
        checa(r == "OK op2 30\n", "escrita com replica morta responde ok");
        std::printf("ok: degradado responde em %.2fs (sem travar na replica morta)\n", dt);
        if (!(dt < 5.0)) {
            std::fprintf(stderr, "FALHOU: degradado lento demais\n");
            return 1;
        }
    }
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "GET g4 k3\n");
        checa(r == "OK g4 30\n", "dado presente no primario");
    }

    // 7. Cauda truncada no log da replica (simula queda no meio do append).
    {
        int fd = open(logb.c_str(), O_WRONLY | O_APPEND);
        const char *lixo = "{\"id\":\"lixo\"";
        if (fd < 0 || write(fd, lixo, strlen(lixo)) < 0) {
            std::perror("append lixo");
            return 1;
        }
        fsync(fd);
        close(fd);
    }

    // 8. Reinicia B com o MESMO log: replay ignora a cauda.
    pid_t pb2 = fork();
    if (pb2 == 0) {
        No no;
        no.porta = PB;
        no.arquivo_log = logb;
        no.par = "127.0.0.1:18093";
        no.rejogar();
        if (!no.servir()) {
            _exit(3);
        }
        _exit(0);
    }
    espera_porta(PB);
    {
        int fd = conecta("127.0.0.1", PB);
        std::string r = pergunta(fd, "GET g5 k1\n");
        checa(r == "OK g5 10\n", "replay trouxe k1");
    }
    {
        int fd = conecta("127.0.0.1", PB);
        std::string r = pergunta(fd, "GET g6 k3\n");
        checa(r == "OK g6 \n", "k3 ausente antes do reenvio");
    }

    // 9. Reenvio com o MESMO id converge sem duplicar.
    {
        int fd = conecta("127.0.0.1", PB);
        std::string r = pergunta(fd, "PUT op2 k3 30\n");
        checa(r == "OK op2 30\n", "reenvio aceito");
    }
    {
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "GET g7 k3\n");
        checa(r == "OK g7 30\n", "k3 nos dois (A)");
        int fd2 = conecta("127.0.0.1", PB);
        r = pergunta(fd2, "GET g8 k3\n");
        checa(r == "OK g8 30\n", "k3 nos dois (B)");
    }

    // 10. Par lento: 300 ms de atraso, cliente nao trava.
    ::kill(pb2, SIGKILL);
    waitpid(pb2, nullptr, 0);
    pb2 = fork();
    if (pb2 == 0) {
        No no;
        no.porta = PB;
        no.arquivo_log = logb;
        no.par = "127.0.0.1:18093";
        no.atraso_ms.store(300);
        no.rejogar();
        if (!no.servir()) {
            _exit(3);
        }
        _exit(0);
    }
    espera_porta(PB);
    {
        auto t0 = std::chrono::steady_clock::now();
        int fd = conecta("127.0.0.1", PA);
        std::string r = pergunta(fd, "PUT op3 k4 40\n");
        double dt = std::chrono::duration<double>(std::chrono::steady_clock::now() - t0).count();
        checa(r == "OK op3 40\n", "escrita com par lento responde ok");
        std::printf("ok: atraso ok: resposta em %.2fs (lento, sem travar)\n", dt);
        if (!(dt < 5.0 && dt >= 0.3)) {
            std::fprintf(stderr, "FALHOU: atraso fora do esperado\n");
            return 1;
        }
    }
    {
        int fd = conecta("127.0.0.1", PB);
        std::string r = pergunta(fd, "GET g9 k4\n");
        checa(r == "OK g9 40\n", "k4 replicou apesar do atraso");
    }

    // 11. Estado final igual nos dois.
    {
        int fa = conecta("127.0.0.1", PA);
        std::string ra = pergunta(fa, "GET fa k1\n");
        int fb = conecta("127.0.0.1", PB);
        std::string rb = pergunta(fb, "GET fb k1\n");
        checa(ra == "OK fa 10\n" && rb == "OK fb 10\n", "igualdade final k1");
    }
    {
        int fa = conecta("127.0.0.1", PA);
        std::string ra = pergunta(fa, "GET fa k3\n");
        int fb = conecta("127.0.0.1", PB);
        std::string rb = pergunta(fb, "GET fb k3\n");
        checa(ra == "OK fa 30\n" && rb == "OK fb 30\n", "igualdade final k3");
    }
    {
        int fa = conecta("127.0.0.1", PA);
        std::string ra = pergunta(fa, "GET fa k4\n");
        int fb = conecta("127.0.0.1", PB);
        std::string rb = pergunta(fb, "GET fb k4\n");
        checa(ra == "OK fa 40\n" && rb == "OK fb 40\n", "igualdade final k4");
    }

    std::printf("DISTRIBUIDO_OK: replicacao, idempotencia, queda, reinicio, atraso\n");
    ::kill(pa, SIGKILL);
    ::kill(pb2, SIGKILL);
    waitpid(pa, nullptr, 0);
    waitpid(pb2, nullptr, 0);
    // Limpeza do diretorio temporario.
    std::string cmd = std::string("rm -rf ") + dir;
    (void)system(cmd.c_str());
    return 0;
}

### O que o teste prova (rode `./srv23b` e espere `DISTRIBUIDO_OK`)

| Teste | Ataque/defesa | Critério |
| --- | --- | --- |
| Escrita + leitura + réplica | `PUT op1` via A | `OK` nos dois nós (replicação funciona) |
| Duplicata com outro valor | reenvio `op1` com 999 | `OK-REPETIDO op1 10`; `GET` segue 10 (vale a primeira) |
| Truncado | `PARCIAL` + EOF | descarta sem responder; servidor segue vivo (`ERRO` no próximo pedido) |
| Réplica morta | `SIGKILL` em B + `PUT op2` | `OK` em A em < 5 s (degrada, não trava) |
| Cauda rasgada no log | lixo sem `\n` + reinício de B | replay traz `k1`, ignora a cauda; `k3` ausente (nunca chegou a B) |
| Reenvio com mesmo id | `PUT op2` direto em B | aceito uma vez; converge nos dois sem duplicar |
| Par lento | 300 ms de atraso em B | resposta em ~0,3 s (lento, sem travar); `k4` replica |
| Igualdade final | `GET` das 3 chaves nos 2 nós | mesmos valores nos dois (convergência) |

### O que a memória e os processos fazem aqui

Duas verdades separadas: cada nó é um processo (`fork`), com seu `map` e seu log — nada é compartilhado entre A e B. Dentro de um nó, uma thread por conexão divide `dados` e `vistos` sob um `mutex`; o atraso injetado é `atomic` porque o teste o ajusta entre reinícios. `fork` + `SIGKILL` não é teatro: é a queda que o SO entrega, com log pela metade e tudo. O preço da durabilidade é um `fsync` por escrita — este nó troca vazão por sobrevivência, e diz isso abertamente.

## 4. Erros comuns e implicações defensivas

1. **Reenviar sem chave de idempotência:** sem `id`, repetição vira segunda aplicação. O `id` não é metadado — é o que separa "de novo" de "duplo".
2. **Responder antes do `fsync`:** `write` retornou, queda veio, dado sumiu, cliente já ouviu `OK`. A ordem é persistir, aplicar, responder — nunca o inverso.
3. **Anexar sobre cauda rasgada:** sem o selo, o registro novo cola no lixo e o replay perde os dois. Uma linha de defesa (`ultimo != '\n'`) protege todos os registros futuros.
4. **`read` em fd `O_WRONLY`:** o selo precisa ler o último byte; abrir só-escrita devolve `EBADF` e o servidor responde `ERRO sem-disco` para escrita saudável. Abrir `O_RDWR` não é detalhe — é o que o selo exige.
5. **Encaminhar sem timeout:** par lento sem teto de espera transforma queda alheia em travamento próprio. 2 s aqui; estouro é degradação, não erro.
6. **Achar que réplica é backup:** réplica recebe as mesmas escritas pelo fio, com atraso e repetição. Quem não testa reenvio e reinício tem duas cópias divergentes, não redundância.

## 5. Ponte com as demais trilhas

Go faz o mesmo com `net.Conn`, deadlines e `fsync` por append (aulas G5/G6, teste com falhas injetadas); Python conta com `socket`, threads e o mesmo protocolo de linha (aula PY7: falhas parciais, idempotência, recuperação). Em todas: id por operação, persistir antes de responder, replay que descarta cauda, reenvio que converge. Compare os três fios byte a byte — o protocolo é o mesmo, só a roupa muda.
