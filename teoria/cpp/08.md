# Aula 8 - `std::string`, containers da STL, iteradores e algoritmos

---

## Objetivo da Aula

Entender como `std::string`, containers da STL, iteradores e algoritmos trabalham juntos em C++ moderno, e por que essa combinacao substitui grande parte da infraestrutura manual que em C seria reescrita o tempo todo. ## 2. `std::string`

`std::string` representa string de tamanho variavel com gerenciamento automatico de memoria.

Exemplo:

```cpp
std::string nome = "C++";
```

### 2.1 Por que isso importa?

Porque em C a historia costuma envolver:

- `char*`
- `malloc`
- `free`
- buffer fixo
- risco de overflow

Em C++, `std::string` encapsula boa parte disso com RAII.

### 2.2 O que ela nao faz?

Nao transforma strings em algo sem custo.

Ainda existem:

- alocacoes;
- copias;
- movimentos;
- crescimento;

Mas o contrato e muito melhor.

---

## 3. `std::vector`

`std::vector<T>` e o container sequencial dinamico mais importante do ecossistema C++.

Exemplo:

```cpp
std::vector<int> v = {1, 2, 3};
```

### 3.1 O que ele oferece?

- crescimento dinamico;
- armazenamento contiguo;
- acesso por indice;
- bom suporte a cache;
- integracao com algoritmos da STL.

### 3.2 Comparacao com C

Em C, um vetor dinamico costuma significar:

- ponteiro;
- capacidade;
- tamanho;
- `malloc`/`realloc`/`free`;
- muito contrato manual.

Em C++, `std::vector` oferece isso como tipo pronto e seguro dentro do razoavel.

## 5. Iteradores

Iterador e um objeto que representa uma posicao em uma sequencia.

Pense nele como uma abstracao de:

- "ponteiro generalizado para percorrer container"

Exemplo:

```cpp
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << "\n";
}
```

### 5.1 Por que isso existe?

Porque algoritmos da STL nao querem conhecer todos os containers concretos.

Eles querem operar sobre:

- intervalos definidos por iteradores

---

## 6. Range-based for

Forma idiomatica comum:

```cpp
for (int x : v) {
    std::cout << x << "\n";
}
```

ou:

```cpp
for (const auto& s : nomes) {
    std::cout << s << "\n";
}
```

### 6.1 Quando usar?

Quando voce quer:

- percorrer elementos;
- sem precisar lidar diretamente com iterador;
- sem precisar de indice.

### 6.2 Cuidado

`auto x` copia.

`auto& x` referencia mutavel.

`const auto& x` referencia de leitura.

Isso importa.

---

## 7. Algoritmos da STL

Em vez de escrever loop manual para tudo, C++ oferece algoritmos como:

- `std::sort`
- `std::find`
- `std::count`
- `std::for_each`
- `std::reverse`

Exemplo:

```cpp
std::sort(v.begin(), v.end());
```

### 7.1 Ideia central

Separar:

- estrutura de dados

de:

- operacao generica

Esse desacoplamento e uma das forcas de C++.

## 8. Exemplo completo da aula

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::string titulo = "cpp moderno";
    std::vector<std::string> palavras = {"templates", "raii", "stl", "algoritmos"};

    std::cout << "titulo: " << titulo << "\n";
    std::cout << "tamanho do titulo: " << titulo.size() << "\n";

    palavras.push_back("iteradores");
    palavras.push_back("containers");

    std::cout << "antes da ordenacao:\n";
    for (const auto& palavra : palavras) {
        std::cout << "- " << palavra << "\n";
    }

    std::sort(palavras.begin(), palavras.end());

    std::cout << "depois da ordenacao:\n";
    for (const auto& palavra : palavras) {
        std::cout << "- " << palavra << "\n";
    }

    auto it = std::find(palavras.begin(), palavras.end(), std::string("raii"));
    if (it != palavras.end()) {
        std::cout << "encontrei: " << *it << "\n";
    } else {
        std::cout << "nao encontrei raii\n";
    }

    std::vector<int> numeros = {5, 1, 9, 3, 1, 7};

    std::cout << "numeros originais:\n";
    for (int n : numeros) {
        std::cout << n << " ";
    }
    std::cout << "\n";

    std::sort(numeros.begin(), numeros.end());

    std::cout << "numeros ordenados:\n";
    for (int n : numeros) {
        std::cout << n << " ";
    }
    std::cout << "\n";

    int qtd_uns = std::count(numeros.begin(), numeros.end(), 1);
    std::cout << "quantidade de 1: " << qtd_uns << "\n";

    return 0;
}
```

---

## 9. O que esse exemplo mostra?

### 9.1 `std::string`

Mostra:

- armazenamento de texto;
- consulta de tamanho;
- integracao natural com `std::cout`

### 9.2 `std::vector<std::string>`

Mostra:

- container homogeneo;
- crescimento com `push_back`

### 9.3 `std::sort`

Mostra:

- algoritmo generico operando sobre iteradores

### 9.4 `std::find` e `std::count`

Mostram:

- busca e contagem sem loop manual explicito

## 10. O que acontece em memoria?

`std::vector` tipicamente mantem:

- ponteiro para dados;
- tamanho;
- capacidade;

e os elementos costumam ficar contiguos no heap quando o container cresce.

`std::string` tambem administra memoria dinamica, embora implementacoes possam usar otimizacoes internas.

### 10.1 O ponto essencial

Esses tipos nao eliminam custo.

Eles:

- organizam ownership;
- encapsulam alocacao;
- oferecem contratos melhores;
- reduzem erro manual.

### 10.2 Ligacao com a Aula 5

Esses containers sao exemplos fortissimos de:

- regra dos 0

Voce compoe com eles e evita reimplementar lifetime manual.

## 11. Indice vs iterador vs range-based for

### 11.1 Indice

Bom quando:

- o container suporta acesso por indice;
- voce realmente precisa da posicao.

### 11.2 Iterador

Bom quando:

- quer trabalhar do jeito generico da STL;
- quer passar intervalo para algoritmo.

### 11.3 Range-based for

Bom quando:

- so quer percorrer os elementos de forma clara.

---

## 12. Quando nao reinventar a roda

Se voce precisa:

- ordenar;
- procurar;
- contar;
- inverter;

verifique primeiro se ja existe algoritmo pronto.

Em C++ idiomatico, escrever loop manual para tudo costuma indicar que voce ainda nao internalizou bem a STL.

---

## 13. Comparacao com C, Rust, Go e Python

- Em C, `std::string` e `std::vector` nao existem; muito disso vira infraestrutura manual.
- Em Rust, `String` e `Vec<T>` cumprem papeis semelhantes, tambem com ownership e generics fortes.
- Em Go, slices e strings existem com outro modelo semantico e outra ergonomia.
- Em Python, listas e strings sao muito mais simples de usar no comeco, mas com custo e modelo interno menos expostos.

C++ moderno quer te levar a:

- reusar tipos da biblioteca padrao;
- combinar containers e algoritmos;
- evitar gestao manual desnecessaria.

## 15. Erros comuns e anti-padroes

1. **Escrever arrays crus e loops manuais para tudo sem necessidade**.
2. **Usar `auto` em range-based for e copiar elementos sem perceber**.
3. **Esquecer que `std::vector` pode realocar ao crescer**.
4. **Achar que `std::string` torna custo de texto irrelevante**.
5. **Reimplementar ordenacao e busca basica antes de olhar `std::algorithm`**.
6. **Usar `std::list` cedo demais sem motivo concreto**.
