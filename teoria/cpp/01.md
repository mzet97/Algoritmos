## 1. O que e C++?

C++ e uma linguagem de programacao compilada, de uso geral, com foco historico em:

- desempenho;
- controle de memoria e layout;
- abstracoes de custo previsivel;
- software de infraestrutura;
- engines, bibliotecas, sistemas, backend e codigo proximo do hardware.

Ela nasceu como extensao de C, mas hoje e uma linguagem propria, com:

- sistema de tipos mais rico;
- funcoes e sobrecarga;
- classes;
- templates;
- RAII;
- biblioteca padrao extensa;
- ferramentas para generics, concorrencia e software moderno.

### 1.1 C++ e "C com classes"?

Historicamente isso ajuda a entender a origem.

Tecnicamente, hoje isso e insuficiente.

C++ moderno inclui ideias que vao muito alem de C:

- referencias;
- sobrecarga;
- construtores e destrutores;
- move semantics;
- templates;
- lambdas;
- exceptions;
- STL;
- coroutines em contextos mais avancados.

### 1.2 Comparacao inicial com C, Rust, Go e Python

- Em C, muito do que em C++ vira tipo, construtor e RAII ainda precisa ser feito manualmente.
- Em Rust, ownership e borrow checking sao mais rigorosos e verificados pelo compilador de outro jeito.
- Em Go, a linguagem e menor e o runtime assume mais responsabilidades.
- Em Python, a ergonomia inicial e maior, mas o controle fino de layout, lifetime e custo e muito menor.

## 2. Compilacao: o programa nao nasce pronto

Em C++, voce escreve codigo fonte em arquivos como:

- `main.cpp`
- `app.cpp`
- `exemplo.cpp`

Depois um compilador como `g++` ou `clang++` transforma isso em binario executavel.

### 2.1 Ferramentas que vamos usar

- `g++`
- `clang++`
- `gdb`
- sanitizers
- `make` ou `cmake` quando o projeto crescer

### 2.2 Flags importantes desde ja

- `-std=c++20`: escolhe a versao da linguagem
- `-Wall`: liga varios warnings uteis
- `-Wextra`: liga warnings adicionais
- `-Wpedantic`: sinaliza trechos pouco portaveis ou estranhos
- `-O0`: sem otimizacao, bom para aprendizado e debug
- `-O2`: baseline otimizado comum
- `-g`: inclui informacao de debug

### 2.3 Regra pratica

Para estudar e depurar no comeco, um baseline excelente e:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic -O0 -g main.cpp -o main
```

ou:

```bash
clang++ -std=c++20 -Wall -Wextra -Wpedantic -O0 -g main.cpp -o main
```

## 3. Estrutura minima de um programa C++

Exemplo:

```cpp
#include <iostream>

int main() {
    std::cout << "Ola, C++!\n";
    return 0;
}
```

Vamos desmontar isso com calma.

### 3.1 `#include <iostream>`

Isso pede acesso ao header da biblioteca padrao que declara facilidades de entrada e saida por stream, incluindo `std::cout`.

- `#include` faz parte do preprocessor
- o preprocessor roda antes da compilacao propriamente dita
- ele ajuda a montar a translation unit que sera compilada

### 3.2 `int main()`

`main` e o ponto de entrada do programa.

Quando o processo comeca, o ambiente de execucao eventualmente chama `main`.

- o retorno `int` indica um codigo de saida
- `0` costuma significar sucesso
- diferente de `0` costuma significar erro

### 3.3 `std::cout`

`std::cout` e um objeto global da biblioteca padrao usado para escrita em saida padrao.

- `std` e o namespace da biblioteca padrao
- `cout` e um stream de saida

### 3.4 `<<`

Nesse contexto, `<<` nao e "deslocamento de bits".

Aqui ele esta sendo usado como operador de insercao em stream:

- empurra dados para `std::cout`

### 3.5 `return 0;`

Indica sucesso ao sistema operacional.

## 4. Exemplo completo da aula

```cpp
#include <iostream>

int main() {
    int idade = 34;
    double altura = 1.78;
    char inicial = 'A';
    bool gosta_de_cpp = true;

    std::cout << "Idade: " << idade << "\n";
    std::cout << "Altura: " << altura << "\n";
    std::cout << "Inicial: " << inicial << "\n";
    std::cout << "Gosta de C++: " << gosta_de_cpp << "\n";

    return 0;
}
```

---

## 5. Explicacao conceitual do exemplo

Esse programa ja mostra varias coisas importantes:

- declaracao de variaveis;
- tipos basicos;
- inicializacao;
- escrita em `stdout`;
- custo operacional simples e visivel.

### 5.1 `int idade = 34;`

- `int` representa inteiro
- `idade` e o nome da variavel
- `34` e o valor inicial

### 5.2 `double altura = 1.78;`

- `double` representa numero de ponto flutuante em dupla precisao
- serve para valores fracionarios aproximados

### 5.3 `char inicial = 'A';`

- `char` representa um byte interpretado como caractere ou pequeno inteiro
- aspas simples indicam um caractere

### 5.4 `bool gosta_de_cpp = true;`

- `bool` representa verdadeiro ou falso
- `true` e `false` sao palavras da linguagem

### 5.5 O que vai para a memoria?

Conceitualmente, essas variaveis locais ficam na stack frame de `main`.

Ou seja:

- sao criadas ao entrar em `main`
- deixam de existir ao sair de `main`

Isso importa muito em C++ porque, mais tarde, objetos com destrutores tambem vao morrer nesse momento.

## 6. Tipos basicos iniciais: tamanho e limites

Os tipos abaixo aparecem o tempo todo no comeco. Valores da maquina de referencia (Linux x86-64, LP64); `long` e `char` variam por plataforma — meça sempre com `sizeof` e `<limits>`:

| Tipo | `sizeof` aqui | Minimo | Maximo |
|---|---|---|---|
| `int` | 4 bytes | -2147483648 | 2147483647 |
| `double` | 8 bytes | ~-1.8e308 | ~1.8e308 |
| `char` | 1 byte | -128 (aqui, com sinal) ou 0 | 127 ou 255 |
| `bool` | 1 byte | `false` | `true` |

Tabela completa com `short`, `long`, `long long`, `unsigned` e `float` na [Aula 2](02.md).

### 6.1 `int`

Bom para contadores, indices e inteiros em geral. Aqui: 4 bytes, de -2147483648 a 2147483647.

### 6.2 `double`

Bom para calculos com casas decimais quando precisao maior e importante. Aqui: 8 bytes, IEEE 754 dupla precisao, ate ~1.8e308.

### 6.3 `char`

Um unico byte (por definicao da linguagem).

Pode representar:

- caractere textual simples;
- pequeno valor numerico (-128 a 127 ou 0 a 255, conforme o sinal de `char` na plataforma).

### 6.4 `bool`

Representa:

- `true`
- `false`

Ocupa 1 byte.

## 7. `std::cout` nao e `printf`

Em C, voce provavelmente veria:

```c
printf("idade=%d\n", idade);
```

Em C++, uma forma idiomatica inicial costuma ser:

```cpp
std::cout << "idade=" << idade << "\n";
```

### 7.1 Diferenca conceitual

- `printf` e uma funcao variadica baseada em string de formato
- `std::cout` usa streams e sobrecarga de operadores

### 7.2 Comparacao com outras linguagens

- Em C, `printf` e mais manual e sujeito a erro de formato.
- Em Rust, `println!` usa macro com checagens melhores.
- Em Go, `fmt.Println` e funcao de mais alto nivel.
- Em Python, `print()` e dinamico e muito mais permissivo.

## 8. Compilando e rodando

Suponha o arquivo `main.cpp`.

Compilar com `g++`:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic -O0 -g main.cpp -o main
```

Compilar com `clang++`:

```bash
clang++ -std=c++20 -Wall -Wextra -Wpedantic -O0 -g main.cpp -o main
```

Rodar em Unix-like:

```bash
./main
```

No Windows, dependendo do ambiente:

```bash
main.exe
```

### 8.1 Por que usar warnings ja no primeiro dia?

Porque em C++ erro logico e comportamento estranho podem ficar caros rapidamente.

Warnings fortes ajudam a:

- detectar conversoes suspeitas;
- detectar variaveis nao usadas;
- detectar padroes ruins cedo.

## 9. O que o compilador faz em alto nivel?

Modelo mental simplificado:

1. preprocessor expande includes e macros
2. compilador analisa e traduz o codigo
3. assembler gera codigo de maquina intermediario
4. linker monta o executavel final

Hoje isso basta como visao inicial.

Mais tarde vamos detalhar:

- headers
- translation units
- linkagem
- ABI

## 10. Erros comuns de iniciante

1. **Esquecer `#include <iostream>` ao usar `std::cout`**.
2. **Esquecer `;` no final de uma instrucao**.
3. **Confundir `"` com `'`**.
4. **Tentar usar `cout` sem `std::`**.
5. **Compilar sem `-std=c++20` e estranhar erros em codigo moderno**.
6. **Tratar `std::cout` como se fosse exatamente igual a `printf`**.

## 11. Comparacao com C, Rust, Go e Python

- Em C, o programa minimo costuma usar `printf` e a biblioteca padrao de C; em C++ o ecossistema inicial tende a passar por `iostream`.
- Em Rust, o `main` tambem e ponto de entrada, mas a ergonomia de output e diferente e o sistema de tipos e ownership aparece cedo.
- Em Go, o binario tambem e compilado, mas a linguagem e mais enxuta e o runtime assume varias responsabilidades.
- Em Python, nao ha etapa de compilacao do mesmo tipo no fluxo do usuario iniciante, o que reduz atrito inicial e tambem esconde varias camadas.

Em C++, desde a Aula 1, queremos formar habito de:

- compilar conscientemente;
- olhar warnings;
- entender o que o binario esta fazendo;
- pensar em memoria e lifetime.
