# Aula 9 - Lambdas, functors, `std::function`, callbacks e callable objects

Passar comportamento como valor — lambda, functor, callback — é o que transforma código rígido em código componível. Esta aula mostra o custo real de cada forma de callável, para você escolher sem superstição.

---

## Nesta aula

Entender como C++ representa comportamento como valor, usando lambdas, functors, ponteiros para funcao e `std::function`, e como isso permite callbacks e algoritmos flexiveis. Você vai aprender a parametrizar um algoritmo com lambda, functor e `std::function`; medir a diferenca de custo entre estatico e apagado; e explicar quando cada um paga.

## 2. O que e um callable?

Em C++, callable e qualquer coisa que pode ser "chamada" como funcao.

Exemplos:

- funcao livre;
- lambda;
- objeto com `operator()`;
- ponteiro para funcao;
- certos wrappers como `std::function`.

### 2.1 Por que isso importa?

Porque C++ permite parametrizar comportamento, nao apenas dados.

---

## 3. Funcao livre como callback

Exemplo:

```cpp
int dobro(int x) {
    return x * 2;
}
```

E uma API simples:

```cpp
int aplicar(int x, int (*f)(int)) {
    return f(x);
}
```

Uso:

```cpp
aplicar(10, dobro);
```

### 3.1 Limitacao

Ponteiro de funcao cru e simples, mas pouco flexivel para estado capturado.

---

## 4. Functor

Functor e um objeto que implementa `operator()`.

Exemplo:

```cpp
struct Multiplicador {
    int fator;

    int operator()(int x) const {
        return x * fator;
    }
};
```

Uso:

```cpp
Multiplicador m{3};
int y = m(10);
```

### 4.1 O que isso compra?

- comportamento com estado;
- tipo proprio;
- possibilidade de inline e otimizacao forte;
- uso natural com templates.

---

## 5. Lambda

Lambda e uma forma compacta de criar um objeto callable anonimo.

Exemplo:

```cpp
auto dobro = [](int x) {
    return x * 2;
};
```

Uso:

```cpp
std::cout << dobro(5) << "\n";
```

### 5.1 O que a lambda realmente e?

Conceitualmente:

- um objeto gerado pelo compilador com `operator()`

Ou seja:

- ela se parece mais com um functor anonimo do que com "funcao magica".

---

## 6. Captura em lambdas

Lambdas podem capturar nomes do escopo externo.

Exemplo:

```cpp
int fator = 4;
auto mult = [fator](int x) {
    return x * fator;
};
```

### 6.1 Captura por valor

`[fator]` significa:

- copie `fator` para dentro da lambda

### 6.2 Captura por referencia

```cpp
int total = 0;
auto acumular = [&total](int x) {
    total += x;
};
```

Aqui:

- a lambda referencia a variavel externa

### 6.3 Cuidado

Capturar por referencia exige cuidado com lifetime.

Se a lambda sobreviver mais do que a variavel capturada:

- problema serio.

---

## 7. `std::function`

`std::function` e um wrapper polimorfico para callables compativeis com certa assinatura.

Exemplo:

```cpp
#include <functional>

std::function<int(int)> f;
```

Ele pode receber:

- funcao livre;
- lambda;
- functor.

### 7.1 Por que isso existe?

Para armazenar e passar comportamento com interface uniforme.

### 7.2 Qual o custo?

Mais flexibilidade geralmente implica:

- mais indirecao;
- possivel alocacao;
- menos oportunidade de otimizacao do que template puro.

---

## 8. Quando usar template e quando usar `std::function`?

### 8.1 Template

Bom quando:

- o callable e conhecido em compilacao;
- voce quer mais desempenho;
- quer mais chance de inline;
- aceita gerar mais codigo por instanciacao.

### 8.2 `std::function`

Bom quando:

- precisa armazenar callables heterogeneos sob mesma assinatura;
- quer interface uniforme em runtime;
- custo extra e aceitavel.

## 9. Exemplo completo da aula

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

int aplicar_funcao(int x, int (*f)(int)) {
    return f(x);
}

int quadrado(int x) {
    return x * x;
}

struct Multiplicador {
    int fator;

    int operator()(int x) const {
        return x * fator;
    }
};

void processar(const std::vector<int>& valores,
               const std::function<void(int)>& callback) {
    for (int v : valores) {
        callback(v);
    }
}

int main() {
    std::cout << "ponteiro de funcao: "
              << aplicar_funcao(5, quadrado) << "\n";

    Multiplicador mult{3};
    std::cout << "functor: " << mult(5) << "\n";

    auto soma_dois = [](int x) {
        return x + 2;
    };
    std::cout << "lambda simples: " << soma_dois(5) << "\n";

    int total = 0;
    auto acumular = [&total](int x) {
        total += x;
    };

    std::vector<int> valores = {4, 1, 7, 3, 2};

    std::sort(valores.begin(), valores.end(), [](int a, int b) {
        return a > b;
    });

    std::cout << "ordenado desc:\n";
    for (int v : valores) {
        std::cout << v << " ";
    }
    std::cout << "\n";

    processar(valores, acumular);
    std::cout << "total: " << total << "\n";

    processar(valores, [](int x) {
        std::cout << "valor: " << x << "\n";
    });

    return 0;
}
```

---

## 10. O que esse exemplo mostra?

### 10.1 Ponteiro de funcao

Simples e direto, mas sem captura de estado.

### 10.2 Functor

Comporta:

- estado (`fator`)
- chamada natural com `operator()`

### 10.3 Lambda

Forma compacta de declarar comportamento local.

### 10.4 Lambda em `std::sort`

Mostra um caso real muito comum:

- passar criterio customizado para algoritmo da STL

### 10.5 `std::function`

Permite que `processar` aceite varios tipos de callback sob mesma assinatura observavel.

---

## 11. O que acontece em memoria?

Uma lambda sem captura costuma ser extremamente leve.

Uma lambda com captura e um objeto com campos internos correspondentes ao que foi capturado.

Functor tambem e objeto normal com estado.

`std::function` pode:

- armazenar callable internamente;
- usar alocacao em alguns casos;
- fazer type erasure para esconder o tipo concreto.

### 11.1 O ponto essencial

Passar comportamento em C++ nao e "feitico funcional".

E modelagem de objeto, tipo e custo.

## 12. Captura por valor vs por referencia

Exemplo:

```cpp
int x = 10;
auto a = [x]() { return x; };
auto b = [&x]() { return x; };
```

### 12.1 `a`

- guarda copia de `x`

### 12.2 `b`

- referencia `x` externo

### 12.3 Regra pratica

Prefira captura por valor quando:

- a lambda nao precisa modificar o externo;
- lifetime independente ajuda;
- custo da copia e razoavel.

Use captura por referencia quando:

- precisa afetar estado externo;
- o lifetime esta claramente controlado.

---

## 13. Comparacao com C, Rust, Go e Python

- Em C, callbacks tipicamente giram em torno de ponteiros de funcao e, se houver estado, isso costuma exigir ponteiro de contexto separado.
- Em Rust, closures lembram muito lambdas com regras de captura bem formalizadas pelo sistema de ownership.
- Em Go, funcoes de primeira classe tambem existem, com closures em outro modelo de runtime.
- Em Python, funcoes e lambdas sao bem naturais, mas custo e checagem estatica seguem outra historia.

C++ junta:

- alto desempenho;
- callables tipados;
- lambdas;
- templates;
- wrappers dinamicos quando necessario.

## 15. Erros comuns e anti-padroes

1. **Usar `std::function` em todo lugar sem pensar no custo**.
2. **Capturar por referencia e esquecer lifetime do dado externo**.
3. **Achar que lambda e "funcao magica" e nao um objeto callable**.
4. **Usar functor ou lambda sem clareza sobre estado capturado**.
5. **Escolher ponteiro de funcao quando precisava de estado associado**.
6. **Esconder demais a logica em lambdas grandes e ilegiveis**.
