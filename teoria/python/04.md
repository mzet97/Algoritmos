# Aula 4 - Strings, listas, tuplas, dicionarios e conjuntos

String imutável, lista mutável, tupla, dicionário e conjunto: as quatro formas de guardar dados em Python parecem intercambiáveis até o primeiro bug de aliasing ou de chave. Cada uma tem um contrato; esta aula lê os quatro.

---

## Nesta aula

Dominar as principais estruturas de dados builtin de Python, entender quando usar `str`, `list`, `tuple`, `dict` e `set`, conhecer operacoes fundamentais, custos conceituais e as diferencas de mutabilidade entre essas estruturas.

Você vai aprender a usar strings, listas, tuplas, dicionários e conjuntos, escolher a estrutura pelo padrão de acesso, e prever custo e erro típico de cada uma.

---

## 1. Visao geral

As colecoes builtin de Python resolvem a maior parte dos problemas comuns sem que voce precise implementar estruturas de dados na mao.

Cada uma existe por uma razao:

- `str`: representar texto;
- `list`: sequencia mutavel ordenada;
- `tuple`: sequencia imutavel ordenada;
- `dict`: mapa chave -> valor;
- `set`: conjunto sem repeticao.

Se voce aprende a escolher a colecao certa, muito codigo ruim simplesmente deixa de existir.

---

## 2. Strings (`str`)

### 2.1 O que e uma string?

Uma string e um objeto imutavel que representa texto Unicode.

```python
nome = "Python"
print(nome)
print(type(nome))
```

### 2.2 Indexacao e slicing

```python
texto = "python"

print(texto[0])   # p
print(texto[1])   # y
print(texto[-1])  # n
print(texto[1:4]) # yth
```

Termos importantes:

- **Indexacao**: acesso a um elemento por posicao.
- **Slice**: recorte de uma sequencia.

### 2.3 Strings sao imutaveis

```python
texto = "python"
# texto[0] = "P"   # TypeError
```

Para "alterar" uma string, voce cria outra:

```python
texto = "python"
texto = "P" + texto[1:]
print(texto)
```

### 2.4 Metodos comuns

```python
frase = "  Ola Mundo  "

print(frase.lower())
print(frase.upper())
print(frase.strip())
print(frase.replace("Mundo", "Python"))
print("a,b,c".split(","))
print("-".join(["2026", "04", "22"]))
```

**Observacao de performance:** concatenar muitas strings com `+` dentro de loop pode ser ruim; normalmente `''.join(...)` e a abordagem melhor quando ha muitas partes.

## 3. Listas (`list`)

### 3.1 O que e uma lista?

Lista e uma sequencia mutavel e ordenada.

```python
numeros = [10, 20, 30]
print(numeros)
print(type(numeros))
```

### 3.2 Operacoes basicas

```python
numeros = [10, 20, 30]

print(numeros[0])
print(numeros[-1])

numeros.append(40)
print(numeros)

numeros.insert(1, 15)
print(numeros)

removido = numeros.pop()
print(removido)
print(numeros)
```

### 3.3 Alteracao em lugar

```python
valores = [1, 2, 3]
valores[0] = 999
print(valores)
```

### 3.4 Listas podem ser heterogeneas, mas cuidado

```python
dados = [10, "ana", True, 3.14]
print(dados)
```

Python permite isso, mas em codigo serio normalmente voce quer alguma regularidade estrutural. Liberdade demais tambem pode virar desordem.

### 3.5 Slicing em listas

```python
numeros = [0, 1, 2, 3, 4, 5]

print(numeros[1:4])
print(numeros[:3])
print(numeros[3:])
print(numeros[::2])
print(numeros[::-1])
```

### 3.6 Custo conceitual

Conceitualmente:

- acesso por indice: rapido;
- `append` no fim: normalmente eficiente;
- inserir/remover no meio: mais caro, porque pode exigir deslocamento interno.

**Comparacao:**

- parecido com `std::vector` de C++;
- parecido com `Vec<T>` de Rust;
- nao e lista ligada.

## 4. Tuplas (`tuple`)

### 4.1 O que e uma tupla?

Tupla e uma sequencia ordenada e imutavel.

```python
ponto = (10, 20)
print(ponto)
print(type(ponto))
```

### 4.2 Sintaxe importante

```python
t = (1, 2, 3)
u = 1, 2, 3
v = (42,)
```

O caso de um elemento exige virgula. Sem ela, o Python interpreta apenas o valor entre parenteses.

### 4.3 Desempacotamento

```python
coordenada = (100, 200)
x, y = coordenada

print(x)
print(y)
```

- **Desempacotamento**: extrair os elementos de uma sequencia para nomes distintos.

### 4.4 Quando usar tuple?

Use quando:

- a estrutura tem tamanho fixo;
- a ordem importa;
- a intencao e semantica de "registro pequeno";
- voce quer imutabilidade sem criar uma classe ainda.

---

## 5. Dicionarios (`dict`)

### 5.1 O que e um dicionario?

Dicionario e uma estrutura de mapeamento chave -> valor.

```python
usuario = {
    "nome": "Ana",
    "idade": 30,
    "ativo": True,
}

print(usuario)
print(type(usuario))
```

### 5.2 Acesso e atualizacao

```python
print(usuario["nome"])

usuario["idade"] = 31
usuario["cidade"] = "Recife"

print(usuario)
```

### 5.3 `get()`

```python
print(usuario.get("email"))
print(usuario.get("email", "nao informado"))
```

Usar `get()` evita `KeyError` quando a chave pode nao existir.

### 5.4 Iteracao

```python
for chave in usuario:
    print(chave)

for chave, valor in usuario.items():
    print(chave, valor)
```

### 5.5 O que existe por baixo?

Conceitualmente, `dict` e baseado em **hash table**.

- **Hash table**: estrutura que usa uma funcao hash para mapear chaves a posicoes internas, permitindo acesso medio muito rapido.
- **Hash**: valor numerico derivado da chave, usado para distribuicao interna.

**Comparacao:**

- C++: `std::unordered_map`
- Rust: `HashMap<K, V>`
- Python: `dict`

## 6. Conjuntos (`set`)

### 6.1 O que e um set?

`set` representa um conjunto de elementos unicos, sem ordem conceitual relevante para a logica do problema.

```python
valores = {1, 2, 3}
print(valores)
print(type(valores))
```

### 6.2 Remocao de duplicatas

```python
numeros = [1, 1, 2, 3, 3, 4]
unicos = set(numeros)
print(unicos)
```

### 6.3 Operacoes matematicas

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # uniao
print(a & b)  # intersecao
print(a - b)  # diferenca
print(a ^ b)  # diferenca simetrica
```

Sets sao excelentes para testes de pertencimento rapido:

```python
permitidos = {"admin", "dev", "ops"}
print("dev" in permitidos)
```

## 7. Escolhendo a estrutura certa

### 7.1 Resumo de uso

| Estrutura | Use quando | Mutavel |
|-----------|------------|---------|
| `str` | Texto | Nao |
| `list` | Sequencia editavel | Sim |
| `tuple` | Sequencia fixa | Nao |
| `dict` | Associacao chave -> valor | Sim |
| `set` | Unicidade e pertencimento | Sim |

### 7.2 Perguntas praticas

- Preciso representar texto? `str`
- Preciso de ordem e alteracao? `list`
- Preciso de ordem fixa e imutabilidade? `tuple`
- Preciso consultar por chave? `dict`
- Preciso evitar repetidos ou testar pertencimento rapido? `set`

## 8. Exemplo completo da aula

```python
nome = "Python"
print(nome[0])
print(nome.lower())

linguagens = ["Python", "Rust", "C++"]
linguagens.append("Go")
print(linguagens)

coordenada = (10, 20)
x, y = coordenada
print(x, y)

usuario = {
    "nome": "Marina",
    "idade": 28,
    "skills": ["Python", "SQL"],
}

print(usuario["nome"])
print(usuario.get("email", "sem email"))

tags = {"backend", "python", "backend", "api"}
print(tags)
print("python" in tags)
```

### Explicacao linha por linha

- `nome[0]`: acessa o primeiro caractere da string.
- `nome.lower()`: retorna nova string em minusculas.
- `linguagens.append("Go")`: altera a lista existente.
- `x, y = coordenada`: desempacota a tupla.
- `usuario["nome"]`: acessa valor pela chave.
- `usuario.get("email", ...)`: faz consulta segura com valor padrao.
- `tags = {...}`: cria conjunto de valores unicos.

## 10. Erros Comuns e Anti-Padroes

1. **Tentar alterar caractere de string por indice**: `str` e imutavel.
2. **Usar lista quando a logica pede dicionario**: isso piora busca e clareza.
3. **Usar tupla e depois tentar editar**: tupla foi feita para nao mudar.
4. **Acessar chave opcional com `dict["chave"]` sem verificar existencia**: pode gerar `KeyError`.
5. **Achar que set preserva ordem sem necessidade semantica**: nao modele sua logica confiando nisso.
6. **Usar lista para testes repetidos de pertencimento em grande volume quando set seria melhor**.
