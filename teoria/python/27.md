## 2. Lista Python nao e array numerico

Lista Python guarda:

- referencias para objetos.

Ja `ndarray` guarda:

- bloco de memoria mais regular;
- `dtype` fixo;
- shape;
- stride.

Essa diferenca explica boa parte do ganho.

## 3. `dtype`

- **`dtype`**: tipo concreto dos elementos do array.

Isso importa porque define:

- tamanho de cada elemento;
- interpretacao dos bytes;
- compatibilidade de operacoes;
- consumo de memoria.

---

## 4. Shape e stride

- **Shape**: dimensoes logicas do array.
- **Stride**: quantos bytes precisamos saltar para avancar em cada eixo.

Sem esse modelo mental, muito codigo NumPy vira "funciona por sorte".

---

## 5. View vs copy

Erro classico:

- achar que toda transformacao gera copia.

Em NumPy, varias operacoes produzem:

- view.

Isto e:

- outro objeto;
- mesma memoria subjacente.

---

## 6. Exemplo completo da aula

```python
import numpy as np


def main() -> None:
    a = np.arange(12, dtype=np.int32)
    print("a:", a)
    print("dtype:", a.dtype)
    print("shape:", a.shape)
    print("strides:", a.strides)

    matrix = a.reshape(3, 4)
    print("matrix:\n", matrix)
    print("matrix shape:", matrix.shape)
    print("matrix strides:", matrix.strides)

    first_two_cols = matrix[:, :2]
    print("slice:\n", first_two_cols)
    print("slice shares memory:", np.shares_memory(matrix, first_two_cols))

    doubled = matrix * 2
    print("doubled:\n", doubled)

    row_sums = matrix.sum(axis=1)
    print("row_sums:", row_sums)

    contiguous = np.ascontiguousarray(first_two_cols)
    print("contiguous strides:", contiguous.strides)
    print("copy shares memory:", np.shares_memory(matrix, contiguous))


if __name__ == "__main__":
    main()
```

## 7. O que esse exemplo ensina?

### 7.1 `reshape`

Pode reorganizar visao logica:

### 7.2 Fatiamento

### 7.3 Operacao vetorizada

Executa:

---

## 8. Vetorizacao

Em Python puro, loop numerico grande sofre com:

- overhead do interpretador;
- boxing;
- dispatch dinamico.

Em NumPy, varias operacoes passam a acontecer:

- em codigo nativo;
- sobre memoria regular.

---

## 9. Contiguidade

Array contiguo tende a ser melhor para:

- cache;
- interoperabilidade;
- kernels nativos;
- previsibilidade de custo.

Views estranhas podem ser uteis.

Mas tambem podem piorar:

- localidade;
- compatibilidade com biblioteca externa.

---

## 10. Comparacao com C, C++ e Rust

- Em C, arrays contiguos e layout sao completamente explicitos.
- Em C++, bibliotecas numericas tambem se apoiam em contiguidade e tipos fixos.
- Em Rust, slices e arrays tambem deixam claro o bloco de memoria.
- Em Python, NumPy e a grande ponte entre ergonomia de alto nivel e custo mais proximo do hardware.
