## 1. O que e I/O?

I/O significa **Input/Output**, isto e, entrada e saida de dados.

Exemplos:

- ler arquivo;
- escrever log;
- receber dados da rede;
- imprimir no terminal;
- carregar configuracao;
- salvar resultado de processamento.

Do ponto de vista de sistemas, I/O costuma ser mais lento e menos previsivel que operacoes puramente em memoria.

Isso importa muito em desempenho e em desenho de software.

---

## 2. Arquivos sao recursos externos

Diferente de uma lista em memoria, arquivo envolve:

- sistema operacional;
- permissao;
- disco ou dispositivo;
- falha fisica ou logica;
- encoding;
- caminho;
- concorrencia de acesso.

Por isso leitura e escrita de arquivo sempre devem ser tratadas com mais cuidado do que simples manipulacao de objetos locais.

---

## 3. Abrindo arquivos com `open`

Forma mais comum:

```python
with open("dados.txt", "r", encoding="utf-8") as arquivo:
    conteudo = arquivo.read()
```

Parametros importantes:

- primeiro argumento: caminho do arquivo;
- `"r"`: modo leitura;
- `encoding="utf-8"`: codificacao textual.

**Regra pratica:** em arquivo texto, especifique encoding explicitamente quando isso for relevante para portabilidade e clareza.

---

## 4. Modos de abertura

### 4.1 Leitura

```python
open("dados.txt", "r", encoding="utf-8")
```

### 4.2 Escrita

```python
open("dados.txt", "w", encoding="utf-8")
```

`"w"` recria ou trunca o arquivo.

- **Truncar**: apagar o conteudo anterior ao redefinir o tamanho para zero.

### 4.3 Acrescentar

```python
open("dados.txt", "a", encoding="utf-8")
```

`"a"` adiciona ao final.

### 4.4 Binario

```python
open("imagem.bin", "rb")
open("saida.bin", "wb")
```

Modo binario trabalha com `bytes`, nao com `str`.

---

## 5. `str` vs `bytes`

Isto e essencial.

- `str`: texto Unicode.
- `bytes`: sequencia bruta de bytes.

Exemplo:

```python
texto = "cafe"
dados = texto.encode("utf-8")

print(texto)
print(dados)
print(dados.decode("utf-8"))
```

Quando lidamos com arquivo texto, Python faz conversao entre bytes e string usando o encoding informado.

Quando lidamos com arquivo binario, essa traducao nao acontece.

**Comparacao com C:**

- em C, texto e frequentemente tratado como array de bytes com convencoes.
- em Python, a separacao `str`/`bytes` e mais explicita e segura conceitualmente.

---

## 6. Por que `with` e tao importante aqui?

Porque arquivo precisa ser fechado mesmo se algo falhar.

```python
with open("dados.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        print(linha.strip())
```

Ao sair do bloco:

- recurso e liberado;
- buffer e descarregado quando necessario;
- risco de vazamento de descriptor diminui.

- **File descriptor**: identificador de recurso de arquivo gerenciado pelo sistema operacional.

---

## 7. Formas de leitura

### 7.1 Ler tudo

```python
with open("dados.txt", "r", encoding="utf-8") as f:
    conteudo = f.read()
```

Bom para arquivos pequenos.

### 7.2 Ler linha a linha

```python
with open("dados.txt", "r", encoding="utf-8") as f:
    for linha in f:
        print(linha.rstrip())
```

Melhor para arquivos maiores.

### 7.3 Ler tamanho fixo

```python
with open("dados.txt", "r", encoding="utf-8") as f:
    trecho = f.read(100)
```

## 8. Formas de escrita

```python
with open("saida.txt", "w", encoding="utf-8") as f:
    f.write("linha 1\n")
    f.write("linha 2\n")
```

Ou:

```python
linhas = ["ana\n", "bruno\n", "carla\n"]

with open("saida.txt", "w", encoding="utf-8") as f:
    f.writelines(linhas)
```

**Cuidado:** `writelines` nao adiciona `\n` sozinho.

## 9. Caminhos com `pathlib`

Evite manipular caminhos com concatenacao textual ingenua.

Forma idiomatica moderna:

```python
from pathlib import Path


caminho = Path("dados") / "entrada.txt"
print(caminho)
```

`Path` oferece:

- composicao portavel de caminhos;
- metodos de leitura/escrita;
- verificacoes de existencia;
- operacoes de diretorio.

Exemplo:

```python
from pathlib import Path


arquivo = Path("config.json")
if arquivo.exists():
    print("Existe")
```

## 11. JSON

JSON e um formato textual amplamente usado para troca de dados.

Em Python, a biblioteca padrao oferece o modulo `json`.

### 11.1 Serializando

```python
import json


dados = {"nome": "Ana", "idade": 30, "ativo": True}
texto = json.dumps(dados, ensure_ascii=False, indent=2)
print(texto)
```

- **Serializacao**: transformar estrutura em representacao transmissivel ou armazenavel.

### 11.2 Desserializando

```python
import json


texto = '{"nome": "Ana", "idade": 30}'
obj = json.loads(texto)
print(obj["nome"])
```

- **Desserializacao**: reconstruir estrutura de dados a partir de representacao serializada.

---

## 12. JSON em arquivo

### 12.1 Escrevendo

```python
import json


dados = {"nome": "Ana", "cidade": "Recife"}

with open("usuario.json", "w", encoding="utf-8") as f:
    json.dump(dados, f, ensure_ascii=False, indent=2)
```

### 12.2 Lendo

```python
import json


with open("usuario.json", "r", encoding="utf-8") as f:
    dados = json.load(f)

print(dados["cidade"])
```

## 13. Dados externos nunca sao "confiaveis por padrao"

Ao ler arquivo ou JSON, voce precisa assumir possibilidade de problema:

- arquivo nao existe;
- formato invalido;
- encoding errado;
- chave faltando;
- valor com tipo inesperado.

Por isso, I/O quase sempre conversa com tratamento de excecao.

Exemplo:

```python
import json


try:
    with open("config.json", "r", encoding="utf-8") as f:
        config = json.load(f)
except FileNotFoundError:
    print("arquivo nao encontrado")
except json.JSONDecodeError:
    print("json invalido")
```

## 14. `pickle`

Python tambem possui `pickle`, que serializa objetos Python em formato binario proprio.

Exemplo conceitual:

```python
import pickle


dados = {"x": 10, "y": [1, 2, 3]}
blob = pickle.dumps(dados)
obj = pickle.loads(blob)
```

Mas aqui ha um alerta forte:

> nao carregue `pickle` vindo de fonte nao confiavel.

`pickle` nao e formato seguro para entrada arbitraria.

Para interoperabilidade e seguranca relativa maior, JSON costuma ser escolha muito melhor quando aplicavel.

## 15. Buffering

I/O frequentemente usa **buffering**.

- **Buffer**: area temporaria em memoria usada para acumular dados antes de enviar ou apos receber.

Isso existe para reduzir custo de chamadas repetidas ao sistema operacional.

Consequencia pratica:

- dados escritos podem nao ir imediatamente ao disco;
- fechar arquivo ou descarregar buffer e importante.

Em geral, o `with` e suficiente para o caso comum.

## 16. Exemplo completo da aula

```python
import json
from pathlib import Path


def salvar_usuarios(caminho: Path, usuarios: list[dict[str, object]]) -> None:
    caminho.parent.mkdir(parents=True, exist_ok=True)
    with caminho.open("w", encoding="utf-8") as f:
        json.dump(usuarios, f, ensure_ascii=False, indent=2)


def carregar_usuarios(caminho: Path) -> list[dict[str, object]]:
    with caminho.open("r", encoding="utf-8") as f:
        dados = json.load(f)
    if not isinstance(dados, list):
        raise ValueError("arquivo deve conter lista de usuarios")
    return dados


def main() -> None:
    caminho = Path("saida") / "usuarios.json"
    usuarios = [
        {"nome": "Ana", "idade": 30},
        {"nome": "Bruno", "idade": 25},
    ]

    salvar_usuarios(caminho, usuarios)
    carregados = carregar_usuarios(caminho)

    for usuario in carregados:
        print(usuario)


if __name__ == "__main__":
    main()
```

### Explicacao linha por linha

- `Path("saida") / "usuarios.json"`: monta caminho de forma portavel.
- `mkdir(parents=True, exist_ok=True)`: garante diretorio de destino.
- `caminho.open(...)`: usa API de `Path` para abrir arquivo.
- `json.dump(...)`: serializa estrutura para arquivo.
- `json.load(...)`: desserializa do arquivo para objeto Python.
- `isinstance(dados, list)`: validacao minima de contrato apos leitura externa.

## 18. Erros Comuns e Anti-Padroes

1. **Abrir arquivo sem `with`** e esquecer de fechar.
2. **Confundir `str` com `bytes`**.
3. **Nao informar encoding quando isso importa**.
4. **Ler arquivo inteiro enorme sem necessidade**.
5. **Concatenar caminhos manualmente como string**.
6. **Confiar cegamente em JSON ou arquivo externo sem validacao minima**.
7. **Usar `pickle` com dados nao confiaveis**.
