# Aula 32 - Projeto pratico: pipeline de dados com Python, NumPy e Pandas

---

## Objetivo da Aula

Construir o modelo mental de um pequeno pipeline de dados em Python que integra ingestao, validacao, transformacao, agregacao e medicao de custo. O exemplo usa Pandas; NumPy participa indiretamente como base de varias operacoes internas. Ao final, voce deve conseguir julgar quando esse fluxo basta ou precisa evoluir.

---

## 1. O que vamos construir?

Um pipeline simples que:

- le dados tabulares;
- valida colunas;
- converte tipos;
- filtra registros invalidos;
- agrega resultados;
- mede tempo e memoria.

---

## 2. Etapas do pipeline

Queremos separar:

- ingestao;
- validacao;
- transformacao;
- agregacao;
- observacao de custo.

Sem isso, ETL vira bloco opaco e dificil de operar.

---

## 3. Exemplo completo da aula

```python
from io import StringIO
import time
import tracemalloc

import pandas as pd


RAW_CSV = """user_id,team,score
1,blue,10
2,red,18
3,blue,25
4,red,invalid
5,blue,30
"""


def load_frame() -> pd.DataFrame:
    return pd.read_csv(StringIO(RAW_CSV))


def validate_schema(df: pd.DataFrame) -> None:
    required = {"user_id", "team", "score"}
    missing = required - set(df.columns)
    if missing:
        raise ValueError(f"missing columns: {sorted(missing)}")


def transform(df: pd.DataFrame) -> pd.DataFrame:
    df = df.copy()
    df["score"] = pd.to_numeric(df["score"], errors="coerce")
    df = df.dropna(subset=["score"])
    # Nao force int32 sem verificar faixa e integralidade em dados externos.
    df["approved"] = df["score"] >= 20
    return df


def aggregate(df: pd.DataFrame) -> pd.DataFrame:
    return (
        df.groupby("team", as_index=False)
        .agg(
            total_score=("score", "sum"),
            avg_score=("score", "mean"),
            approved_count=("approved", "sum"),
        )
        .sort_values("total_score", ascending=False)
    )


def main() -> None:
    tracemalloc.start()
    start = time.perf_counter()

    df = load_frame()
    validate_schema(df)
    clean = transform(df)
    result = aggregate(clean)

    elapsed_ms = (time.perf_counter() - start) * 1000.0
    current, peak = tracemalloc.get_traced_memory()

    print(clean)
    print(result)
    print(f"elapsed_ms={elapsed_ms:.2f}")
    print(f"current_traced_python_bytes={current}")
    print(f"peak_traced_python_bytes={peak}")


if __name__ == "__main__":
    main()
```

## 4. O que esse projeto consolida?

- leitura tabular;
- schema mental;
- limpeza de dado;
- transformacao explicita;
- agregacao;
- medicao de tempo e memoria.

---

## 5. O que esta bom aqui?

- etapas separadas;
- schema validado;
- conversao numerica explicita;
- agregacao isolada;
- tempo e alocacoes Python observados.

`tracemalloc` acompanha blocos rastreados pelo Python, nao representa o pico total do processo nem toda memoria nativa usada por NumPy/Pandas. Para carga real, meca tambem RSS do processo e valide os tipos e a faixa antes de reduzir `dtype`.

---

## 6. O que ainda faltaria em sistema real?

- leitura de arquivos grandes ou em chunk;
- controle de schema mais formal;
- particionamento;
- formato columnar como parquet;
- observabilidade mais rica;
- integracao com storage real;
- checkpoint por lote.

---

## 7. Quando este pipeline ainda cabe em Python?

Quando o problema e:

- volume moderado;
- time pequeno;
- exploracao rapida;
- transformacao clara;
- dependencia forte do ecossistema Python.

Quando talvez nao caiba mais:

- volume grande demais em memoria;
- latencia muito apertada;
- transformacao muito pesada e repetitiva;
- necessidade de paralelismo mais forte ou sistema distribuido.


## 10. Erros Comuns e Anti-Padroes

1. **Misturar ingestao, limpeza e agregacao em bloco unico ilegivel**.
2. **Nao validar schema de entrada**.
3. **Ignorar `dtype` e custo de memoria**.
4. **Nao medir tempo e pico de memoria em pipeline relevante**.
5. **Achar que Pandas resolve qualquer escala sozinho**.
