## 1. O que e Python?

Python e uma linguagem de programacao de alto nivel, interpretada, com sintaxe enxuta e forte foco em produtividade, legibilidade e ecossistema.

Como esta e a primeira vez que esses termos aparecem, vamos defini-los com cuidado:

- **Linguagem de alto nivel**: linguagem que abstrai muitos detalhes do hardware e do sistema operacional, deixando o programador trabalhar mais perto do problema e menos perto de registradores, ponteiros crus e gerenciamento manual de memoria.
- **Interpretada**: significa que, no uso comum, o codigo fonte e executado por um programa intermediario chamado interpretador, em vez de ser transformado diretamente em um binario nativo como em C/C++.
- **Ecossistema**: conjunto de ferramentas, bibliotecas, empacotamento, convencoes e comunidade ao redor da linguagem.

Python existe porque, em muitos tipos de software, velocidade de desenvolvimento, clareza e integracao importam mais do que controle total de baixo nivel.

Na pratica, Python e muito usado para:

- automacao;
- backend;
- ferramentas internas;
- ciencia de dados;
- scripts de infraestrutura;
- prototipagem rapida;
- orquestracao de sistemas escritos em linguagens mais rapidas.

**Comparacao com C/C++ e Rust:**

| Conceito | C/C++ | Rust | Python |
|----------|-------|------|--------|
| Execucao comum | Binario nativo | Binario nativo | Interpretador |
| Tipagem | Estatica | Estatica | Dinamica |
| Gerencia de memoria | Manual / RAII | Ownership + borrowing | Garbage collector + reference counting |
| Performance bruta | Muito alta | Muito alta | Menor, em geral |
| Velocidade de desenvolvimento | Media | Media | Alta |

**Tipagem dinamica** significa que o tipo pertence ao objeto em runtime, nao ao nome escrito no codigo.

## 2. Interpretador, script e REPL

### 2.1 O interpretador

O interpretador Python e o programa que le seu codigo, compila internamente para bytecode e executa esse bytecode dentro da Python Virtual Machine.

Termos importantes:

- **Bytecode**: representacao intermediaria, mais proxima da maquina virtual do Python do que do codigo fonte original.
- **Maquina virtual**: ambiente de execucao de software que entende um conjunto proprio de instrucoes. Aqui, nao e uma VM tipo VirtualBox; e um motor de execucao da linguagem.

No Windows, o comando mais comum pode ser:

```bash
python --version
```

Em algumas instalacoes:

```bash
py --version
```

### 2.2 REPL

REPL significa **Read-Eval-Print Loop**:

- **Read**: le o que voce digitou;
- **Eval**: avalia/executa;
- **Print**: mostra o resultado;
- **Loop**: repete o processo.

Abrindo o REPL:

```bash
python
```

Exemplo:

```python
>>> 2 + 3
5
>>> print("Ola")
Ola
```

**Quando usar REPL:**

- testar expressoes rapidas;
- explorar API;
- validar ideias pequenas.

**Quando usar arquivo `.py`:**

- programas reais;
- codigo reutilizavel;
- exemplos maiores;
- qualquer coisa que precise ser versionada.

### 2.3 Script `.py`

Crie um arquivo `ola.py`:

```python
print("Ola, mundo!")
```

Executar:

```bash
python ola.py
```

**Comparacao com C/C++ e Rust:**

```bash
gcc ola.c -o ola
./ola
```

```bash
rustc ola.rs
./ola
```

```bash
python ola.py
```

Em Python, o ciclo inicial e menor: voce normalmente nao tem etapa manual de link/geracao de executavel para exemplos simples.

## 3. Estrutura minima de um programa Python

O menor programa util de Python pode ser literalmente uma unica linha:

```python
print("Ola, mundo!")
```

Python nao exige:

- funcao `main`;
- declaracoes de tipo para cada variavel;
- ponto e virgula ao fim de cada linha;
- chaves `{}` para delimitar blocos.

Em vez disso, Python usa **indentacao significativa**.

- **Indentacao significativa**: os espacos no inicio da linha fazem parte da sintaxe e definem blocos logicos.

Exemplo:

```python
if True:
    print("Dentro do bloco")
print("Fora do bloco")
```

Em C/C++/Rust, o bloco e delimitado por `{}`. Em Python, o bloco e delimitado pela indentacao.

## 4. `print()` e saida formatada

`print()` e uma funcao builtin usada para escrever texto na saida padrao.

- **Builtin**: algo que ja vem disponivel na linguagem sem precisar importar biblioteca.
- **Saida padrao**: fluxo de saida normalmente conectado ao terminal.

Exemplo simples:

```python
print("Ola")
print(123)
print(True)
```

### 4.1 Multiplos argumentos

```python
nome = "Ana"
idade = 30

print("Nome:", nome, "Idade:", idade)
```

Saida:

```text
Nome: Ana Idade: 30
```

### 4.2 f-strings

Forma moderna e idiomatica:

```python
nome = "Ana"
idade = 30

print(f"Nome: {nome}, idade: {idade}")
```

- **f-string**: string formatada em que expressoes Python entre chaves `{}` sao avaliadas em runtime.

**Comparacao:**

```c
printf("Nome: %s, idade: %d\n", nome, idade);
```

```rust
println!("Nome: {}, idade: {}", nome, idade);
```

```python
print(f"Nome: {nome}, idade: {idade}")
```

Python evita especificadores de formato obrigatorios no caso simples, embora existam opcoes avancadas de formatacao.

## 5. Variaveis em Python

## 5.1 O modelo mental correto

Em Python, uma variavel nao e uma "caixa tipada" fixa como em C. O mais correto e pensar assim:

> Um **nome** e associado a um **objeto**.

Exemplo:

```python
x = 10
```

Isso significa:

- o objeto inteiro `10` existe;
- o nome `x` passa a referenciar esse objeto.

Termos fundamentais:

- **Nome**: identificador escrito no codigo, como `x`, `total`, `usuario`.
- **Objeto**: entidade em runtime que possui identidade, tipo e valor/estado.
- **Referencia**: ligacao entre um nome e um objeto.

### 5.2 Reatribuicao

```python
x = 10
print(x)

x = "agora sou texto"
print(x)
```

Saida:

```text
10
agora sou texto
```

Isso mostra algo central: o nome `x` nao tem tipo fixo declarado. Primeiro ele referencia um objeto `int`; depois, um objeto `str`.

**Comparacao com C:**

```c
int x = 10;
x = 20;         // OK
// x = "texto"; // ERRO de tipo
```

**Comparacao com Rust:**

```rust
let x = 10;
let x = "texto"; // shadowing: nova variavel
```

Em Python, nao ha shadowing nesse caso. Ha simplesmente rebinding do nome para outro objeto.

- **Rebinding**: ato de fazer um nome deixar de apontar para um objeto e passar a apontar para outro.

### 5.3 O que acontece na memoria

Modelo simplificado:

```text
x = 10

Stack conceitual do frame atual:
  nome x  ----> objeto int(10) no heap
```

Depois:

```text
x = "agora sou texto"

Stack conceitual do frame atual:
  nome x  ----> objeto str("agora sou texto") no heap
```

O objeto antigo pode ser reaproveitado ou destruido mais tarde se nao houver mais referencias para ele.

## 6. Tipos basicos: tamanho e limites

Python tem varios tipos basicos builtin. Vamos comecar pelos mais importantes.

Diferente de C/Rust/Go, Python nao tem largura fixa para `int`: o tamanho e o limite dependem do valor e da memoria. A tabela abaixo resume o que e fixo e o que deve ser medido com `sys.getsizeof`, `sys.maxsize` e `sys.float_info`:

| Tipo | Tamanho | Minimo | Maximo | Como medir |
|---|---|---|---|---|
| `int` | variavel (precisao arbitraria; ~28 bytes para `0` nesta maquina) | sem minimo fixo (limitado pela memoria) | sem maximo fixo (limitado pela memoria) | `sys.getsizeof(x)`, `sys.maxsize` (limite do `Py_ssize_t`, nao do `int`) |
| `float` | 24 bytes de objeto (8 bytes de payload IEEE 754 double) | ~2.2e-308 (`sys.float_info.min`) | ~1.8e308 (`sys.float_info.max`) | `sys.getsizeof(x)`, `sys.float_info` |
| `bool` | 28 bytes de objeto (`True`/`False` sao singletons) | `False` | `True` | `sys.getsizeof(True)` |
| `str` | variavel (cabecalho + 1, 2 ou 4 bytes por caractere) | — | — | `sys.getsizeof(s)` |
| `NoneType` | 16 bytes (singleton `None`) | — | — | `sys.getsizeof(None)` |

### 6.0 Experimento: medir na sua maquina

```python
import sys

print("maxsize:", sys.maxsize)
print("float max:", sys.float_info.max)
print("float min:", sys.float_info.min)
print("sizeof 0:", sys.getsizeof(0))
print("sizeof 2**100:", sys.getsizeof(2**100))
print("sizeof 1.0:", sys.getsizeof(1.0))
print("sizeof True:", sys.getsizeof(True))
print("sizeof 'a':", sys.getsizeof("a"))
print("sizeof None:", sys.getsizeof(None))
```

Saida nesta maquina (CPython 3.14, 64 bits):

```text
maxsize: 9223372036854775807
float max: 1.7976931348623157e+308
float min: 2.2250738585072014e-308
sizeof 0: 28
sizeof 2**100: 40
sizeof 1.0: 24
sizeof True: 28
sizeof 'a': 42
sizeof None: 16
```

Note que `sys.getsizeof(2**100)` e maior que `sys.getsizeof(0)`: o `int` cresce com o valor. `sys.maxsize` nao e o "maximo do int" — e o maximo do tipo interno usado para tamanhos de container. Registre `python --version` e a saida: os bytes exatos do objeto variam com a versao do CPython.

### 6.1 Inteiros: `int`

```python
idade = 30
temperatura = -5

print(type(idade))
print(type(temperatura))
```

Saida:

```text
<class 'int'>
<class 'int'>
```

Em Python, `int` tem precisao arbitraria. Isso significa que ele nao fica limitado a 32 ou 64 bits do mesmo jeito que em C.

**Por que isso existe?**

Para evitar overflow silencioso em contas inteiras comuns.

**Comparacao:**

- C: `int`, `long`, `long long` com tamanho finito.
- Rust: `i32`, `u64`, etc., com tamanho explicito.
- Python: `int` cresce conforme necessario, com custo de performance maior.

### 6.2 Ponto flutuante: `float`

```python
preco = 19.99
pi = 3.14159

print(type(preco))
```

Em CPython, `float` normalmente corresponde a `double` de C, ou seja, dupla precisao IEEE 754.

### 6.3 Booleano: `bool`

```python
ativo = True
bloqueado = False

print(type(ativo))
print(ativo, bloqueado)
```

Python usa `True` e `False` com inicial maiuscula.

### 6.4 Strings: `str`

```python
nome = "Carlos"
mensagem = 'Python tambem aceita aspas simples'

print(type(nome))
print(nome)
```

String em Python e um objeto imutavel que representa texto Unicode.

- **Unicode**: padrao universal para representar texto humano de varios idiomas e simbolos.

### 6.5 `None`

```python
resultado = None
print(resultado)
print(type(resultado))
```

`None` representa ausencia de valor.

**Comparacao:**

- C: `NULL` normalmente aparece no contexto de ponteiros.
- Rust: `Option<T>` representa presenca ou ausencia explicitamente no tipo.
- Python: `None` e um objeto singleton muito usado para sinalizar "nao ha valor".

- **Singleton**: objeto do qual so existe uma instancia relevante naquele runtime.

## 7. Descobrindo tipos em runtime

Como Python e dinamica, inspecao de tipos em runtime e normal:

```python
valor = 42
print(type(valor))

valor = "texto"
print(type(valor))
```

Voce tambem pode testar pertencimento a um tipo:

```python
print(isinstance(42, int))        # True
print(isinstance("abc", str))     # True
```

- **Runtime**: momento em que o programa esta rodando.
- **`isinstance()`**: funcao que verifica se um objeto pertence a um tipo ou hierarquia de tipos.

## 9. Exemplo completo da aula

```python
print("=== Aula 1 de Python ===")

nome = "Marina"
idade = 28
altura = 1.68
estudando = True
apelido = None

print(f"nome = {nome}")
print(f"idade = {idade}")
print(f"altura = {altura}")
print(f"estudando = {estudando}")
print(f"apelido = {apelido}")

print(type(nome))
print(type(idade))
print(type(altura))

print(type(apelido))

print(f"valor inicial = {valor} ({type(valor)})")

valor = "dez"
print(f"valor final = {valor} ({type(valor)})")
```

### Explicacao linha por linha

- `print("=== Aula 1 de Python ===")`: escreve um titulo na saida.
- `nome = "Marina"`: associa o nome `nome` a um objeto `str`.
- `idade = 28`: associa `idade` a um objeto `int`.
- `altura = 1.68`: associa `altura` a um objeto `float`.
- `estudando = True`: associa `estudando` a um objeto `bool`.
- `apelido = None`: marca ausencia de valor.
- `print(f"...")`: usa f-string para interpolar valores.
- `type(...)`: inspeciona o tipo real do objeto em runtime.
- `valor = 10` e depois `valor = "dez"`: mostra rebinding do mesmo nome para objetos de tipos diferentes.

## 10. Erros Comuns e Anti-Padroes

1. **Pensar em variavel como caixa tipada**: em Python, o nome aponta para objetos. Isso muda totalmente como voce deve pensar atribuicao.
2. **Confundir `=` com "igualdade"**: `=` faz atribuicao. Comparacao usa `==`.
3. **Escrever `true` e `false` minusculos**: em Python o correto e `True` e `False`.
4. **Esperar `main()` obrigatorio**: Python nao exige ponto de entrada formal para scripts simples.
5. **Misturar tabs e espacos**: indentacao e sintaxe. Mistura ruim quebra o programa.
6. **Achar que interpretada significa "sem compilacao nenhuma"**: o interpretador ainda faz etapas internas de compilacao para bytecode.
