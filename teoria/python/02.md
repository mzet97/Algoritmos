# Aula 2 - Controle de fluxo, operadores, funcoes e escopo de execucao

Controle de fluxo em Python parece trivial até `and` devolver um objeto em vez de um booleano e o `else` do laço rodar quando ninguém chamou. A semântica por baixo da sintaxe amigável é o conteúdo real desta aula.

---

## Nesta aula

Dominar os blocos de controle de fluxo em Python (`if`, `elif`, `else`, `while`, `for`), entender operadores aritmeticos, relacionais e logicos, criar funcoes com parametros e retorno, e construir o modelo mental de como chamadas de funcao criam novos escopos de execucao.

Você vai aprender a usar `if`/`for`/`while`, operadores e `range`, definir funções com parâmetros e retorno, e prever escopo e valor de retorno.

---

## 1. Controle de fluxo

Controle de fluxo e o conjunto de mecanismos que faz um programa seguir caminhos diferentes em runtime.

Isso existe porque programas reais precisam:

- decidir;
- repetir;
- interromper;
- escolher caminhos com base em dados.

Em baixo nivel, isso se conecta a saltos condicionais da CPU. Em Python, a linguagem abstrai essa mecanica, mas a ideia logica continua a mesma.

---

## 2. `if`, `elif`, `else`

### 2.1 Exemplo basico

```python
idade = 20

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

Python avalia a condicao. Se ela for verdadeira, executa o primeiro bloco; caso contrario, executa o outro.

### 2.2 Multiplos caminhos

```python
nota = 8.5

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Bom")
elif nota >= 5:
    print("Recuperacao")
else:
    print("Reprovado")
```

- **Condicao**: expressao cujo resultado sera interpretado como verdadeiro ou falso.

### 2.3 Truthy e falsy

Python nao exige que toda condicao seja literalmente `True` ou `False`. Em vez disso, muitos objetos possuem **valor de verdade**.

Exemplos falsy:

- `False`
- `None`
- `0`
- `0.0`
- `""`
- `[]`
- `{}`
- `set()`

Exemplo:

```python
nome = ""

if nome:
    print("Nome preenchido")
else:
    print("Nome vazio")
```

- **Truthy/falsy**: convencao de runtime que permite interpretar objetos como verdadeiros ou falsos em contexto booleano.

**Comparacao importante:**

- Em Rust, a condicao precisa ser `bool`.
- Em C, quase qualquer inteiro diferente de zero vira verdadeiro.
- Em Python, existe um protocolo de verdade mais rico baseado no objeto.

## 3. Operadores

### 3.1 Aritmeticos

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

Termos importantes:

- **Divisao real `/`**: produz `float`.
- **Divisao inteira `//`**: descarta a parte fracionaria.
- **Modulo `%`**: resto da divisao.
- **Exponenciacao `**`**: potencia.

### 3.2 Relacionais

```python
x = 10
y = 20

print(x == y)
print(x != y)
print(x < y)
print(x <= y)
print(x > y)
print(x >= y)
```

### 3.3 Logicos

```python
idade = 25
tem_documento = True

print(idade >= 18 and tem_documento)
print(idade < 18 or tem_documento)
print(not tem_documento)
```

`and`, `or` e `not` fazem logica booleana. Python nao usa `&&`, `||` e `!` como C/C++/Rust.

### 3.4 Curto-circuito

```python
nome = ""
apelido = "gui"

resultado = nome or apelido
print(resultado)
```

Saida:

```text
gui
```

Python usa **short-circuit**:

- em `a or b`, se `a` ja for suficiente para definir o resultado, `b` nem precisa ser avaliado;
- em `a and b`, o mesmo vale na direcao oposta.

Mais importante: `and` e `or` retornam **objetos**, nao necessariamente `True`/`False`.

```python
print("" or "backup")      # "backup"
print("principal" or "x")  # "principal"
print(0 and 999)           # 0
```

Isso e muito idiomatico em Python, mas exige cuidado para nao esconder intencao.

## 4. `while`

`while` repete um bloco enquanto a condicao continuar verdadeira.

```python
contador = 0

while contador < 5:
    print(contador)
    contador += 1
```

Saida:

```text
0
1
2
3
4
```

### 4.1 `break` e `continue`

```python
contador = 0

while True:
    contador += 1

    if contador == 2:
        continue

    if contador == 5:
        break

    print(contador)
```

- **`break`**: interrompe o loop.
- **`continue`**: pula para a proxima iteracao.

### 4.2 `while` com `else`

Pouca gente aprende isso cedo, mas faz parte da linguagem:

```python
numero = 1

while numero < 4:
    print(numero)
    numero += 1
else:
    print("Loop terminou sem break")
```

O `else` do loop executa se o loop terminar de forma natural, sem `break`.

## 5. `for` e iteracao

Em Python, `for` nao e um "mini while com contador" como em C. Ele funciona sobre um **iteravel**.

- **Iteravel**: objeto que pode fornecer elementos um por um.

### 5.1 `for` com `range`

```python
for i in range(5):
    print(i)
```

Saida:

```text
0
1
2
3
4
```

`range(5)` produz os numeros `0, 1, 2, 3, 4`.

Exemplos:

```python
for i in range(2, 8):
    print(i)

for i in range(0, 10, 2):
    print(i)
```

### 5.2 `for` sobre strings e listas

```python
for letra in "python":
    print(letra)
```

```python
nomes = ["Ana", "Bruno", "Carla"]

for nome in nomes:
    print(nome)
```

### 5.3 `enumerate`

```python
nomes = ["Ana", "Bruno", "Carla"]

for indice, nome in enumerate(nomes):
    print(indice, nome)
```

- **`enumerate()`**: builtin que combina indice e elemento durante a iteracao.

### 5.4 `for` com `else`

```python
numeros = [1, 3, 5, 7]

for n in numeros:
    if n % 2 == 0:
        print("Achei um par")
        break
else:
    print("Nao ha numeros pares")
```

Assim como em `while`, o `else` roda se o loop terminar sem `break`.

## 6. Funcoes

### 6.1 O que e uma funcao?

Uma funcao e um bloco nomeado de codigo que pode receber entradas, executar logica e devolver um resultado.

Por que isso existe?

- para evitar repeticao;
- para encapsular comportamento;
- para melhorar teste e reutilizacao;
- para dar nome a uma ideia.

### 6.2 Funcao basica

```python
def saudacao():
    print("Ola!")


saudacao()
```

Python usa `def` para definir funcoes.

**Comparacao:**

```c
void saudacao(void) {
    printf("Ola!\n");
}
```

```rust
fn saudacao() {
    println!("Ola!");
}
```

### 6.3 Parametros e retorno

```python
def soma(a, b):
    return a + b


resultado = soma(10, 20)
print(resultado)
```

- **Parametro**: nome que a funcao usa para receber dados.
- **Retorno**: valor devolvido pela funcao.

Ao contrario de Rust e C/C++, Python nao exige tipos na assinatura basica.

### 6.4 `return`

```python
def classificar_idade(idade):
    if idade < 0:
        return "idade invalida"
    if idade < 18:
        return "menor"
    return "maior"


print(classificar_idade(15))
```

Quando a funcao atinge `return`, ela termina imediatamente.

### 6.5 Funcoes sem retorno explicito

```python
def registrar():
    print("registrando...")


valor = registrar()
print(valor)
```

Saida:

```text
registrando...
None
```

Se nao houver `return`, a funcao devolve `None`.

## 7. Escopo de execucao

Cada chamada de funcao cria um novo escopo local.

```python
nome = "global"


def mostrar():
    nome = "local"
    print(nome)


mostrar()
print(nome)
```

Saida:

```text
local
global
```

Isso acontece porque o `nome` dentro da funcao e outro binding, em outro escopo.

Termos importantes:

- **Escopo**: regiao em que um nome e visivel.
- **Escopo local**: nomes definidos dentro da funcao.
- **Escopo global**: nomes definidos no modulo atual.

### 7.1 Modelo simplificado de chamada

```python
def soma(a, b):
    resultado = a + b
    return resultado


x = 3
y = 4
z = soma(x, y)
```

Modelo conceitual:

```text
Frame global:
  x -> int(3)
  y -> int(4)
  z -> ?

Chamada soma(x, y):
  frame local da funcao
  a -> mesma referencia para o objeto 3
  b -> mesma referencia para o objeto 4
  resultado -> int(7)
```

Em Python, argumentos sao passados por **object reference sharing**: a funcao recebe nomes locais apontando para os mesmos objetos passados pelo chamador.

Nao pense nisso como "passagem por valor" de C, nem como "passagem por referencia" classica de C++. O modelo correto em Python e:

> nomes locais passam a apontar para os mesmos objetos recebidos.

## 8. Exemplo completo da aula

```python
def avaliar_numero(numero):
    if numero < 0:
        return "negativo"
    elif numero == 0:
        return "zero"
    else:
        return "positivo"


for i in range(-2, 3):
    classificacao = avaliar_numero(i)
    print(f"{i} -> {classificacao}")

contador = 0
while contador < 3:
    print(f"while: {contador}")
    contador += 1
```

### Explicacao linha por linha

- `def avaliar_numero(numero):` define uma funcao com um parametro.
- `if`, `elif`, `else` escolhem caminhos diferentes.
- `return` devolve uma string e termina a funcao.
- `for i in range(-2, 3):` itera pelos valores `-2, -1, 0, 1, 2`.
- `classificacao = avaliar_numero(i)` chama a funcao.
- `while contador < 3:` repete enquanto a condicao for verdadeira.

## 10. Erros Comuns e Anti-Padroes

1. **Esquecer a indentacao**: sem indentacao correta, o bloco nao existe sintaticamente.
2. **Esperar chaves `{}`**: em Python, bloco e dado por espacos, nao por delimitadores.
3. **Confundir `=` com `==`**: atribuicao nao e comparacao.
4. **Usar `&&` ou `||`**: em Python o correto e `and` e `or`.
5. **Achar que `for` funciona como em C**: em Python ele itera sobre um iteravel.
6. **Ignorar `None` em funcoes sem `return`**: toda funcao sem retorno explicito devolve `None`.
7. **Usar `if x == True` sem necessidade**: em muitos casos idiomaticos, `if x:` ja basta.
