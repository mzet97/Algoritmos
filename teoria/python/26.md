- o que falhou?;
- de onde retomar?;
- como evitar duplicacao?;
- como auditar a execucao?;

## 3. Checkpoint

- **Checkpoint**: ponto registrado que permite saber ate onde o processo avancou.

Exemplo:

- ultimo arquivo lido;
- ultimo ID processado;
- ultimo timestamp consolidado.

---

## 4. Idempotencia tambem importa aqui

Reexecutar um job pode acontecer por:

- falha;
- timeout;
- deploy;
- manutencao;
- duvida operacional.

Se a execucao repetida corrompe resultado:

- seu job nao e confiavel.

## 5. Exemplo completo da aula

```python
from dataclasses import dataclass
import json
from pathlib import Path


CHECKPOINT_PATH = Path("checkpoint.json")
SOURCE_PATH = Path("input.txt")
OUTPUT_PATH = Path("output.txt")


@dataclass
class Checkpoint:
    last_line: int


def load_checkpoint() -> Checkpoint:
    if not CHECKPOINT_PATH.exists():
        return Checkpoint(last_line=0)

    data = json.loads(CHECKPOINT_PATH.read_text(encoding="utf-8"))
    return Checkpoint(last_line=int(data["last_line"]))


def save_checkpoint(checkpoint: Checkpoint) -> None:
    CHECKPOINT_PATH.write_text(
        json.dumps({"last_line": checkpoint.last_line}),
        encoding="utf-8",
    )


def process_line(line: str) -> str:
    return line.strip().upper()


def run_job() -> int:
    checkpoint = load_checkpoint()

    if not SOURCE_PATH.exists():
        print("source file missing")
        return 2

    lines = SOURCE_PATH.read_text(encoding="utf-8").splitlines()

    with OUTPUT_PATH.open("a", encoding="utf-8") as out:
        for index, line in enumerate(lines, start=1):
            if index <= checkpoint.last_line:
                continue

            result = process_line(line)
            out.write(result + "\n")
            checkpoint.last_line = index
            save_checkpoint(checkpoint)

    print(f"processed_until={checkpoint.last_line}")
    return 0


if __name__ == "__main__":
    raise SystemExit(run_job())
```

## 6. O que esse exemplo ensina?

### 6.1 `checkpoint.json`

Guarda:

- progresso do job.

### 6.2 Escrita incremental

Ajuda a:

- nao perder tudo em caso de falha tardia.

### 6.3 Reexecucao

Permite:

- retomar do ponto conhecido.

## 9. Rastreabilidade

Job maduro deve responder:

- quando rodou?;
- quanto processou?;
- ate onde avancou?;
- onde falhou?;
- se pode rodar de novo com seguranca?;

---

## 10. Comparacao com C, C++ e Rust

- Em C e C++, jobs de lote tambem exigem checkpoint e reexecucao, mas a ergonomia de arquivos, JSON e scripting costuma ser menor.
- Em Rust, mais tipos ajudam a modelar estado, mas o desenho operacional continua igual.
- Em Python, a facilidade de automatizar pode esconder a complexidade de operar processos repetiveis por meses.

## 12. Erros Comuns e Anti-Padroes

1. **Fazer job recorrente sem checkpoint nem rastreabilidade**.
2. **Reexecutar sem pensar em duplicacao de efeito**.
3. **Misturar agendamento com toda a regra do job no mesmo lugar**.
4. **Gravar saida final apenas no fim e perder tudo em falha tardia**.
5. **Nao tratar entrada ausente ou corrompida como parte normal do sistema**.
