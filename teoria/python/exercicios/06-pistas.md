# Aula 06 (Python): pistas graduais

Volte aos [exercicios](../06.md#14-exercicios-obrigatorios) antes de abrir as solucoes.

1. Modulo e arquivo: um de contas, um de texto, nenhum dos dois sabe do `main`.
2. `main.py` importa os dois e so orquestra.
3. Importar executa o modulo sem rodar o bloco `__main__`; executar, roda.
4. Pacote e pasta com `__init__.py`: o import ganha sobrenome (`pacote.modulo`).
5. Ciclo se quebra extraindo o que os dois precisam para um terceiro modulo sem dependencias.
