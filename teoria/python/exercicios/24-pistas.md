# Aula 24 (Python): pistas graduais

Volte aos [exercicios](../24.md#12-exercicios-obrigatorios) antes de abrir as solucoes.

1. Subcomando e outro parser pendurado no primeiro: `version` so imprime e sai.
2. Config JSON se le na partida e se valida antes de validar qualquer caminho.
3. Multiplos caminhos sao uma lista no argumento (`nargs="+"`) e um codigo que resume.
4. `stderr` importa porque `stdout` em pipeline e dado, nao conversa.
5. Codigo de saida minimo se desenha por pergunta: deu? nao deu? nem rodou?
