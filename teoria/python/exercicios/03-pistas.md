# Aula 03 (Python): pistas graduais

Volte aos [exercicios](../03.md#12-exercicios-obrigatorios) antes de abrir as solucoes.

1. Dois nomes, uma lista: `b = a` nao copia nada.
2. `==` compara valor; `is` compara identidade (`id`).
3. Copia rasa copia a lista de fora; a de dentro continua compartilhada.
4. `deepcopy` desce recursivamente — e custa o que desce.
5. Mutar o objeto recebido afeta o chamador; rebinding local, nao.
