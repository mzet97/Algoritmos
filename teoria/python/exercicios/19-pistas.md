# Aula 19 (Python): pistas graduais

Volte aos [exercicios](../19.md#19-exercicios-obrigatorios) antes de abrir as solucoes.

1. `src/` separa o que se importa do que se executa; `tests/` mora fora do pacote.
2. Config hardcoded vira `os.environ` com padrao declarado num lugar so.
3. `print` vira `logging` quando alguem precisa desligar, nivelar ou redirecionar.
4. CLI pequena e `main() -> int`: quem chama decide o processo, quem escreve decide o codigo.
5. Testes, logs e config se listam por superficie: o que entra, o que sai, o que falha.
