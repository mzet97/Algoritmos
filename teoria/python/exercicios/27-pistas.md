# Aula 27 (Python): pistas graduais

Volte aos [exercicios](../27.md#13-exercicios-obrigatorios) antes de abrir as solucoes.

1. `strides` sao os saltos em bytes para andar em cada dimensao.
2. Diagonal parcial e uma view com passo nas duas dimensoes ao mesmo tempo.
3. `np.shares_memory` responde se a view e a base dividem o mesmo buffer.
4. `dtype` manda no `itemsize`: o mesmo numero de elementos, outra conta de bytes.
5. Vetorizar e tirar o interpretador do laco interno, nao "usar NumPy" por ritual.
