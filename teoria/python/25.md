## 5. Exemplo completo da aula

```python
import json
import subprocess
import sys
import time
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen


def run_command(cmd: list[str], timeout_s: float) -> tuple[int, str, str]:
    completed = subprocess.run(
        cmd,
        capture_output=True,
        text=True,
        timeout=timeout_s,
        check=False,
    )
    return completed.returncode, completed.stdout, completed.stderr


def fetch_json(url: str, timeout_s: float, retries: int) -> dict:
    last_error: Exception | None = None

    for attempt in range(1, retries + 1):
        try:
            request = Request(url, headers={"Accept": "application/json"})
            with urlopen(request, timeout=timeout_s) as response:
                max_bytes = 1_000_000
                payload = response.read(max_bytes + 1)
                if len(payload) > max_bytes:
                    raise ValueError("resposta JSON excede 1 MB")
                data = json.loads(payload.decode("utf-8"))
                if not isinstance(data, dict):
                    raise ValueError("resposta JSON nao e um objeto")
                return data
        except (HTTPError, URLError, TimeoutError, json.JSONDecodeError, UnicodeDecodeError, ValueError) as exc:
            last_error = exc
            if attempt == retries:
                break
            time.sleep(0.3 * attempt)

    raise RuntimeError(f"fetch failed after retries: {last_error}") from last_error


def main() -> int:
    code, out, err = run_command([sys.executable, "--version"], timeout_s=2.0)
    print(f"python_version_exit={code}")
    if out.strip():
        print(out.strip())
    if err.strip():
        print(err.strip(), file=sys.stderr)

    try:
        data = fetch_json("https://httpbin.org/json", timeout_s=3.0, retries=3)
        print("keys:", sorted(data.keys()))
    except RuntimeError as exc:
        print(f"api_error={exc}", file=sys.stderr)
        return 2

    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## 6. O que esse exemplo ensina?

### 6.1 `subprocess.run`

Ajuda a:

- executar comando;

- impor timeout.

### 6.2 Lista de argumentos

Ajuda a evitar:

- parsing ambiguo de shell.

### 6.3 Retry em API

Ajuda quando ha:

- falha temporaria.

Mas continua exigindo criterio.

## 7. SSH e execucao remota

Muita automacao faz algo assim:

- chamar `ssh host comando`.

O mecanismo pode funcionar.

Mas a ferramenta precisa pensar em:

- credencial;
- timeout;
- quote correto;
- observabilidade;
- idempotencia do comando remoto.

---

## 8. Retry nao e universal

Retry faz sentido para:

- timeout;
- erro de rede temporario;
- dependencia intermitente.

Retry nao faz sentido para:

- comando invalido;
- autenticacao errada;
- payload mal formado.

---

## 9. Seguranca minima

Nao faca:

- interpolar input direto em comando de shell;
- logar token ou senha;
- assumir que saida externa e sempre confiavel.

Python e otimo para automacao, mas tambem facilita erro de integracao se usado sem criterio.

---

## 10. Comparacao com C, C++ e Rust

- Em C e C++, subprocesso e HTTP costumam exigir mais codigo de infraestrutura e tratamento manual.
- Em Rust, integracoes podem ficar mais verbosas, mas tipos ajudam a explicitar contrato de erro.
- Em Python, a integracao e rapida, o que aumenta a responsabilidade de tratar bem timeout, retry e parsing.

## 12. Erros Comuns e Anti-Padroes

1. **Executar comando externo sem timeout**.
2. **Montar comando com string unica e input nao confiavel**.
3. **Fazer retry de erro deterministico**.
4. **Assumir que retorno nao zero sempre tem mensagem util**.
5. **Logar segredo ou payload sensivel por descuido**.
