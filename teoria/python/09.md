## Objetivo da Aula

Entender o modelo de iteracao de Python, aprender o que e um iteravel, o que e um iterador, como `for` funciona internamente, como criar generators com `yield` e como usar comprehensions de forma idiomatica sem sacrificar legibilidade.

---

## 1. O modelo de iteracao em Python

Quando voce escreve:

```python
for x in algo:
    print(x)
```

parece uma construcao simples. Mas por baixo ha um protocolo claro.

Python precisa responder duas perguntas:

1. como obter o "proximo" valor?
2. como saber quando terminou?

O modelo de iteracao existe justamente para padronizar isso entre varios tipos de objeto.

---

## 2. Iteravel

Um **iteravel** e qualquer objeto que pode fornecer uma sequencia de elementos.

Exemplos comuns:

- `list`
- `tuple`
- `str`
- `dict`
- `set`
- `range`
- arquivos
- generators

Exemplo:

```python
nomes = ["Ana", "Bruno", "Carla"]

for nome in nomes:
    print(nome)
```

Voce nao precisa saber como a lista produz cada elemento; basta saber que ela e iteravel.

---

## 3. Iterador

Um **iterador** e um objeto que sabe entregar um elemento por vez ate acabar.

Em Python, ele implementa conceitualmente:

- `__iter__()`
- `__next__()`

### 3.1 Obtendo iterador manualmente

```python
nomes = ["Ana", "Bruno", "Carla"]

it = iter(nomes)
print(next(it))
print(next(it))
print(next(it))
```

Se voce chamar `next(it)` mais uma vez, surge `StopIteration`.

- **`iter(obj)`**: pede um iterador ao objeto.
- **`next(it)`**: pede o proximo elemento ao iterador.
- **`StopIteration`**: excecao que sinaliza fim da iteracao.

### 3.2 O que o `for` faz por baixo?

Conceitualmente:

```python
it = iter(nomes)

while True:
    try:
        nome = next(it)
    except StopIteration:
        break
    print(nome)
```

Ou seja, `for` e uma interface mais limpa sobre esse protocolo.

---

## 4. Iteravel nao e a mesma coisa que iterador

Isto e importante.

```python
nomes = ["Ana", "Bruno", "Carla"]

print(iter(nomes) is nomes)
```

Para listas, isso tende a ser `False`: a lista e iteravel, mas nao e o proprio iterador.

Ja um generator geralmente e ao mesmo tempo iteravel e iterador.

---

## 5. `range`

Muita gente trata `range` como "lista de numeros", mas isso esta conceitualmente errado.

```python
r = range(5)
print(r)
print(list(r))
```

`range` representa uma sequencia aritmetica de forma eficiente, sem precisar materializar todos os elementos imediatamente.

- **Materializar**: construir explicitamente todos os objetos em memoria.

Isso importa para eficiencia.

**Comparacao:**

- em C, `for (int i = 0; i < 5; i++)` usa contador manual;
- em Python, `for i in range(5)` usa um objeto que sabe descrever a sequencia.

## 6. `enumerate`, `zip` e `reversed`

### 6.1 `enumerate`

```python
nomes = ["Ana", "Bruno", "Carla"]

for indice, nome in enumerate(nomes):
    print(indice, nome)
```

### 6.2 `zip`

```python
nomes = ["Ana", "Bruno", "Carla"]
idades = [30, 25, 28]

for nome, idade in zip(nomes, idades):
    print(nome, idade)
```

### 6.3 `reversed`

```python
for x in reversed([1, 2, 3, 4]):
    print(x)
```

Essas ferramentas existem para manter iteracao expressiva e sem indices desnecessarios.

## 7. List comprehensions

### 7.1 O que sao?

List comprehension e uma forma compacta de construir listas a partir de iteracao.

```python
quadrados = [x * x for x in range(5)]
print(quadrados)
```

Equivalente expandido:

```python
quadrados = []
for x in range(5):
    quadrados.append(x * x)
```

### 7.2 Com filtro

```python
pares = [x for x in range(10) if x % 2 == 0]
print(pares)
```

### 7.3 Quando usar?

Use quando:

- a transformacao for simples;
- a leitura continuar clara;
- o resultado desejado for realmente uma lista.

Nao use quando a logica ficar tao densa que um loop normal fique mais legivel.

---

## 8. Dict comprehensions e set comprehensions

### 8.1 Dict comprehension

```python
quadrados = {x: x * x for x in range(5)}
print(quadrados)
```

### 8.2 Set comprehension

```python
iniciais = {nome[0] for nome in ["Ana", "Alice", "Bruno", "Bianca"]}
print(iniciais)
```

Comprehensions nao sao exclusivas de listas.

## 9. Generator expressions

Se voce so quer produzir valores sob demanda, sem montar lista inteira, pode usar generator expression:

```python
g = (x * x for x in range(5))
print(g)
print(next(g))
print(next(g))
```

Comparacao:

- `[x * x for x in range(5)]` cria lista imediatamente;
- `(x * x for x in range(5))` cria generator lazy.

- **Lazy**: valor so e produzido quando realmente solicitado.

Isso ajuda a economizar memoria e trabalho desnecessario.

## 10. `yield` e generators

### 10.1 O que e um generator?

Generator e uma funcao especial que produz uma sequencia de valores ao longo do tempo usando `yield`.

Exemplo:

```python
def contar_ate(n):
    atual = 1
    while atual <= n:
        yield atual
        atual += 1
```

Uso:

```python
for numero in contar_ate(5):
    print(numero)
```

### 10.2 Diferenca para `return`

```python
def exemplo_return():
    return 10


def exemplo_yield():
    yield 10
```

`return` encerra a funcao e devolve um valor final.

`yield` suspende a execucao, devolve um valor e preserva o estado interno para continuar depois.

### 10.3 Estado suspenso

Isso e o coracao do generator:

- variaveis locais continuam preservadas;
- execucao retoma do ponto seguinte ao `yield`;
- o consumidor pede valores um a um com o protocolo de iteracao.

**Comparacao conceitual com C/Rust:**

- em C, voce normalmente precisaria gerenciar estado manualmente em struct + funcao;
- em Rust, ha iterators e async state machines;
- em Python, `yield` encapsula essa maquina de estados.

## 11. Generator na pratica

### 11.1 Arquivos grandes

Se voce ler tudo de uma vez:

```python
linhas = open("arquivo.txt").readlines()
```

voce materializa todas as linhas.

Se iterar sobre o arquivo:

```python
with open("arquivo.txt", "r", encoding="utf-8") as f:
    for linha in f:
        print(linha.strip())
```

o consumo tende a ser mais eficiente, mais proximo de processamento em fluxo.

### 11.2 Pipeline de transformacao

```python
def pares(valores):
    for x in valores:
        if x % 2 == 0:
            yield x


def quadrados(valores):
    for x in valores:
        yield x * x


resultado = quadrados(pares(range(10)))

for x in resultado:
    print(x)
```

Aqui temos pipeline lazy.

## 12. Criando seu proprio iterador

Embora generators sejam o caminho mais confortavel, voce pode criar um iterador manual.

```python
class Contador:
    def __init__(self, limite):
        self.limite = limite
        self.atual = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.atual >= self.limite:
            raise StopIteration
        self.atual += 1
        return self.atual
```

Uso:

```python
for n in Contador(3):
    print(n)
```

Isso te mostra o protocolo na forma mais explicita.

### 12.1 Quando preferir generator?

Na maioria dos casos, generator com `yield` e mais curto, mais claro e menos sujeito a erro.

## 13. Iteracao e consumo unico

Muitos iteradores e generators sao consumidos uma vez.

```python
g = (x for x in range(3))

print(list(g))
print(list(g))
```

Saida:

```text
[0, 1, 2]
[]
```

Depois de esgotado, acabou.

Isso importa muito em debug e em pipelines.

## 14. Exemplo completo da aula

```python
def ler_numeros():
    for x in range(1, 11):
        yield x


def filtrar_pares(valores):
    for valor in valores:
        if valor % 2 == 0:
            yield valor


def elevar_ao_quadrado(valores):
    for valor in valores:
        yield valor * valor


pipeline = elevar_ao_quadrado(filtrar_pares(ler_numeros()))

print("Consumindo pipeline:")
for item in pipeline:
    print(item)

nomes = ["ana", "bruno", "carla"]
maiusculos = [nome.upper() for nome in nomes]
print(maiusculos)

mapa_tamanho = {nome: len(nome) for nome in nomes}
print(mapa_tamanho)
```

### Explicacao linha por linha

- `yield x`: transforma a funcao em generator.
- `filtrar_pares(...)`: recebe iteravel e produz outro fluxo lazy.
- `elevar_ao_quadrado(...)`: aplica transformacao sem materializar tudo.
- `for item in pipeline`: consome o generator final.
- `[...] for ...`: list comprehension para criar lista imediatamente.
- `{... for ...}`: dict comprehension para mapa derivado.

## 16. Erros Comuns e Anti-Padroes

1. **Confundir iteravel com iterador**.
2. **Esquecer que generator e consumido uma vez**.
3. **Usar comprehension excessivamente complexa e ilegivel**.
4. **Criar lista inteira quando processamento lazy bastaria**.
5. **Nao entender que `for` depende de `iter()` e `next()` por baixo**.
6. **Usar indices manuais quando `enumerate` ou iteracao direta sao melhores**.
7. **Transformar tudo em generator mesmo quando a lista materializada seria mais simples e adequada**.
