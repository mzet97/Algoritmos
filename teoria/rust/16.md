# Aula 16 — FFI com C/C++

---

## Objetivo da Aula

Dominar a **Foreign Function Interface (FFI)** entre Rust e C/C++: chamar código C de Rust, expor Rust para C/C++, gerenciar **ownership na fronteira**, usar **`bindgen`** para gerar bindings automáticos, **`cxx`** para C++ seguro, **callbacks** cross-language, **wrapping de bibliotecas C**, e estratégias para **integrar Rust em codebases C/C++ existentes**. Ao final, você saberá fazer Rust conversar com qualquer biblioteca C/C++ de forma segura e idiomática.

Esta aula existe porque quase nenhum sistema real vive isolado. Mesmo que você escreva um módulo novo em Rust, é muito comum precisar conversar com bibliotecas antigas, APIs do sistema, kernels, bancos ou frameworks escritos em C e C++.

Mapa mental:

- **FFI** é a ponte binária entre linguagens;
- a maior dificuldade não é "chamar a função", mas definir corretamente layout, ABI, strings, ownership e destruição;
- na fronteira entre linguagens, o compilador já não consegue provar tudo sozinho.

## 1. FFI — O Que É e Por Que Precisamos

### 1.1 O problema

Rust não vive no vácuo. O mundo tem **bilhões de linhas de C/C++** em produção:
- Bibliotecas do sistema (libc, libm, libssl, zlib)
- Drivers e APIs do kernel
- Bancos de dados (SQLite, PostgreSQL libpq)
- GUI (Qt, GTK)
- Engines (Unity, Unreal)
- Codebases legadas de décadas

Rust precisa **interagir com todo esse ecossistema**. A FFI é a ponte.

- **FFI (Foreign Function Interface)**: mecanismo que permite a uma linguagem chamar funções, usar tipos e trocar dados com código compilado em outra linguagem.
- **Codebase legada**: base de código antiga que já existe em produção e não pode simplesmente ser reescrita inteira.

### 1.2 O modelo de FFI do Rust

Rust e C compartilham o **mesmo modelo de memória** (endereços lineares, stack, heap) e podem usar a **mesma convenção de chamada** (ABI C). Isso permite interoperabilidade **zero-cost** — sem marshalling, sem serialization, sem cópias.

Termos importantes:

- **Modelo de memória**: forma como dados vivem em endereços, stack, heap e registradores.
- **Convenção de chamada / ABI**: acordo binário sobre como argumentos são passados, quem limpa a stack, como o retorno volta e como símbolos são expostos.
- **Marshalling**: conversão/cópia de dados de um formato de uma linguagem para outro formato de outra linguagem.

Por que a ABI C é tão importante?

- porque ela é o ponto comum mais estável entre compiladores e linguagens de sistema;
- C++ puro, sem cuidado extra, introduz templates, exceptions, vtables e name mangling que dificultam muito essa interoperabilidade direta.

```
┌──────────────────┐         ┌──────────────────┐
│   Código Rust    │ ──────→ │   Código C/C++   │
│   (safe wrapper) │         │   (biblioteca)   │
│                  │ ←────── │                  │
└──────────────────┘         └──────────────────┘
        │                            │
        ▼                            ▼
   Rust ABI                    C ABI (extern "C")
   (estável)                   (estável, definida)
```

## 2. Chamando C de Rust

### 2.1 Declaração de funções C

Quando escrevemos um bloco `extern "C"`, estamos dizendo ao compilador Rust:

- "essas funções existem em outro lugar";
- "use a ABI C ao chamá-las";
- "não tente gerar o corpo delas aqui".

```rust
unsafe extern "C" {
    // Declaração — diz ao Rust que estas funções existem em algum lugar
    fn abs(input: i32) -> i32;
    fn strlen(s: *const i8) -> usize;
    fn puts(s: *const i8) -> i32;
    fn rand() -> i32;
    fn srand(seed: u32);
}

fn main() {
    unsafe {
        // Chamar funções C — sempre dentro de unsafe
        let x = -42;
        println!("abs({}) = {}", x, abs(x));

        // srand + rand
        srand(42);
        println!("rand() = {}", rand());

        // strlen — precisa converter String C
        use std::ffi::CString;
        let s = CString::new("olá mundo").expect("sem null bytes");
        println!("strlen(\"olá mundo\") = {}", strlen(s.as_ptr()));
    }
}
```

### 2.2 Linkando com bibliotecas C

- **Linkar** significa unir o seu código compilado com bibliotecas externas para formar o binário final.
- Biblioteca **estática** é incorporada ao executável final; biblioteca **dinâmica** é carregada em runtime.

```rust
// Linkar com bibliotecas específicas
#[link(name = "m")]     // libm — funções matemáticas
unsafe extern "C" {
    fn sqrt(x: f64) -> f64;
    fn sin(x: f64) -> f64;
    fn cos(x: f64) -> f64;
    fn pow(base: f64, exp: f64) -> f64;
}

#[link(name = "c")]     // libc — geralmente linkada automaticamente
unsafe extern "C" {
    fn printf(format: *const i8, ...) -> i32;
    fn malloc(size: usize) -> *mut std::ffi::c_void;
    fn free(ptr: *mut std::ffi::c_void);
}

fn main() {
    unsafe {
        println!("sqrt(2.0) = {}", sqrt(2.0));
        println!("sin(π/4) = {}", sin(std::f64::consts::FRAC_PI_4));
        println!("pow(2, 10) = {}", pow(2.0, 10.0));

        // malloc + free — alocando do heap do C
        let ptr = malloc(100);
        if !ptr.is_null() {
            println!("Alocou 100 bytes via malloc em {:?}", ptr);
            free(ptr);
            println!("Liberou via free");
        }
    }
}
```

### 2.3 Strings na fronteira FFI

O problema central: Rust usa `String`/`&str` (UTF-8, com comprimento). C usa `char*` (null-terminated, encoding dependente do locale).

Essa é uma das maiores fontes de bug em FFI.

- Rust pensa string como bytes UTF-8 + comprimento;
- C pensa string como ponteiro para bytes terminados por `\0`;
- se você confundir os dois modelos, o código pode ler memória demais, truncar dados ou quebrar em UTF-8 inválido.

```rust
use std::ffi::{CStr, CString};

fn main() {
    // === Rust → C (CString) ===

    // CString: String owned, null-terminated, compatível com C
    let rust_string = String::from("olá do Rust");
    let c_string = CString::new(rust_string).expect("sem null bytes internos");
    let c_ptr: *const i8 = c_string.as_ptr();  // *const i8 = const char*

    unsafe {
        printf("C recebeu: %s\n".as_ptr() as *const i8, c_ptr);
    }

    // === C → Rust (CStr) ===

    // CStr: borrow de string C (não owned, null-terminated)
    let c_str: &CStr = unsafe { CStr::from_ptr(c_ptr) };
    let rust_str: &str = c_str.to_str().expect("UTF-8 válido");
    println!("Rust leu de volta: '{}'", rust_str);

    // === Cuidado com strings C inválidas ===

    // CString NÃO aceita null bytes internos
    // CString::new("olá\0mundo") → Err — null byte no meio!

    // CStr pode não ser UTF-8 válido
    let bytes: &[u8] = c_str.to_bytes();  // bytes brutos (seguro)
    println!("Bytes: {:?}", bytes);
}
```

**Modelo mental:**

```
String (Rust)                 CString (Rust↔C)             char* (C)
┌──────────────────┐         ┌──────────────────────┐     ┌───────────────────┐
│ ptr  │ len │ cap │         │ ptr  │ len │ (null)   │     │ 'o' 'l' 'á' '\0' │
│  ▼               │         │  ▼                  │     └───────────────────┘
│ "olá do Rust"    │         │ "olá do Rust\0"     │          ↑
└──────────────────┘         └──────────────────────┘          │
   UTF-8, length-based         Null-terminated               c_ptr aponta aqui
   pode ter \0 interno         SEMPRE termina com \0
```

- **Null-terminated**: a string termina quando aparece um byte zero.
- **Encoding / codificação**: regra que converte texto humano em bytes.

### 2.4 Structs na fronteira — `#[repr(C)]`

`#[repr(C)]` existe porque duas linguagens só podem trocar structs com segurança se ambas concordarem exatamente sobre:

- ordem dos campos;
- padding;
- alinhamento;
- tamanho total.

```rust
#[repr(C)]          // Garante layout de memória idêntico ao C
#[derive(Debug)]
struct PontoC {
    x: f64,
    y: f64,
}

#[repr(C)]
struct RetanguloC {
    inicio: PontoC,
    fim: PontoC,
}

// Função C esperada:
// double area_retangulo(struct RetanguloC* r);
unsafe extern "C" {
    fn area_retangulo(r: *const RetanguloC) -> f64;
}

// Se não temos a função C, implementamos em Rust:
#[unsafe(no_mangle)]
pub extern "C" fn area_retangulo(r: *const RetanguloC) -> f64 {
    unsafe {
        let r = &*r;
        let largura = (r.fim.x - r.inicio.x).abs();
        let altura = (r.fim.y - r.inicio.y).abs();
        largura * altura
    }
}

fn main() {
    let r = RetanguloC {
        inicio: PontoC { x: 0.0, y: 0.0 },
        fim: PontoC { x: 10.0, y: 5.0 },
    };

    unsafe {
        let a = area_retangulo(&r);
        println!("Área: {}", a);  // 50.0
    }

    // Verificar layout
    println!("sizeof PontoC: {}", std::mem::size_of::<PontoC>());     // 16
    println!("alignof PontoC: {}", std::mem::align_of::<PontoC>());   // 8
}
```

**`#[repr(C)]` faz 3 coisas:**
1. Campos ficam na **ordem de declaração**.
2. Padding segue as **regras do C** (alinhamento natural).
3. Tamanho total é **compatível com struct C equivalente**.

Sem `#[repr(C)]`, Rust pode reordenar campos para otimizar:

```rust
// SEM repr(C) — Rust pode reordenar
struct A {
    a: u8,     // 1 byte
    b: u64,    // 8 bytes → Rust pode colocar ANTES de a para alinhamento
    c: u8,     // 1 byte
}
// sizeof: pode ser 16 (com padding) ou diferente

// COM repr(C) — layout idêntico ao C
#[repr(C)]
struct B {
    a: u8,     // offset 0
              // 7 bytes padding
    b: u64,    // offset 8
    c: u8,     // offset 16
              // 7 bytes padding
}
// sizeof: 24 (idêntico ao struct C)
```

## 3. Expondo Rust para C/C++

### 3.1 Funções exportadas

Quando exportamos Rust para C, o problema se inverte: agora o outro lado precisa conseguir localizar e chamar nossas funções corretamente.

```rust
// #[unsafe(no_mangle)] — impede name mangling (Rust renomeia funções por padrão)
// extern "C" — usa convenção de chamada C
```

- **Name mangling**: técnica usada por compiladores para codificar tipos e namespaces no nome binário do símbolo.
- `#[unsafe(no_mangle)]` deixa o símbolo com nome estável e simples, como C espera. O `unsafe` no atributo obriga o autor a verificar que o nome exportado não colide com outro símbolo global; é exigido na edição 2024 e aceito nas anteriores desde Rust 1.82.

Consulte o [Rust Edition Guide: Unsafe attributes](https://doc.rust-lang.org/edition-guide/rust-2024/unsafe-attributes.html) para o contrato desse atributo.

```rust
use std::ffi::CString;

/// Soma dois inteiros — exportada como "rust_soma"
#[unsafe(no_mangle)]
pub extern "C" fn rust_soma(a: i32, b: i32) -> i32 {
    a + b  // código 100% safe dentro da função exportada
}

/// Cria uma string — caller deve liberar com rust_libera_string
#[unsafe(no_mangle)]
pub extern "C" fn rust_cria_string() -> *mut i8 {
    let s = CString::new("Criado em Rust!").unwrap();
    s.into_raw()  // transfere ownership para C (não dropa!)
}

/// Libera string criada por rust_cria_string
#[unsafe(no_mangle)]
pub extern "C" fn rust_libera_string(ptr: *mut i8) {
    if !ptr.is_null() {
        unsafe {
            // retoma ownership para que Drop seja chamado
            let _ = CString::from_raw(ptr);
        }
    }
}

/// Processa buffer C — recebe ponteiro e tamanho
#[unsafe(no_mangle)]
pub extern "C" fn rust_soma_buffer(data: *const i32, len: usize) -> i32 {
    if data.is_null() {
        return 0;
    }
    let slice = unsafe { std::slice::from_raw_parts(data, len) };
    slice.iter().sum()
}
```

### 3.2 Header C correspondente

```c
// rust_lib.h — header para o código C usar
#ifndef RUST_LIB_H
#define RUST_LIB_H

#include <stdint.h>

int32_t rust_soma(int32_t a, int32_t b);
char* rust_cria_string(void);

#endif
```

### 3.3 Usando de C

```c
// main.c
#include <stdio.h>
#include "rust_lib.h"

int main(void) {
    // Chamar função Rust
    int32_t resultado = rust_soma(10, 20);
    printf("rust_soma(10, 20) = %d\n", resultado);

    // String de Rust
    char* s = rust_cria_string();
    printf("String do Rust: %s\n", s);
    rust_libera_string(s);  // IMPORTANTE: liberar!

    // Buffer
    int32_t buffer[] = {1, 2, 3, 4, 5};
    int32_t soma = rust_soma_buffer(buffer, 5);
    printf("Soma do buffer: %d\n", soma);

    return 0;
}
```

**Compilar tudo:**

```bash
# Compilar Rust como biblioteca estática
rustc --crate-type staticlib -o librust_lib.a rust_lib.rs

# Compilar C e linkar com Rust
gcc main.c -L. -lrust_lib -o programa

# Ou biblioteca dinâmica
rustc --crate-type cdylib -o librust_lib.so rust_lib.rs
gcc main.c -L. -lrust_lib -o programa
```

### 3.4 Tipos de biblioteca Rust

Escolher `staticlib`, `cdylib` ou `lib` muda completamente quem poderá consumir o artefato gerado e em que momento o código será ligado ao restante do sistema.

| Tipo (`--crate-type`) | Extensão | Uso |
|----------------------|----------|-----|
| `staticlib` | `.a` / `.lib` | Linkar estaticamente com C/C++ |
| `cdylib` | `.so` / `.dylib` / `.dll` | Biblioteca dinâmica para C |
| `lib` | `.rlib` | Biblioteca Rust (usada por outros crates Rust) |

## 4. Ownership na Fronteira FFI

### 4.1 As regras

A fronteira FFI é onde **ownership muda de mão**. Sem regras claras, vazamentos e double-frees ocorrem:

Esse é o coração da aula.

- se não estiver formalmente definido quem aloca e quem libera, você terá `memory leak`, `double free` ou uso após liberação;
- na FFI, ownership precisa ser tratado como contrato explícito entre as duas linguagens.

| Direção | Quem aloca? | Quem libera? | Mecanismo |
|---------|------------|-------------|-----------|
| Rust → C | Rust (`Box`, `CString` etc.) | Rust, por função de liberação exportada para C | `Box::into_raw` / `Box::from_raw`, `CString::into_raw` / `CString::from_raw` |
| C → Rust | C (malloc) | C (free) | Rust empresta via ponteiro |
| C → Rust (transfer) | C (malloc) | Rust, pela função de liberação compatível com o alocador de C | `free` ou API de liberação fornecida pela biblioteca C; nunca `CString::from_raw` |

`CString::from_raw` aceita somente ponteiros obtidos anteriormente com `CString::into_raw`. Misturar `malloc`/`free` com o alocador de Rust pode corromper a memória. Também não se deve chamar `free` diretamente em um ponteiro produzido por `Box::into_raw`.

Veja as condições de segurança de [`CString::from_raw`](https://doc.rust-lang.org/std/ffi/struct.CString.html#method.from_raw).

Os exemplos com ponteiros recebidos de C pressupõem que o chamador fornece endereços válidos, alinhados e acessíveis pelo comprimento informado, sem acesso concorrente conflitante. Testar apenas `null` não comprova essas condições. O chamador também deve devolver cada alocação uma única vez à função Rust correspondente. No `BufferTexto`, não pode alterar `dados` ou `capacidade`; `tamanho` só pode indicar bytes efetivamente inicializados, até a capacidade.

### 4.2 Box na fronteira — transferindo ownership de structs

```rust
#[repr(C)]
pub struct Nodo {
    pub valor: i32,
    pub proximo: *mut Nodo,  // ponteiro bruto — C gerencia
}

impl Nodo {
    fn novo(valor: i32) -> *mut Nodo {
        let nodo = Box::new(Nodo { valor, proximo: std::ptr::null_mut() });
        Box::into_raw(nodo)  // transfere para C — Rust não dropa!
    }
}

// Criar nodo — C recebe ownership
#[unsafe(no_mangle)]
pub extern "C" fn nodo_criar(valor: i32) -> *mut Nodo {
    Nodo::novo(valor)
}

// Liberar nodo — C devolve ownership para Rust dropar
#[unsafe(no_mangle)]
pub extern "C" fn nodo_liberar(ptr: *mut Nodo) {
    if !ptr.is_null() {
        unsafe { drop(Box::from_raw(ptr)); }  // retoma ownership → Drop chamado
    }
}

// Ler valor — C empresta, sem transferir ownership
#[unsafe(no_mangle)]
pub extern "C" fn nodo_valor(ptr: *const Nodo) -> i32 {
    if ptr.is_null() {
        return 0;
    }
    unsafe { (*ptr).valor }
}
```

**Modelo mental:**

```
C chama nodo_criar(42):
  Rust: Box::new(Nodo) → aloca no heap
  Box::into_raw(nodo) → retorna ponteiro bruto, NÃO dropa
  C recebe ponteiro → C é dono agora

C usa nodo_valor(ptr):
  Rust: lê *ptr → empresta, não modifica ownership

C chama nodo_liberar(ptr):
  Rust: Box::from_raw(ptr) → retoma ownership
  drop(box) → Drop chamado, memória liberada
```

### 4.3 Callbacks — C chamando Rust de volta

- **Callback**: função passada como argumento para ser chamada mais tarde por outra biblioteca ou sistema.
- Eles são comuns em GUIs, bibliotecas de rede, APIs de eventos e bibliotecas C antigas.

```rust
use std::ffi::CStr;

// Tipo do callback: função C que recebe string e retorna int
type CallbackFn = extern "C" fn(*const i8) -> i32;

// Função C simulada que recebe um callback
unsafe extern "C" {
    // Simulamos com uma implementação Rust
    // fn processa_com_callback(data: *const i8, cb: CallbackFn) -> i32;
}

// Implementar o callback em Rust
extern "C" fn meu_callback(s: *const i8) -> i32 {
    let c_str = unsafe { CStr::from_ptr(s) };
    match c_str.to_str() {
        Ok(texto) => {
            println!("Callback recebeu: '{}'", texto);
            texto.len() as i32
        }
        Err(_) => -1,
    }
}

// Função que registra e usa callback
#[unsafe(no_mangle)]
pub extern "C" fn rust_registra_callback() {
    let mensagem = CString::new("dados do Rust").unwrap();
    let resultado = meu_callback(mensagem.as_ptr());
    println!("Callback retornou: {}", resultado);
}
```

### 4.4 Callback com state (userdata)

- **userdata**: ponteiro opaco passado de volta ao callback para que ele tenha acesso a algum estado associado.
- Isso existe porque uma função C isolada normalmente não carrega contexto lexical como uma closure Rust carregaria.

```rust

// Tipo do callback com userdata
type CallbackComState = extern "C" fn(i32, *mut c_void);

// Estado que passamos para C
#[repr(C)]
struct EstadoCallback {
    contador: i32,
    prefixo: [u8; 16],
}

extern "C" fn callback_com_state(valor: i32, userdata: *mut c_void) {
    let estado = unsafe { &mut *(userdata as *mut EstadoCallback) };
    estado.contador += 1;
    let prefixo = std::str::from_utf8(&estado.prefixo)
        .unwrap_or("???")
        .trim_end_matches('\0');
    println!("{} [{}]: valor={}", prefixo, estado.contador, valor);
}

fn main() {
    let mut estado = EstadoCallback {
        contador: 0,
        prefixo: [0u8; 16],
    }
    let prefixo = b"Evento";
    estado.prefixo[..prefixo.len()].copy_from_slice(prefixo);

    let ptr_estado = &mut estado as *mut EstadoCallback as *mut c_void;

    // Simular chamadas de callback
    for i in 1..=5 {
        callback_com_state(i * 10, ptr_estado);
    }
}
```

## 5. `bindgen` — Bindings Automáticos para C

### 5.1 O problema

Bibliotecas C têm **centenas de structs, enums, funções, defines, typedefs**. Escrever bindings manualmente é:
- Tedioso (milhares de linhas)
- Propenso a erros (layout errado, tipo errado)
- Frágil (muda quando a biblioteca muda)

- **Binding**: declaração em Rust que espelha a assinatura e os tipos de uma API externa.
- `bindgen` existe para reduzir erro humano e manter alinhamento com headers reais.

### 5.2 `bindgen` — gera bindings Rust automaticamente

```bash
# Instalar bindgen
cargo install bindgen-cli

# Ou adicionar como build dependency no Cargo.toml
```

Exemplo: gerar bindings para um header C fictício:

```c
// minha_lib.h
#ifndef MINHA_LIB_H
#define MINHA_LIB_H

#include <stdint.h>
#include <stddef.h>

typedef enum {
    STATUS_OK = 0,
    STATUS_ERRO = -1,
    STATUS_NAO_ENCONTRADO = -2,
} Status;

typedef struct {
    int32_t x;
    int32_t y;
    int32_t largura;
    int32_t altura;
} Retangulo;

Status retangulo_criar(int32_t x, int32_t y, int32_t w, int32_t h, Retangulo* out);
int32_t retangulo_area(const Retangulo* r);
void retangulo_transladar(Retangulo* r, int32_t dx, int32_t dy);
const char* retangulo_para_string(const Retangulo* r);

#endif
```

```bash
# Gerar bindings
bindgen minha_lib.h -o bindings.rs -- -I/caminho/para/headers
```

Resultado (`bindings.rs`):

```rust
// Gerado automaticamente por bindgen — NÃO EDITAR
#[repr(i32)]
#[derive(Debug, Copy, Clone, PartialEq, Eq)]
pub enum Status {
    STATUS_OK = 0,
    STATUS_ERRO = -1,
    STATUS_NAO_ENCONTRADO = -2,
}

#[repr(C)]
#[derive(Debug, Copy, Clone)]
pub struct Retangulo {
    pub x: i32,
    pub y: i32,
    pub largura: i32,
    pub altura: i32,
}

unsafe extern "C" {
    pub fn retangulo_criar(
        x: i32, y: i32, w: i32, h: i32, out: *mut Retangulo,

    pub fn retangulo_area(r: *const Retangulo) -> i32;

```

### 5.3 Usando bindings gerados com safe wrappers

```rust
// bindings.rs — gerado por bindgen (NÃO EDITAR)
mod bindings {
    #[repr(C)]
    #[derive(Debug, Copy, Clone)]
    pub struct Retangulo {
        pub x: i32, pub y: i32,
        pub largura: i32, pub altura: i32,
    }

    #[repr(i32)]
    #[derive(Debug, Copy, Clone, PartialEq, Eq)]
    pub enum Status { Ok = 0, Erro = -1, NaoEncontrado = -2 }

    unsafe extern "C" {
        pub fn retangulo_criar(x: i32, y: i32, w: i32, h: i32, out: *mut Retangulo) -> Status;
        pub fn retangulo_area(r: *const Retangulo) -> i32;
        pub fn retangulo_transladar(r: *mut Retangulo, dx: i32, dy: i32);
        pub fn retangulo_para_string(r: *const Retangulo) -> *const i8;
    }
}

// === Safe wrapper — API idiomática Rust ===

#[derive(Debug)]
pub struct Rect {
    inner: bindings::Retangulo,
}

impl Rect {
    pub fn novo(x: i32, y: i32, largura: i32, altura: i32) -> Result<Self, String> {
        let mut inner = bindings::Retangulo { x: 0, y: 0, largura: 0, altura: 0 };
        let status = unsafe {
            bindings::retangulo_criar(x, y, largura, altura, &mut inner)
        };
        match status {
            bindings::Status::Ok => Ok(Rect { inner }),
            _ => Err(format!("Erro ao criar retângulo: {:?}", status)),
        }
    }

    pub fn area(&self) -> i32 {
        unsafe { bindings::retangulo_area(&self.inner) }
    }

    pub fn transladar(&mut self, dx: i32, dy: i32) {
        unsafe { bindings::retangulo_transladar(&mut self.inner, dx, dy) }
    }

    pub fn para_string(&self) -> String {
        unsafe {
            let ptr = bindings::retangulo_para_string(&self.inner);
            CStr::from_ptr(ptr).to_string_lossy().into_owned()
        }
    }
}

use std::ffi::CStr;

fn main() {
    let mut r = Rect::novo(10, 20, 100, 50).unwrap();
    println!("Área: {}", r.area());
    r.transladar(5, -10);
    println!("{}", r.para_string());
}
```

## 6. `cxx` — FFI Seguro com C++

### 6.1 O problema do C++

C++ tem name mangling complexo, exceptions, classes, templates, STL, vtables... A FFI C tradicional não suporta nada disso. `cxx` resolve isso:

`cxx` existe porque a fronteira direta com C++ costuma ser muito mais difícil do que com C puro.

- C é o "denominador comum" binário;
- C++ acrescenta recursos de linguagem que não têm correspondência trivial na ABI C;
- `cxx` cria uma ponte mais tipada e muito mais segura para os casos suportados.

```toml
# Cargo.toml
[dependencies]
cxx = "1.0"

[build-dependencies]
cxx-build = "1.0"
```

### 6.2 Definindo a bridge

```rust
// src/main.rs
use cxx::let_cxx_string;

#[cxx::bridge]
mod ffi {
    // Tipos compartilhados entre Rust e C++
    struct Ponto {
        x: f64,
        y: f64,
    }

    // Funções C++ que Rust pode chamar
    extern "C++" {
        fn distancia(a: &Ponto, b: &Ponto) -> f64;
        fn saudacao(nome: &str) -> String;
    }

    // Funções Rust que C++ pode chamar
    extern "Rust" {
        fn processar_ponto(p: &Ponto) -> f64;
    }
}

// Implementação Rust (exportada para C++)
fn processar_ponto(p: &ffi::Ponto) -> f64 {
    (p.x * p.x + p.y * p.y).sqrt()
}

fn main() {
    let a = ffi::Ponto { x: 0.0, y: 0.0 };
    let b = ffi::Ponto { x: 3.0, y: 4.0 };

    // Chamar C++ de Rust — safe!
    let d = ffi::distancia(&a, &b);
    println!("Distância: {}", d);  // 5.0

    let msg = ffi::saudacao("Rust");
    println!("{}", msg);
}
```

```cpp
// src/main.cpp
#include "rust/cxx.h"
#include <cmath>
#include <string>
#include <sstream>

struct Ponto {
    double x, y;
};

double distancia(const Ponto& a, const Ponto& b) {
    double dx = b.x - a.x;
    double dy = b.y - a.y;
    return std::sqrt(dx * dx + dy * dy);
}

rust::String saudacao(rust::Str nome) {
    std::ostringstream oss;
    oss << "Olá do C++, " << nome << "!";
    return rust::String(oss.str().c_str());
}
```

**Vantagens do `cxx`:**
- **Safe** — verifica tipos em tempo de compilação.
- **Sem `unsafe`** — a bridge gera código seguro.
- **Suporta** `String`, `&str`, `Vec<T>`, `Box<T>`, `unique_ptr`, `shared_ptr`.
- **Exceptions** — C++ exceptions são convertidas em `Result`.
- **Tipos compartilhados** — structs definidas uma vez, usadas em ambos.

Isso é importante porque reduz uma das fontes clássicas de bug em integração: declarar o mesmo tipo duas vezes de maneira levemente diferente em cada lado.

### 6.3 Tipos suportados pelo cxx

| Rust | C++ | Descrição |
|------|-----|-----------|
| `i32` | `int32_t` | Inteiro |
| `f64` | `double` | Float |
| `bool` | `bool` | Booleano |
| `String` | `rust::String` | String owned |
| `&str` | `rust::Str` | String borrowed |
| `Vec<T>` | `rust::Vec<T>` | Vetor |
| `Box<T>` | `rust::Box<T>` | Heap pointer |
| `UniquePtr<T>` | `std::unique_ptr<T>` | C++ unique_ptr |
| `SharedPtr<T>` | `std::shared_ptr<T>` | C++ shared_ptr |

## 7. Estratégias de Integração

### 7.1 Padrões de migração Rust em codebase C/C++

| Estratégia | Descrição | Quando |
|------------|-----------|--------|
| **Leaf-first** | Substituir funções leaf (que não chamam nada mais) | Menor risco |
| **Wrapper** | Rust envolve biblioteca C com API idiomática | Usar lib C existente |
| **Service boundary** | Rust como serviço separado, comunica via IPC/gRPC | Arquitetura de microsserviços |
| **Progressive** | Um módulo por vez, testado extensivamente | Migração gradual |

Essas estratégias existem porque "reescrever tudo em Rust" raramente é viável em produção. Engenharia de migração quase sempre é incremental.

### 7.2 Checklist para wrapping de biblioteca C

```
1. Ler documentação da biblioteca C
2. Identificar structs, funções, enums, defines
3. Gerar bindings com bindgen
4. Criar tipos Rust idiomáticos (structs que wrap ponteiros C)
5. Implementar Drop para liberar recursos C
6. Converter erros C em Result<T, Erro>
7. Converter strings C → String Rust
8. Escrever testes (unit + integration)
9. Documentar invariants e ownership
10. Rodar com Miri para verificar UB
```

### 7.3 Exemplo completo de wrapper — simulando SQLite

```rust
use std::ffi::{CStr, CString};
use std::ptr;
use std::fmt;

// Simulação de tipos C que viriam do bindgen
#[repr(C)]
struct DbConnection {
    // campos opacos — não sabemos o conteúdo
    _private: [u8; 0],
}

#[repr(C)]
#[derive(Debug, Copy, Clone)]
enum DbStatus {
    Ok = 0,
    Erro = 1,
    NaoEncontrado = 2,
}

// Funções C simuladas
unsafe extern "C" {
    fn db_abrir(caminho: *const i8, conn: *mut *mut DbConnection) -> DbStatus;
    fn db_fechar(conn: *mut DbConnection);
    fn db_executar(conn: *mut DbConnection, sql: *const i8) -> DbStatus;
    fn db_ultimo_erro(conn: *mut DbConnection) -> *const i8;
}

// === Safe Wrapper ===

pub struct Database {
    conn: *mut DbConnection,
}

#[derive(Debug)]
pub enum DbError {
    Conexao(String),
    Execucao(String),
    NaoEncontrado,
}

impl fmt::Display for DbError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            DbError::Conexao(s) => write!(f, "Erro de conexão: {}", s),
            DbError::Execucao(s) => write!(f, "Erro de execução: {}", s),
            DbError::NaoEncontrado => write!(f, "Não encontrado"),
        }
impl std::error::Error for DbError {}

impl Database {
    pub fn abrir(caminho: &str) -> Result<Self, DbError> {
        let c_path = CString::new(caminho).map_err(|_| {
            DbError::Conexao("caminho contém null byte".into())
        })?;

        let mut conn: *mut DbConnection = ptr::null_mut();
        let status = unsafe {
            db_abrir(c_path.as_ptr(), &mut conn)
        };

        match status {
            DbStatus::Ok => {
                if conn.is_null() {
                    Err(DbError::Conexao("conexão null".into()))
                } else {
                    Ok(Database { conn })
                }
            }
            _ => {
                let msg = unsafe {
                    CStr::from_ptr(db_ultimo_erro(conn))
                        .to_string_lossy()
                        .into_owned()
                };
                Err(DbError::Conexao(msg))
            }
        }
    }

    pub fn executar(&self, sql: &str) -> Result<(), DbError> {
        let c_sql = CString::new(sql).map_err(|_| {
            DbError::Execucao("SQL contém null byte".into())
        })?;

        let status = unsafe {
            db_executar(self.conn, c_sql.as_ptr())
        };

        match status {
            DbStatus::Ok => Ok(()),
            _ => {
                let msg = unsafe {
                    CStr::from_ptr(db_ultimo_erro(self.conn))
                        .to_string_lossy()
                        .into_owned()
                };
                Err(DbError::Execucao(msg))
            }
        }
    }
}

// Drop garante que a conexão é fechada
impl Drop for Database {
    fn drop(&mut self) {
        if !self.conn.is_null() {
            unsafe { db_fechar(self.conn); }
        }
    }
}

fn main() {
    // API completamente safe — sem unsafe visível!
    match Database::abrir("meu_banco.db") {
        Ok(db) => {
            println!("Conectado!");
            match db.executar("CREATE TABLE test (id INT)") {
                Ok(()) => println!("Tabela criada"),
                Err(e) => println!("Erro: {}", e),
            }
        }
        Err(e) => println!("Falha: {}", e),
    }
    // db.drop() → db_fechar() chamado automaticamente
}
```

## 8. Exemplo Completo — Biblioteca Rust Chamável de C

```rust
// aula16_ffi.rs
// Compilar como biblioteca:
//   rustc --crate-type cdylib -o libaula16.so aula16_ffi.rs  (Linux)
//   rustc --crate-type cdylib -o aula16.dll aula16_ffi.rs     (Windows)
//   rustc --crate-type staticlib -o libaula16.a aula16_ffi.rs (Linux static)

use std::ffi::{CStr, CString};
use std::ptr;
use std::slice;

// === Tipos compartilhados ===

#[repr(C)]
pub struct ResultadoEstatistica {
    pub media: f64,
    pub minimo: i32,
    pub maximo: i32,
    pub soma: i64,
    pub contagem: usize,
}

#[repr(C)]
pub struct BufferTexto {
    pub dados: *mut u8,
    pub tamanho: usize,
    pub capacidade: usize,
}

// === Funções exportadas para C ===

/// Calcula estatísticas de um array de inteiros
#[unsafe(no_mangle)]
pub extern "C" fn estatisticas(data: *const i32, len: usize) -> ResultadoEstatistica {
    if data.is_null() || len == 0 {
        return ResultadoEstatistica {
            media: 0.0, minimo: 0, maximo: 0, soma: 0, contagem: 0,
        };
    }

    let slice = unsafe { slice::from_raw_parts(data, len) };
    let soma: i64 = slice.iter().map(|&x| x as i64).sum();
    let minimo = *slice.iter().min().unwrap_or(&0);
    let maximo = *slice.iter().max().unwrap_or(&0);
    let media = soma as f64 / len as f64;

    ResultadoEstatistica { media, minimo, maximo, soma, contagem: len }
}

/// Inverte uma string (aloca nova string — caller deve liberar com libera_string)
#[unsafe(no_mangle)]
pub extern "C" fn inverter_string(s: *const i8) -> *mut i8 {
    if s.is_null() {
        return ptr::null_mut();
    }

    let c_str = unsafe { CStr::from_ptr(s) };
    let rust_str = match c_str.to_str() {
        Ok(s) => s,
        Err(_) => return ptr::null_mut(),
    };

    let invertido: String = rust_str.chars().rev().collect();
    let c_result = CString::new(invertido).unwrap();
    c_result.into_raw()  // transfere para C
}

/// Filtra valores acima de um limite — retorna novo array (caller deve liberar)
#[unsafe(no_mangle)]
pub extern "C" fn filtrar_maiores(
    data: *const i32,
    len: usize,
    limite: i32,
    out_len: *mut usize,
) -> *mut i32 {
    if data.is_null() || out_len.is_null() {
        return ptr::null_mut();
    }

    let slice = unsafe { slice::from_raw_parts(data, len) };
    let filtrados: Vec<i32> = slice.iter().copied().filter(|&x| x > limite).collect();

    unsafe { *out_len = filtrados.len(); }

    if filtrados.is_empty() {
        return ptr::null_mut();
    }

    // Converter Box<[i32]> em buffer bruto; C deve devolvê-lo com o mesmo len.
    let mut filtrados = filtrados.into_boxed_slice();
    let ptr = filtrados.as_mut_ptr();
    std::mem::forget(filtrados);  // Rust retoma a alocação em libera_array.
    ptr
}

/// Libera array alocado por filtrar_maiores
#[unsafe(no_mangle)]
pub extern "C" fn libera_array(ptr: *mut i32, len: usize) {
    if !ptr.is_null() && len > 0 {
        unsafe {
            let fatia = ptr::slice_from_raw_parts_mut(ptr, len);
            drop(Box::from_raw(fatia));
        };
    }
}

/// Libera string alocada por Rust
#[unsafe(no_mangle)]
pub extern "C" fn libera_string(ptr: *mut i8) {
    if !ptr.is_null() {
        unsafe { let _ = CString::from_raw(ptr); }
    }
}

/// Callback: processa cada elemento com função C
type Processador = extern "C" fn(i32) -> i32;

#[unsafe(no_mangle)]
pub extern "C" fn mapear_array(
    data: *mut i32,
    len: usize,
    processador: Processador,
) {
    if data.is_null() {
        return;
    }
    let slice = unsafe { slice::from_raw_parts_mut(data, len) };
    for elem in slice.iter_mut() {
        *elem = processador(*elem);
    }
}

/// Cria buffer de texto (Rust allocado)
#[unsafe(no_mangle)]
pub extern "C" fn cria_buffer_texto(capacidade: usize) -> *mut BufferTexto {
    let mut buf = Vec::with_capacity(capacidade);
    let capacidade_real = buf.capacity();
    let ptr = buf.as_mut_ptr();
    std::mem::forget(buf);

    Box::into_raw(Box::new(BufferTexto {
        dados: ptr,
        tamanho: 0,
        capacidade: capacidade_real,
    }))
}

/// Libera buffer de texto
#[unsafe(no_mangle)]
pub extern "C" fn libera_buffer(buf: *mut BufferTexto) {
    if buf.is_null() { return; }
    unsafe {
        let buf = Box::from_raw(buf);
        if !buf.dados.is_null() && buf.capacidade > 0 {
            let _ = Vec::from_raw_parts(buf.dados, buf.tamanho, buf.capacidade);
        }
    }
}

// === Demonstração standalone (sem C) ===

extern "C" fn dobra(x: i32) -> i32 { x * 2 }

fn main() {
    println!("=== FFI Demonstração ===\n");

    // Estatísticas
    let dados = [10, 20, 30, 40, 50];
    let r = estatisticas(dados.as_ptr(), dados.len());
    println!("Estatísticas: media={:.1}, min={}, max={}, soma={}, count={}",
        r.media, r.minimo, r.maximo, r.soma, r.contagem);

    // Inverter string
    let s = CString::new("Rust").unwrap();
    let inv = inverter_string(s.as_ptr());
    unsafe {
        let inv_str = CStr::from_ptr(inv);
        println!("Invertido: {:?}", inv_str);
        libera_string(inv);
    }

    // Filtrar
    let dados2 = [5, 15, 25, 3, 30, 10];
    let mut out_len: usize = 0;
    let filtrados = filtrar_maiores(dados2.as_ptr(), dados2.len(), 10, &mut out_len);
    unsafe {
        let slice = std::slice::from_raw_parts(filtrados, out_len);
        println!("Filtrados (>10): {:?}", slice);
        libera_array(filtrados, out_len);
    }

    // Callback
    let mut dados3 = [1, 2, 3, 4, 5];
    mapear_array(dados3.as_mut_ptr(), dados3.len(), dobra);
    println!("Mapeado (×2): {:?}", dados3);

    // Buffer
    let buf = cria_buffer_texto(256);
    unsafe {
        println!("Buffer criado: cap={}", (*buf).capacidade);
        libera_buffer(buf);
    }
}
```

## 9. Erros Comuns

### Erro 1: Esquecer `#[repr(C)]`

```rust
// SEM repr(C) — layout indefinido, incompatível com C
struct Ponto { x: f64, y: f64 }

// COM repr(C) — layout garantido
#[repr(C)]
struct PontoC { x: f64, y: f64 }
```

### Erro 2: Não liberar memória na fronteira

```rust
// Rust aloca, C não libera → MEMORY LEAK
let s = CString::new("olá").unwrap();
let ptr = s.into_raw();  // transfere para C
// Se C nunca chama libera_string(ptr) → vaza!

// C aloca, Rust não libera → MEMORY LEAK
// Se Rust recebe ptr de malloc e nunca chama free → vaza!
```

### Erro 3: Passar String Rust diretamente para C

```rust
let s = String::from("olá");
// funcao_c(s.as_ptr());  // PODE NÃO TER NULL TERMINATOR!
// String NÃO garante null terminator

let cs = CString::new(s).unwrap();
// funcao_c(cs.as_ptr());  // OK — CString garante null terminator
```

### Erro 4: Usar tipos Rust em `extern "C"`

```rust
// ERRADO — Vec<T> não é compatível com C!
// #[unsafe(no_mangle)]
// pub extern "C" fn retorna_vec() -> Vec<i32> { ... }

// CORRETO — retorna ponteiro + tamanho
#[unsafe(no_mangle)]
pub extern "C" fn retorna_array(len: *mut usize) -> *mut i32 {
    let v = vec![1, 2, 3];
    unsafe { *len = v.len(); }
    let mut v = v;
    let ptr = v.as_mut_ptr();
    std::mem::forget(v);
    ptr
}
```

### Erro 5: Panic através da fronteira FFI

```rust
// UB — panic não pode cruzar a fronteira C!
#[unsafe(no_mangle)]
pub extern "C" fn funcao_exportada(x: i32) -> i32 {
    // panic!("erro!");  // UB quando chamado de C!
    // Se panic ocorrer, é UB — o unwind não funciona através de C frames

    // Solução: catch_unwind
    std::panic::catch_unwind(|| {
        // código que pode panic
        if x < 0 { return -1; }
        x * 2
    }).unwrap_or(-1)
}
```

## 10. Comparação — Abordagens de FFI

| Abordagem | Complexidade | Segurança | Quando usar |
|-----------|-------------|-----------|-------------|
| `extern "C"` manual | Alta | Baixa (muito unsafe) | APIs C simples, poucas funções |
| `bindgen` | Média | Média (gera bindings, mas unsafe) | Bibliotecas C grandes |
| `cxx` | Média | Alta (safe bridge) | C++ com tipos complexos |
| `cc` crate | Baixa | Média | Compilar C junto com Rust |
| `autocxx` | Média | Alta | C++ automático (experimental) |
| IPC/gRPC | Baixa | Alta | Serviços separados |
