# Aula 05 (Rust): pistas graduais

Volte aos [exercicios](../05.md#9-exercícios-obrigatórios) antes de abrir as solucoes.

1. `pode_conter` compara as duas dimensoes sem rotacao; `quadrado` e funcao associada (sem `self`).
2. No `match` da forma, desestruture cada variante para chegar nos numeros.
3. No encadeamento: `and_then` recebe e devolve `Option`; `map` so transforma o conteudo.
4. Na lista com `Box`, `comprimento` e recursivo; o caso `Nil` e a base de tudo.
5. No tokenizer, numeros consomem digitos e ponto; letras consomem identificador; cada outro caractere e um token so.
6. Com `?`, o erro precisa de conversao para o tipo de erro da funcao que propaga.
