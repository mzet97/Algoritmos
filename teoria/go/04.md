# Aula 4 - Arrays, slices, strings, bytes e runes

---

## Objetivo da Aula

Entender como Go representa sequencias de dados e texto: arrays, slices, strings, bytes e runes. Construir o modelo mental correto para distinguir estrutura fixa de visao dinamica, texto UTF-8 de unidades numericas e copia de valores de compartilhamento de backing array. Ao final, voce deve conseguir manipular colecoes lineares sem confundir tamanho, capacidade e representacao de texto.

---

## 1. Arrays

Array em Go e uma sequencia de tamanho fixo cujo tamanho faz parte do tipo.

```go
var numeros [3]int
fmt.Println(numeros)
```

- `[3]int` significa "array de 3 inteiros".
- `[4]int` e outro tipo diferente.

Exemplo com inicializacao:

```go
idades := [3]int{10, 20, 30}
fmt.Println(idades)
```

### 1.1 O tamanho faz parte do tipo

```go
var a [3]int
var b [4]int

// a = b // erro de compilacao
```

Esse detalhe e importante e difere do modelo mental de C, em que arrays frequentemente decaem para ponteiros em varias expressoes.

## 2. Slices

Slice e uma das estruturas mais importantes de Go.

- **Slice**: visao sobre uma sequencia de elementos, normalmente apoiada por um array subjacente.

Exemplo:

```go
numeros := []int{10, 20, 30}
fmt.Println(numeros)
```

Enquanto array tem tamanho fixo no tipo, slice e a forma idiomatica de trabalhar com colecoes dinamicas no dia a dia.

### 2.1 `len` e `cap`

```go
package main

import "fmt"

func main() {
    numeros := []int{10, 20, 30}
    fmt.Println("len =", len(numeros))
    fmt.Println("cap =", cap(numeros))
}
```

- `len`: quantidade atual de elementos visiveis.
- `cap`: capacidade disponivel a partir do inicio daquele slice no array subjacente.

---

## 3. O backing array

Esse e o modelo mental central.

Quando voce cria um slice, geralmente existe por baixo um array real armazenando os dados.

```go
base := [5]int{1, 2, 3, 4, 5}
parte := base[1:4]
fmt.Println(parte)
```

`parte` nao e uma copia completa independente por padrao. Ela aponta para uma faixa do array `base`.

### 3.1 Efeito de compartilhamento

```go
package main

import "fmt"

func main() {
    base := [5]int{1, 2, 3, 4, 5}
    parte := base[1:4]

    parte[0] = 999

    fmt.Println(base)
    fmt.Println(parte)
}
```

Alterar `parte[0]` afeta `base[1]`.

Isso e crucial para evitar bugs de aliasing acidental.

- **Aliasing**: duas referencias ou visoes que acessam a mesma regiao de dados.

## 4. `append`

`append` adiciona elementos a um slice.

```go
numeros := []int{1, 2, 3}
numeros = append(numeros, 4)
fmt.Println(numeros)
```

Ponto importante:

- o resultado de `append` deve ser capturado;
- ele pode reutilizar o backing array existente ou alocar outro maior.

Por isso, esta forma esta correta:

```go
numeros = append(numeros, 5)
```

E esta costuma ser erro conceitual:

```go
append(numeros, 5)
```

---

## 5. Copiando dados com `copy`

Quando voce quer uma copia independente de um slice, use `copy`.

```go
package main

import "fmt"

func main() {
    original := []int{10, 20, 30}
    clone := make([]int, len(original))
    copy(clone, original)

    clone[0] = 999

    fmt.Println(original)
    fmt.Println(clone)
}
```

- `make([]int, len(original))`: cria slice com espaco proprio.
- `copy(dst, src)`: copia elementos entre slices.

## 6. Strings em Go

String em Go representa texto codificado em UTF-8 e e **imutavel**.

```go
nome := "Go"
fmt.Println(nome)
```

- **Imutavel**: nao pode ser alterada em uma posicao interna diretamente.

Isso significa que voce nao faz isto:

```go
// nome[0] = 'P' // erro
```

### 6.1 Bytes de uma string

```go
palavra := "Go"
fmt.Println(len(palavra))
fmt.Println(palavra[0])
```

Aqui, `palavra[0]` retorna um **byte**, nao necessariamente um caractere humano completo.

---

## 7. Bytes e runes

### 7.1 `byte`

`byte` e alias de `uint8`.

Ele representa uma unidade de 8 bits, muito usada para dados binarios e para inspecionar UTF-8 em baixo nivel.

### 7.2 `rune`

`rune` e alias de `int32`.

Em Go, `rune` representa um **code point Unicode**.

Por que isso importa?

Porque texto humano nem sempre cabe em 1 byte por simbolo.

Exemplo:

```go
package main

import "fmt"

func main() {
    texto := "acao"
    for i, r := range texto {
        fmt.Println(i, r, string(r))
    }
}
```

Se voce usar texto com acentos ou simbolos multibyte, `len(texto)` mede bytes, nao quantidade de caracteres humanos.

## 8. `range` sobre slices e strings

`range` facilita iteracao.

### 8.1 Sobre slice

```go
numeros := []int{10, 20, 30}
for i, valor := range numeros {
    fmt.Println(i, valor)
}
```

### 8.2 Sobre string

```go
texto := "Go"
for i, r := range texto {
    fmt.Println(i, r, string(r))
}
```

Em strings, `range` percorre runes decodificadas de UTF-8, nao apenas bytes crus.

## 10. Exemplo completo da aula

```go
package main

import "fmt"

func main() {
    array := [4]int{10, 20, 30, 40}
    slice := array[1:3]

    fmt.Println("array:", array)
    fmt.Println("slice:", slice)
    fmt.Println("len(slice):", len(slice))
    fmt.Println("cap(slice):", cap(slice))

    slice[0] = 999
    fmt.Println("array apos alteracao:", array)

    numeros := []int{1, 2, 3}
    numeros = append(numeros, 4)
    fmt.Println("append:", numeros)

    texto := "Go"
    fmt.Println("len(texto):", len(texto))

    for i, r := range texto {
        fmt.Println("indice:", i, "rune:", r, "char:", string(r))
    }
}
```

### Explicacao linha por linha

- `array := [4]int{...}`: cria array de tamanho fixo.
- `slice := array[1:3]`: cria uma visao sobre parte do array.
- `len(slice)` e `cap(slice)`: mostram tamanho e capacidade.
- `slice[0] = 999`: altera tambem o array subjacente.
- `append(numeros, 4)`: pode reutilizar ou crescer armazenamento.
- `len(texto)`: mede bytes na string.
- `range texto`: itera por runes decodificadas.

## 11. Erros Comuns e Anti-Padroes

1. **Confundir array com slice**: em Go, sao tipos diferentes e com comportamentos diferentes.
2. **Achar que sub-slice sempre copia dados**: normalmente ele compartilha backing array.
3. **Esquecer de capturar o retorno de `append`**: isso e fonte classica de bug.
4. **Usar `len(string)` como se fosse numero de caracteres humanos**: `len` mede bytes.
5. **Tentar editar string como se fosse array mutavel**: string em Go e imutavel.
6. **Ignorar `copy` quando precisa de isolamento real**: aliasing acidental pode contaminar dados.
