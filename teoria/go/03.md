Ao final, voce deve conseguir escrever funcoes pequenas, previsiveis e idiomaticas.

## 1. O que e uma funcao em Go?

Uma funcao e um bloco nomeado de codigo que recebe dados, executa trabalho e opcionalmente devolve resultados.

Exemplo minimo:

```go
package main

import "fmt"

func saudacao() {
    fmt.Println("Ola!")
}

func main() {
    saudacao()
}
```

- `func`: palavra-chave de declaracao de funcao.
- `saudacao`: nome da funcao.
- `()` apos o nome: lista de parametros.
- bloco entre chaves: corpo da funcao.

## 2. Parametros e retorno

```go
package main

import "fmt"

func somar(a int, b int) int {
    return a + b
}

func main() {
    total := somar(10, 20)
    fmt.Println(total)
}
```

### 2.1 Leitura da assinatura

`func somar(a int, b int) int` significa:

- existe uma funcao chamada `somar`;
- ela recebe dois parametros do tipo `int`;
- ela retorna um `int`.

Forma abreviada quando tipos se repetem:

```go
func somar(a, b int) int {
    return a + b
}
```

---

## 3. Passagem por valor

Em Go, parametros sao passados por valor.

```go
package main

import "fmt"

func dobrar(n int) {
    n = n * 2
}

func main() {
    valor := 10
    dobrar(valor)
    fmt.Println(valor)
}
```

Saida:

```text
10
```

Isso acontece porque a funcao recebeu uma copia do valor de `valor`.

**Comparacao conceitual:**

- Em C, passar `int x` tambem copia o valor.
- Em Go, esse modelo continua central.
- Mais adiante veremos ponteiros para permitir modificacao indireta quando isso for desejado.

## 4. Multiplos retornos

Esse e um dos recursos mais caracteristicos de Go.

```go
package main

import "fmt"

func dividir(a, b float64) (float64, bool) {
    if b == 0 {
        return 0, false
    }
    return a / b, true
}

func main() {
    resultado, ok := dividir(10, 2)
    fmt.Println(resultado, ok)
}
```

- **Multiplos retornos**: funcao devolve mais de um valor de uma vez.

### 4.1 Por que isso existe?

Go usa multiplos retornos para representar sucesso, erro, metadados e resultados auxiliares sem precisar de excecoes obrigatorias.

Esse recurso aparece o tempo todo com `valor, erro`.

---

## 5. O valor especial `_`

Quando voce quer ignorar um retorno, pode usar o identificador em branco.

```go
resultado, _ := dividir(10, 2)
fmt.Println(resultado)
```

- `_` recebe o valor e o descarta imediatamente.

Use com criterio. Ignorar retorno demais pode esconder erro real.

---

## 6. Retornos nomeados

Go permite nomear retornos:

```go
func dimensoes() (largura int, altura int) {
    largura = 1920
    altura = 1080
    return
}
```

Embora o recurso exista, muitas vezes o estilo mais claro e retornar explicitamente os valores.

Em material tecnico, prefira clareza a esperteza.

## 7. Escopo entre funcoes

Cada funcao tem seu proprio escopo local.

```go
package main

import "fmt"

func mostrar() {
    mensagem := "escopo local"
    fmt.Println(mensagem)
}

func main() {
    mostrar()
    // fmt.Println(mensagem) // erro
}
```

- nomes declarados dentro de `mostrar` nao existem dentro de `main`.

Esse isolamento reduz interferencia acidental entre partes do programa.

---

## 8. Visibilidade por maiuscula e minuscula

Go usa um mecanismo simples de visibilidade entre packages.

- nome iniciado com letra maiuscula: exportado;
- nome iniciado com letra minuscula: nao exportado.

Exemplo:

```go
func Somar(a, b int) int {
    return a + b
}

func subtrair(a, b int) int {
    return a - b
}
```

- `Somar` pode ser usada por outros packages.
- `subtrair` fica restrita ao package atual.

**Por que isso existe?**

Para reduzir configuracao e tornar a API publica visivel de forma imediata no proprio nome.

## 9. Organizando codigo em varias funcoes

Programas reais nao devem concentrar tudo em `main`.

Ruim:

```go
func main() {
    // tudo misturado aqui
}
```

Melhor:

```go
func cabecalho() {
    fmt.Println("=== Sistema ===")
}

func calcularTotal(preco float64, quantidade int) float64 {
    return preco * float64(quantidade)
}
```

Separar por funcao melhora:

- legibilidade;
- reuso;
- testabilidade;
- manutencao.

## 11. Exemplo completo da aula

```go
package main

import "fmt"

func somar(a, b int) int {
    return a + b
}

func dividir(a, b float64) (float64, bool) {
    if b == 0 {
        return 0, false
    }

    return a / b, true
}

func exibirResultado(nome string, valor float64) {
    fmt.Println(nome, valor)
}

func main() {
    total := somar(10, 25)
    fmt.Println("total:", total)

    resultado, ok := dividir(20, 4)
    if ok {
        exibirResultado("divisao:", resultado)
    } else {
        fmt.Println("divisao invalida")
    }
}
```

### Explicacao linha por linha

- `func somar(a, b int) int`: recebe dois inteiros e devolve um inteiro.
- `return a + b`: encerra a funcao devolvendo o resultado.
- `func dividir(...) (float64, bool)`: retorna um valor numerico e um indicador de sucesso.
- `if b == 0`: evita divisao por zero.
- `resultado, ok := dividir(20, 4)`: captura dois valores retornados.
- `if ok { ... }`: usa o segundo retorno para controlar o fluxo.
- `exibirResultado(...)`: mostra composicao simples entre funcoes.

## 12. Erros Comuns e Anti-Padroes

1. **Tentar usar excecao como estrategia primaria de fluxo**: em Go, multiplos retornos e `error` sao o caminho normal.
2. **Concentrar tudo em `main`**: isso destroi modularidade.
3. **Ignorar `_` sem pensar**: descartar retorno importante pode esconder bug.
4. **Confundir passagem por valor com passagem por referencia automatica**: Go copia o argumento, mesmo quando a sintaxe parece simples.
5. **Usar retorno nomeado sem necessidade**: clareza importa mais que recurso incomum.
6. **Criar funcoes longas demais**: em Go, funcoes pequenas e diretas costumam ser mais idiomaticas.
