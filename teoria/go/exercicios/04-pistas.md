# Aula 04 (Go): pistas graduais

Volte aos [exercicios](../04.md#12-exercicios-obrigatorios) antes de abrir as solucoes.

1. Array tem tamanho no tipo; percorra com indice e com `range`.
2. Slice de array compartilha o armazenamento: escreva pelo slice e leia pelo array.
3. `append` pode realocar: guarde sempre o retorno.
4. `len` de string conta **bytes**; acentos ocupam mais de um.
5. `[]rune` converte para caracteres Unicode de verdade.
