# Aula 02 (Go): pistas graduais

Volte aos [exercicios](../02.md#13-exercicios-obrigatorios) antes de abrir as solucoes.

1. `var` declara sem precisar de valor imediato; `:=` infere e so existe dentro de funcao.
2. Zero value e o valor que a variavel nasce tendo — imprima sem atribuir nada.
3. O `switch` sem expressao (`switch { case cond: }`) e o `if/else if` disfarcado.
4. Go so tem `for`: o estilo while e `for cond { }`.
5. No `switch` de faixas, cada `case` compara a idade com um limite.
