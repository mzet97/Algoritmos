# Aula 06 (Go): pistas graduais

Volte aos [exercicios](../06.md#13-exercicios-obrigatorios) antes de abrir as solucoes.

1. Metodo de leitura usa receiver por valor; o que muda pede `*Conta`.
2. Depositar por valor alteraria a copia — o compilador nao avisa, o saldo e que denuncia.
3. A interface se satisfaz so por ter o metodo: nenhum `implements` para escrever.
4. Composicao: `Pessoa` tem um `Endereco`, nao "e um" endereco.
5. Embedding promove os metodos do `Logger` para o tipo externo.
