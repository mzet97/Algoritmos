# Aula 05 (Go): pistas graduais

Volte aos [exercicios](../05.md#12-exercicios-obrigatorios) antes de abrir as solucoes.

1. O mapa nasce com `map[string]int{...}` ou `make`; escreva nos dois jeitos uma vez.
2. Chave ausente sem `, ok` devolve o zero value — indistinguivel de uma nota zero de verdade.
3. `Livro` com campos exportados para o exercicio imprimir sem getters.
4. A lista e um `[]Livro` montado com literais e percorrido com `range`.
5. No estoque, o produto inteiro mora no valor do mapa; atualizar pede ler, mudar e gravar.
