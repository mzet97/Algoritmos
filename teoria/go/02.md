# Aula 2 - Variaveis, constantes, tipos basicos, inferencia e controle de fluxo

---

## Objetivo da Aula

Aprofundar o modelo de declaracao de variaveis em Go, entender zero values, inferencia de tipos, conversoes explicitas, operadores e as estruturas fundamentais de controle de fluxo: `if`, `switch` e `for`. Ao final, você deverá: declarar variáveis com `:=` e `var`, distinguir tipos básicos e inferência, usar `if`, `for` e `switch`, e prever o valor zero de cada tipo.
Mediremos com níveis de proficiência:
- **Nível 1 — Recordar:** `definir declaração curta, valor zero e as formas de `for`/`switch` em Go`;
- **Nível 2 — Aplicar:** `prever o valor zero e o fluxo de um trecho e corrigir variável não utilizada`;
- **Nível 3 — Projetar:** `projetar controle de fluxo com `switch` sem fallthrough acidental, justificando a escolha`.

## 1. Declaracao com `var` e com `:=`

Na aula anterior vimos as duas formas principais de criar variaveis.

```go
var nome string = "Ana"
idade := 30
```

Agora precisamos distinguir com precisao quando cada uma aparece.

### 1.1 `var`

`var` pode ser usado dentro e fora de funcoes.

```go
var linguagem string = "Go"
var porta int = 8080
```

Ele tambem permite declarar sem inicializar explicitamente:

```go
var total int
var ativo bool
```

### 1.2 `:=`

A forma curta so pode ser usada **dentro de funcao**.

```go
func main() {
    nome := "Carlos"
    _ = nome
}
```

Se voce tentar usar `:=` no nivel do package, o compilador rejeita.

- **Nivel do package**: codigo declarado fora de qualquer funcao, visivel para todo o package.

---

## 2. Zero values

Em Go, variaveis declaradas sem valor explicito recebem um **zero value**.

- `int` vira `0`;
- `float64` vira `0`;
- `bool` vira `false`;
- `string` vira `""`.

Exemplo:

```go
package main

import "fmt"

func main() {
    var idade int
    var saldo float64
    var ativo bool
    var nome string

    fmt.Println(idade)
    fmt.Println(saldo)
    fmt.Println(ativo)
    fmt.Println(nome)
}
```

**Por que isso existe?**

Para dar um estado inicial previsivel e seguro para variaveis declaradas sem inicializacao manual.

**Comparacao:**

- Em C, ler variavel local nao inicializada pode levar a lixo de memoria.
- Em Go, o compilador/runtime garantem inicializacao segura.
- Em Rust, o compilador simplesmente impede uso de variavel nao inicializada.

## 3. Inferencia de tipos

Go pode inferir o tipo a partir do valor atribuido.

```go
idade := 30
preco := 19.90
ativo := true
nome := "Go"
```

O compilador conclui:

- `idade` e `int`;
- `preco` e `float64`;
- `ativo` e `bool`;
- `nome` e `string`.

Go faz inferencia local e direta. Ela nao tenta ser tao sofisticada quanto alguns sistemas de tipos mais complexos. Isso ajuda a manter previsibilidade.

## 4. Tipos numericos: tamanho e limites

Tipos numericos comuns, com tamanho em bytes e faixa de valores (medidos em linux/amd64; `int`/`uint`/`uintptr` dependem da plataforma — 8 bytes em 64 bits, 4 bytes em 32 bits):

| Tipo | Tamanho | Minimo | Maximo |
|---|---|---|---|
| `int8` | 1 byte | -128 | 127 |
| `uint8` (`byte`) | 1 byte | 0 | 255 |
| `int16` | 2 bytes | -32768 | 32767 |
| `uint16` | 2 bytes | 0 | 65535 |
| `int32` (`rune`) | 4 bytes | -2147483648 | 2147483647 |
| `uint32` | 4 bytes | 0 | 4294967295 |
| `int64` | 8 bytes | -9223372036854775808 | 9223372036854775807 |
| `uint64` | 8 bytes | 0 | 18446744073709551615 |
| `int` | 8 bytes aqui (depende da plataforma) | -9223372036854775808 | 9223372036854775807 |
| `uint` | 8 bytes aqui (depende da plataforma) | 0 | 18446744073709551615 |
| `uintptr` | 8 bytes aqui (depende da plataforma) | 0 | 18446744073709551615 |
| `float32` | 4 bytes | ~-3.4e38 | ~3.4e38 (`math.MaxFloat32`) |
| `float64` | 8 bytes | ~-1.8e308 | ~1.8e308 (`math.MaxFloat64`) |
| `bool` | 1 byte | `false` | `true` |
| `string` | 16 bytes de cabecalho (ponteiro + tamanho) + conteudo | — | — |

Aliases: `byte` e `uint8`, `rune` e `int32`. `string` nao e um numero: o cabecalho tem 16 bytes em 64 bits e o conteudo (bytes UTF-8 imutaveis) varia com o texto.

### 4.1 Experimento: medir na sua maquina

```go
package main

import (
    "fmt"
    "math"
    "unsafe"
)

func main() {
    fmt.Println("int:", unsafe.Sizeof(int(0)), math.MinInt, math.MaxInt)
    fmt.Println("int8:", unsafe.Sizeof(int8(0)), math.MinInt8, math.MaxInt8)
    fmt.Println("int64:", unsafe.Sizeof(int64(0)), math.MinInt64, math.MaxInt64)
    fmt.Println("uint:", unsafe.Sizeof(uint(0)), 0, uint64(math.MaxUint))
    fmt.Println("float32:", unsafe.Sizeof(float32(0)), -math.MaxFloat32, math.MaxFloat32)
    fmt.Println("float64:", unsafe.Sizeof(float64(0)), -math.MaxFloat64, math.MaxFloat64)
    fmt.Println("bool:", unsafe.Sizeof(true))
    fmt.Println("string header:", unsafe.Sizeof(""))
}
```

Saida em linux/amd64:

```text
int 8 -9223372036854775808 9223372036854775807
uint 8 0 18446744073709551615
int8 1 -128 127
uint8 1 0 255
int16 2 -32768 32767
uint16 2 0 65535
int32 4 -2147483648 2147483647
uint32 4 0 4294967295
int64 8 -9223372036854775808 9223372036854775807
uint64 8 0 18446744073709551615
uintptr 8
float32 4 -3.4028234663852886e+38 3.4028234663852886e+38
float64 8 -1.7976931348623157e+308 1.7976931348623157e+308
bool 1
string header 16
```

Registre `go version`, `GOARCH` (`go env GOARCH`) e a saida: `int`/`uint`/`uintptr` mudam com a arquitetura, os tipos com numero fixo (`int8`...`uint64`, `float32/64`) nao.

### 4.2 Conversao explicita

Go nao faz varias conversoes implicitas que C/C++ fariam com facilidade.

```go
package main

import "fmt"

func main() {
    var idade int = 30
    var preco float64 = 19.99

    total := float64(idade) + preco
    fmt.Println(total)
}
```

- **Conversao explicita**: transformacao pedida pelo programador, escrita de forma visivel no codigo.

Esse design reduz ambiguidade e surpresas em expressoes.

## 5. Operadores

Go possui operadores aritmeticos e logicos familiares.

### 5.1 Aritmeticos

```go
package main

import "fmt"

func main() {
    a := 10
    b := 3

    fmt.Println(a + b)
    fmt.Println(a - b)
    fmt.Println(a * b)
    fmt.Println(a / b)
    fmt.Println(a % b)
}
```

Ponto importante:

- `a / b` entre inteiros faz divisao inteira.

### 5.2 Relacionais e logicos

```go
idade := 20
ativo := true

fmt.Println(idade >= 18)
fmt.Println(idade < 18)
fmt.Println(ativo && idade >= 18)
fmt.Println(!ativo)
```

## 6. `if` em Go

A estrutura basica:

```go
if condicao {
    // bloco
}
```

Exemplo:

```go
package main

import "fmt"

func main() {
    idade := 20

    if idade >= 18 {
        fmt.Println("maior de idade")
    } else {
        fmt.Println("menor de idade")
    }
}
```

### 6.1 `if` com inicializacao curta

Go permite criar uma variavel local antes da condicao:

```go
if limite := 100; limite > 50 {
    fmt.Println("limite alto")
}
```

A variavel `limite` so existe naquele `if` e nos blocos associados.

Isso ajuda a restringir escopo e reduz o vazamento de nomes desnecessarios.

## 7. `switch`

`switch` em Go e mais flexivel do que em C.

```go
package main

import "fmt"

func main() {
    dia := 2

    switch dia {
    case 1:
        fmt.Println("domingo")
    case 2:
        fmt.Println("segunda")
    default:
        fmt.Println("outro dia")
    }
}
```

Diferenca importante:

- Em Go, `switch` **nao faz fallthrough automaticamente**.
- Em C, esquecer `break` e uma fonte classica de bugs.

Go tambem aceita `switch` sem expressao:

```go
switch {
case idade < 12:
    fmt.Println("crianca")
case idade < 18:
    fmt.Println("adolescente")
default:
    fmt.Println("adulto")
}
```

## 8. `for`: o unico laco da linguagem

Go tem apenas `for`, mas ele cobre os papeis de `while`, `do while` e laco classico.

### 8.1 Forma classica

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

### 8.2 Como `while`

```go
contador := 0
for contador < 3 {
    fmt.Println(contador)
    contador++
}
```

### 8.3 Laco infinito

```go
for {
    break
}
```

- **Laco infinito**: repeticao sem condicao de parada embutida; a saida depende de `break`, `return` ou outra interrupcao.

## 9. Escopo de bloco

Go usa chaves para delimitar blocos e escopos.

```go
package main

import "fmt"

func main() {
    if true {
        mensagem := "visivel so neste bloco"
        fmt.Println(mensagem)
    }

    // fmt.Println(mensagem) // erro: fora do escopo
}
```

- **Escopo**: regiao do programa onde um nome e valido.

Em software real, escopo menor geralmente significa menos acoplamento mental e menos erros.

## 11. Exemplo completo da aula

```go
package main

import "fmt"

func main() {
    var nome string = "Marina"
    idade := 28
    var saldo float64
    ativo := true

    fmt.Println("nome =", nome)
    fmt.Println("idade =", idade)
    fmt.Println("saldo =", saldo)
    fmt.Println("ativo =", ativo)

    if idade >= 18 && ativo {
        fmt.Println("usuario ativo e maior de idade")
    } else {
        fmt.Println("usuario com restricao")
    }

    switch {
    case idade < 18:
        fmt.Println("faixa: menor")
    case idade < 60:
        fmt.Println("faixa: adulto")
    default:
        fmt.Println("faixa: idoso")
    }

    for i := 0; i < 3; i++ {
        fmt.Println("iteracao", i)
    }
}
```

### Explicacao linha por linha

- `var nome string = "Marina"`: declaracao explicita com tipo.
- `idade := 28`: declaracao curta com inferencia.
- `var saldo float64`: valor inicial vira `0`.
- `ativo := true`: booleano com inferencia.
- `if idade >= 18 && ativo`: combina comparacao e operador logico.
- `switch { ... }`: usa condicoes em vez de uma expressao central.
- `for i := 0; i < 3; i++`: laco classico controlado por contador.

## 12. Erros Comuns e Anti-Padroes

1. **Usar `:=` fora de funcao**: isso nao e permitido.
2. **Esperar conversao implicita entre `int` e `float64`**: Go pede conversao explicita.
3. **Achar que `switch` cai automaticamente no proximo `case`**: em Go isso nao acontece por padrao.
4. **Esquecer que `for` substitui `while`**: Go nao tem palavra-chave `while`.
5. **Ignorar zero values**: eles fazem parte do modelo mental da linguagem.
6. **Criar variaveis com escopo maior do que o necessario**: prefira escopos curtos e claros.
