# Aula 1 - Introducao ao Go, instalacao, ferramenta `go`, estrutura de um programa, `package main`, `func main`, `fmt.Println`, variaveis, constantes e tipos basicos

Go nasceu de uma frustração: compilar projetos gigantes devagar demais e escrever concorrência difícil demais. A primeira aula instala a ferramenta e o modelo mental — programa compilado, tipos explícitos, simplicidade como decisão de engenharia.

## Nesta aula

Compreender o que e Go, por que ela existe, como instalar a toolchain, como compilar e executar programas, qual e a estrutura minima de um executavel Go e como declarar suas primeiras variaveis, constantes e tipos basicos. Você vai aprender a instalar o toolchain, usar `go run`/`go build`/`go mod`, explicar a estrutura (`package main`, `func main`, `fmt.Println`), declarar variáveis e constantes e prever tipos básicos.

## 1. O que e Go?

Go e uma linguagem compilada, tipada estaticamente e projetada para simplicidade, produtividade em engenharia e bom suporte a software concorrente.

Como estes termos aparecem pela primeira vez, vale defini-los com cuidado:

- **Compilada**: o codigo fonte e transformado em codigo de maquina antes da execucao, gerando um binario nativo.
- **Tipada estaticamente**: os tipos das expressoes sao verificados antes do programa rodar, e nao apenas durante a execucao.
- **Concorrente**: a linguagem oferece mecanismos proprios para estruturar varias tarefas em progresso ao mesmo tempo.

Go surgiu para atacar problemas reais de engenharia:

- compilacao lenta em codebases grandes de C++;
- verbosidade excessiva em algumas linguagens corporativas;
- dificuldade de construir servicos concorrentes robustos;
- necessidade de ferramentas simples e padronizadas.

**Comparacao com C, C++ e Rust:**

| Aspecto | C | C++ | Rust | Go |
|---|---|---|---|---|
| Compilacao | Sim | Sim | Sim | Sim |
| Gerencia de memoria | Manual | Manual/RAII | Ownership | Garbage collector |
| Concorrencia nativa | Biblioteca/SO | Biblioteca | Muito forte | Muito forte |
| Simplicidade sintatica | Alta | Media/Baixa | Media | Alta |
| Binario nativo | Sim | Sim | Sim | Sim |

Go abre mao de alguns recursos sofisticados para manter a linguagem menor e mais previsivel no dia a dia.

## 2. Instalacao e verificacao

No Windows, baixe o instalador em [go.dev/dl](https://go.dev/dl) e conclua a instalacao.

Depois, valide no terminal:

```bash
go version
```

Saida esperada, por exemplo:

```text
go version go1.24.x windows/amd64
```

Voce tambem pode inspecionar o ambiente:

```bash
go env
```

### 2.1 A ferramenta `go`

Diferentemente de ecossistemas em que voce precisa combinar varias ferramentas separadas, Go centraliza quase tudo no comando `go`.

Comandos importantes desde o inicio:

- `go run`: compila e executa rapidamente;
- `go build`: gera um binario;
- `go test`: roda testes;
- `go fmt`: formata codigo;
- `go vet`: analisa erros comuns;
- `go mod init`: inicia um modulo.

**Comparacao:**

- Em C, e comum chamar `gcc` manualmente.
- Em Rust, `cargo` centraliza build e testes.
- Em Go, o proprio `go` cumpre esse papel de forma parecida com `cargo`, mas com menos camadas de configuracao no caso simples.

## 3. Estrutura minima de um programa Go

Crie um arquivo `main.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Ola, Go!")
}
```

Vamos decompor o programa.

### 3.1 `package main`

Todo arquivo Go pertence a um **package**.

- **Package**: unidade basica de organizacao de codigo em Go.
- `package main` indica que esse conjunto de arquivos gera um programa executavel.

Se o package nao for `main`, normalmente ele representa uma biblioteca reutilizavel.

### 3.2 `import "fmt"`

`import` traz outro package para dentro do arquivo atual.

- `fmt` e parte da biblioteca padrao.
- Ele oferece funcoes de formatacao e saida, como `Println`, `Printf` e `Sprintf`.

Comparacao conceitual:

- Em C, isso lembra `#include <stdio.h>` para I/O.
- Em Go, nao ha pre-processador de headers como em C/C++.
- Em Rust, o paralelo mental e `use`, mas a organizacao exata do sistema de modulos e diferente.

### 3.3 `func main()`

`main` e o ponto de entrada do programa executavel.

- **Funcao**: bloco nomeado de codigo que pode ser chamado.
- Em Go, a funcao principal chama-se `main` e deve estar no `package main`.

Comparacao:

```c
int main(void) {
    printf("Ola\n");
    return 0;
}
```

```rust
fn main() {
    println!("Ola");
}
```

```go
func main() {
    fmt.Println("Ola")
}
```

## 4. `fmt.Println()` e a primeira saida

`fmt.Println()` escreve valores na saida padrao e adiciona quebra de linha no final.

```go
fmt.Println("Ola, Go!")
fmt.Println(42)
fmt.Println(true)
```

- **Saida padrao**: fluxo normalmente conectado ao terminal.
- `Println` separa argumentos por espaco automaticamente.

Exemplo:

```go
nome := "Marina"
idade := 28

fmt.Println("Nome:", nome, "Idade:", idade)
```

Saida:

```text
Nome: Marina Idade: 28
```

Quando voce precisar de controle fino de formatacao, veremos `fmt.Printf` nas proximas aulas.

## 5. Variaveis em Go

Go e estaticamente tipada, mas pode inferir tipos em muitos casos.

### 5.1 Declaracao com `var`

```go
var nome string = "Carlos"
var idade int = 30
var ativo bool = true
```

Aqui, cada variavel tem um tipo bem definido.

- **Variavel**: nome associado a um valor armazenado ou acessado pelo programa.
- **Tipo**: conjunto de valores possiveis e operacoes validas sobre eles.

### 5.2 Inferencia com `:=`

Forma idiomatica dentro de funcoes:

```go
cidade := "Recife"
ano := 2026
```

O compilador infere:

- `cidade` como `string`;
- `ano` como `int`.

**Comparacao com outras linguagens:**

- C normalmente exige tipo explicito na declaracao.
- C++ pode inferir com `auto`.
- Rust pode inferir com `let x = ...`.
- Go usa `:=` como forma curta e muito comum.

### 5.3 Go nao tem variavel "sem tipo"

Em Go, o nome da variavel nao pode mudar de tipo ao longo da execucao.

```go
idade := 30
// idade = "trinta" // erro de compilacao
```

Isso contrasta fortemente com Python, onde um nome pode ser reatribuido a objetos de tipos diferentes.

## 6. Constantes

Constantes sao valores que nao mudam.

```go
const Pi = 3.14159
const NomeDoCurso = "Go do zero"
```

- **Constante**: identificador cujo valor nao pode ser alterado depois de declarado.

Em Go, constantes sao muito usadas para valores fixos, limites, codigos e configuracoes simbolicas.

## 7. Tipos basicos iniciais: tamanho e limites

Os primeiros tipos que voce precisa reconhecer sao (valores em linux/amd64; `int` muda com a arquitetura):

| Tipo | Tamanho | Minimo | Maximo |
|---|---|---|---|
| `int` | 8 bytes aqui (4 em 32 bits) | -9223372036854775808 | 9223372036854775807 |
| `float64` | 8 bytes | ~-1.8e308 (`-math.MaxFloat64`) | ~1.8e308 (`math.MaxFloat64`) |
| `bool` | 1 byte | `false` | `true` |
| `string` | 16 bytes de cabecalho + conteudo | — | — |

Tabela completa com `int8`...`uint64`, `float32` e limites exatos na [Aula 2](02.md).

Exemplo:

```go
idade := 30
altura := 1.75
estudando := true
nome := "Aline"

fmt.Println(idade)
fmt.Println(altura)
fmt.Println(estudando)
fmt.Println(nome)
```

### 7.1 O que acontece em memoria

Modelo conceitual simplificado para variaveis locais pequenas:

```text
frame atual de main:
- idade: int
- altura: float64
- estudando: bool
- nome: string
```

Ponto importante:

- tipos pequenos como `int` e `bool` costumam caber diretamente no frame da funcao;
- `string` em Go nao e uma lista mutavel de caracteres, mas uma estrutura que referencia bytes imutaveis.

Voltaremos a memoria com mais profundidade quando estudarmos ponteiros, slices e escape analysis.

## 8. Comandos exatos para executar

### 8.1 Rodar rapidamente

```bash
go run main.go
```

### 8.2 Gerar binario

```bash
go build main.go
```

No Windows, isso tende a gerar `main.exe`.

### 8.3 Formatar codigo

```bash
go fmt main.go
```

### 8.4 Criar um modulo

Quando o codigo deixar de ser um unico arquivo solto, faca:

```bash
go mod init exemplo.com/curso-go
```

## 9. Exemplo completo da aula

```go
package main

import "fmt"

const Linguagem = "Go"

func main() {
    nome := "Marina"
    idade := 28
    altura := 1.68
    estudando := true

    fmt.Println("=== Aula 1 de Go ===")
    fmt.Println("Linguagem:", Linguagem)
    fmt.Println("Nome:", nome)
    fmt.Println("Idade:", idade)
    fmt.Println("Altura:", altura)
    fmt.Println("Estudando:", estudando)
}
```

### Explicacao linha por linha

- `package main`: define um package executavel.
- `import "fmt"`: traz o package de formatacao.
- `const Linguagem = "Go"`: declara uma constante textual.
- `func main()`: ponto de entrada do programa.
- `nome := "Marina"`: cria uma variavel `string` com inferencia.
- `idade := 28`: cria uma variavel `int`.
- `altura := 1.68`: cria uma variavel `float64`.
- `estudando := true`: cria uma variavel `bool`.
- `fmt.Println(...)`: escreve cada valor no terminal.

## 10. Erros Comuns e Anti-Padroes

1. **Confundir `package main` com nome de arquivo**: `main` e o nome do package, nao do arquivo.
2. **Achar que `fmt.Println` funciona sem `import "fmt"`**: packages precisam ser importados.
3. **Esperar dinamismo de tipos como em Python**: Go nao permite mudar o tipo da variavel no meio do programa.
4. **Esquecer que Go compila antes de executar**: `go run` parece interpretacao, mas ha compilacao envolvida.
5. **Nao usar `go fmt`**: em Go, formatacao padrao faz parte da cultura e do fluxo normal.
6. **Misturar conceitos de C/C++ sem adaptar o modelo mental**: Go tem sintaxe familiar em alguns pontos, mas o ecossistema e o estilo idiomatico sao diferentes.
