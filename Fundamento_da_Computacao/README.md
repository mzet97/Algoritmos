# Fundamentos da Computação

Soluções de 55 exercícios de algoritmos em 5 linguagens: **Python**, **Rust**, **Go**, **C** e **C++**.

---

## Enunciados

### 101 — Operação aritmética
Escreva uma função que, dados dois números x, y, e uma operação op (op ∈ {"+", "-", "/", "x"}), retorne o resultado "x op y".

### 102 — Formatação de hora
Escreva uma função que receba uma tupla com dois números (h, m), representando os números apontados pelos ponteiros de hora e minuto de um relógio (1 a 12), e retorne uma tupla com os dois possíveis horários para aquele dia.

### 103 — Calcular segundos decorridos
Escreva uma função que receba duas tuplas (h1, m1) e (h2, m2) e retorne o número de segundos entre os dois horários.

### 104 — Contagem de dígitos
Escreva uma função que receba um inteiro x e um dígito y, e retorne quantas vezes o dígito y aparece na representação decimal de x.

### 105 — Soma de listas
Escreva uma função que receba duas listas de dígitos (índice 0 = menos significativo) e retorne a lista representando a soma dos números.

### 106 — Subtração de listas
Escreva uma função que receba duas listas de dígitos e retorne a lista representando a subtração (x ≥ y).

### 107 — Multiplicação de lista por número
Escreva uma função que receba uma lista de dígitos e um natural y (0-9), retorne a lista da multiplicação.

### 108 — Multiplicação de lista por lista
Escreva uma função que receba duas listas de dígitos e retorne a lista da multiplicação.

### 109 — Divisão de listas
Escreva uma função que receba duas listas de dígitos e retorne uma tupla (quociente, resto).

### 110 — Verificar número primo
Escreva uma função que recebe um natural x e retorna um valor lógico indicando se x é primo.

### 111 — Calcular distância (MRU)
Escreva uma função que receba velocidade inicial, aceleração e tempo, e retorne a distância percorrida.

### 112 — Conversão de unidades
Escreva uma função que converta um valor entre unidades de comprimento, massa ou volume.

### 113 — Contar positivos e negativos
Escreva uma função que receba uma lista de inteiros e retorne (qp, qn), quantidade de positivos e negativos.

### 114 — Raiz de equação do primeiro grau
Escreva uma função que receba coeficientes a, b da equação ax + b = 0 e retorne a raiz.

### 115 — Raiz de equação do segundo grau
Escreva uma função que receba coeficientes a, b, c da equação ax² + bx + c = 0 e retorne as raízes.

### 116 — Calcular raiz quadrada [O(√n)]
Escreva uma função que receba n e retorne a raiz quadrada inteira de n.

### 117 — Converter para notação científica
Escreva uma função que receba um real n e retorne a notação científica com uma casa decimal.

### 118 — Calcular MDC
Escreva uma função que receba dois naturais x, y e retorne o MDC entre eles.

### 119 — Calcular MMC
Escreva uma função que receba dois naturais x, y e retorne o MMC entre eles.

### 120 — Contagem de múltiplos
Escreva uma função que receba naturais a, b, n e retorne a quantidade de múltiplos comuns menores que n.

### 121 — Redução de fração
Escreva uma função que receba uma tupla (p, q) e retorne a fração irredutível equivalente.

### 122 — Soma de frações
Escreva uma função que receba duas frações e retorne a soma na forma irredutível.

### 123 — Multiplicação de frações
Escreva uma função que receba duas frações e retorne o produto na forma irredutível.

### 124 — Divisão de frações
Escreva uma função que receba duas frações e retorne o quociente na forma irredutível.

### 125 — Contagem de caracteres
Escreva uma função que receba uma string L e um caractere c, e retorne quantas vezes c aparece em L.

### 126 — Remoção de caracteres
Escreva uma função que receba uma string L e um caractere c, e retorne L sem os caracteres c.

### 127 — Duplicar vogais
Escreva uma função que receba uma string L e retorne outra com cada vogal duplicada.

### 128 — Verificar palíndromo
Escreva uma função que receba uma string L e retorne se é palíndromo (ignorando espaços).

### 129 — Inverter uma cadeia
Escreva uma função que receba uma string L e retorne a cadeia reversa.

### 130 — Verificar subcadeia
Escreva uma função que receba duas strings L, S e retorne se S é subcadeia de L.

### 131 — Notas maiores que a média
Escreva uma função que receba uma lista de notas e retorne quantas estão acima da média.

### 132 — Conversão de polegadas
Escreva uma função que receba diagonal em polegadas e proporção, retorne largura e altura em cm.

### 133 — Troco em moedas
Escreva uma função que receba lista de moedas M e quantidades Q, e retorne o total em unidades monetárias.

### 134 — Ângulo entre ponteiros
Escreva uma função que receba H e M e retorne o menor ângulo entre os ponteiros do relógio.

### 135 — Propriedade especial
Escreva uma função que retorne todos os números de 4 dígitos onde (esq + dir)² = número.

### 136 — Cálculo do Imposto de Renda
Escreva uma função que receba uma lista de salários e retorne o total de imposto devido.

### 137 — Matriz transposta
Escreva uma função que receba uma matriz n×m e retorne a transposta m×n.

### 138 — Progressão aritmética
Escreva uma função que receba a, r, n e retorne os n primeiros termos da PA.

### 139 — Progressão geométrica
Escreva uma função que receba a, q, n e retorne os n primeiros termos da PG.

### 140 — Verificar número perfeito
Escreva uma função que receba n e retorne se é perfeito (soma dos divisores = n).

### 141 — Maiores e menores notas
Escreva uma função que receba matrículas e notas, retorne matrículas da maior e menor nota.

### 142 — Posição do ponto em relação à reta
Escreva uma função que receba reta y = ax + b e ponto (x, y), retorne ">", "=" ou "<".

### 143 — Saque no caixa eletrônico
Escreva uma função que receba um valor S e retorne a lista de notas para o saque ótimo.

### 144 — Calcular π pela série
Escreva uma função que receba N e retorne π aproximado pela série de termo (-1)^i / (2i+1)³.

### 145 — Calcular valor da série
Escreva uma função que receba N e retorne o valor da série Σ(i / (N-i+1)).

### 146 — Sequência de Fibonacci
Escreva uma função que receba N e retorne o N-ésimo termo de Fibonacci.

### 147 — Desenhar a sequência de Fibonacci
Escreva uma função que receba N e escreva a sequência em formato de losango.

### 148 — Calcular fatorial
Escreva uma função que receba N e retorne N!.

### 149 — Calcular resultado do polinômio
Escreva uma função que receba N, coeficientes a[0..N] e valor k, retorne f(k) pelo método de Horner.

### 150 — Contagem de caracteres únicos
Escreva uma função que receba uma string e retorne quantos caracteres são únicos.

### 151 — Multiplicação de matrizes
Escreva uma função que receba matrizes M1 (R×S) e M2 (S×T) e retorne MR = M1 × M2.

### 152 — Resolução de sistema
Escreva uma função que receba matriz triangular inferior a[] e vetor b[], retorne a solução x[].

### 153 — Calcular raiz quadrada [O(log n)]
Escreva uma função que receba n e retorne a raiz quadrada inteira usando busca binária.

### 154 — Calcular distância [aceleração geral]
Escreva uma função que receba velocidade, aceleração (qualquer sinal) e tempo, retorne a distância percorrida.

### 155 — Comparação de listas
Escreva uma função que receba duas listas de dígitos e retorne se x ≥ y.

## Como executar

### Python
```bash
cd python/101
python3 main.py < ../../exercicios/101/Input.txt
```

### Rust
```bash
cd rust
cargo run -p ex101 < ../exercicios/101/Input.txt
```

### Go
```bash
cd go/101
go run main.go < ../../exercicios/101/Input.txt
```

### C
```bash
cd c/101
gcc main.c -lm -o main && ./main < ../../exercicios/101/Input.txt
```

### C++
```bash
cd cpp/101
g++ -std=c++17 main.cpp -lm -o main && ./main < ../../exercicios/101/Input.txt
```

## Biblioteca bib1

Cada linguagem tem uma biblioteca auxiliar:

| Linguagem | Arquivo | Funções |
|-----------|---------|---------|
| Python | `python/bib1.py` | `entrada()` |
| Rust | `rust/bib1/src/lib.rs` | `Leitor::entrada()`, `python_float()` |
| Go | `go/bib1/bib1.go` | `Entrada()`, `PythonFloat()` |
| C | `c/bib1.h` | `entrada()`, `print_python_float()` |
| C++ | `cpp/bib1.hpp` | `entrada()`, `python_float()` |

- **`entrada()`** — lê uma linha de stdin ignorando linhas vazias, retorna EOF
- **`python_float()`** — formata floats no estilo Python (shortest round-trip)

- Exercícios com `@entradagrande` usam inputs especiais para testes de performance
- Listas de dígitos usam índice 0 como dígito menos significativo
- Alguns exercícios (105-109) operam com números de até 10⁶ dígitos
